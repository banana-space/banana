{@help:typesetting}

本文介绍正文中段落、标题、列表、链接、图片等的写法。

## 段落与换行

空一行开始新的段落。段落内的单个换行不会显示出来，
因此可以在标点符号处换行，使源码的每行不太长：

```markdown
这是一个段落。
这一行与上一行属于同一段。

这是另一个段落。
```

需要在段落内换行时，在行末写一个反斜杠 `\`。

## 标题

正文从二级标题开始：

```markdown
## 定义

### 小节标题

#### 更小的标题
```

在百科条目中，只使用 `##` 和 `###` 两级，不用更小的标题。

标题末尾加 `*` 表示不编号，例如 `## 参考文献*`。

标题末尾可以加引用标签，例如 `## 定义 {@sec:definition}`，见 @help:references。

## 文字样式

| 写法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `` `代码` `` | `代码` |

中文不要用斜体，需要强调时用粗体。
文章主题在开头首次出现时加粗，定义中被定义的术语加粗。

## 列表

无序列表用 `-` 开头，有序列表用 `1.` 开头：

```markdown
- 第一项。

  这一段仍属于第一项。

- 第二项。

不缩进的段落不属于列表项。

1. 第一步。

2. 第二步。
```

列表项之间是否空行决定该列表使用宽间距还是窄间距。
在百科条目中，一般都使用宽距列表，因此项目之间应该空行。

以 `a)`、`iv)`、`A1)` 或 `(a)`、`(i)`、`(1)`、`(A1)`
开头的行是自定义标签的列表：

```markdown
a) 第一部分。
b) 第二部分。

(T1) 第一条公理。
(T2') 可以使用撇号。
($\ast$) 也可以使用单独一个公式。

(1\) 这不是列表。
1\. 这也不是列表。
```

标签可以由字母、数字组成，可以带撇号，也可以是单个公式。
使用 `\)` 和 `\.` 可以避免将文字识别成列表。
同样地，在百科条目中，项目之间通常应该空行。

需要在引用列表的某一项时，见 @help:references。

## 引文

行首写 `> `&nbsp;表示引文：

```markdown
> 余数学家是把余定理变成啡的余机器。
```

## 表格

```markdown
| 群 | 阶 |
| --- | --- |
| $\mathbb{Z}/2$ | $2$ |
| $\mathfrak{S}_3$ | $6$ |
```

## 代码

行内代码用 `` ` `` 围起来：`` `abc` ``。
代码块用 ```` ``` ```` 围起来：

````markdown
```latex
\begin{tikzcd} A \arrow[r] & B \end{tikzcd}
```
````

## 脚注

```markdown
这是正文[^1]。

[^1]: 这是脚注。
```

脚注显示在页面末尾。在百科页面中，避免使用脚注。

## 链接

### 百科链接

用两个方括号链接到百科条目：

| 写法 | 显示 | 链接到 |
| --- | --- | --- |
| `[[群]]` | [[群]] | 条目“群” |
| `[[群\|群结构]]` | [[群\|群结构]] | 条目“群” |
| `[[$\infty$-范畴]]` | [[$\infty$-范畴]] | 条目“$\infty$-范畴” |

有时在表格中书写链接会出错，此时可以用 `\|` 代替 `|` 书写链接。

### 其他链接

使用 Markdown 语法链接到外部网页：

```markdown
[$n$Lab](https://ncatlab.org)
<https://arxiv.org>
```

### 参见

在一节的开头指向相关的条目，用 `<see>` 标签，显示为“参见：……”：

```markdown
<see>[[Galois 理论]]、[[Galois 上同调]]</see>
```

## 图片

图片文件放在页面的文件夹中，用 Markdown 的语法插入：

```markdown
![图 1：环面](torus.png){width=300}
```

图片应单独成段，此时图片居中显示，
方括号中的文字显示在图下，作为图片标题。
图片之后的 `{width=300}` 指定显示的宽度（像素），可以省略。

也可以把方括号留空：`![](torus.png "环面")`，
此时不显示图片标题，但引号里的文字会在鼠标悬停时显示。

对于一般的示意图，我们推荐用 TikZ 绘制，见 @help:math。

## 组件

### 折叠内容

```markdown
<spoiler title="提示">
点击后才显示的内容。
</spoiler>
```

### 居右与居中

署名、日期、引文的出处等需要居右的文字：

```markdown
<align right>
作者署名\
日期
</align>
```

各行之间用行末的反斜杠换行。居中的文字写 `<align center>`。

图片、TikZ 图形和行间公式已经居中，不需要这个组件。

### 外文片段

完整的外文句子或段落用 `<lang>` 标签标注语言，网站会按该语言排版：

```markdown
<lang en>Text in English.</lang>
```

语言用代码表示，例如 `en`、`fr`、`de` 等。

### 人名

关于人物的百科条目开头，在姓名之后用 `<person … />` 标签标注原名、转写、读音、生卒年：

```markdown
**Nobuo Yoneda**
<person original="米田 信夫" lang="ja" translit="Yoneda Nobuo" years="1930--1996" />
```

支持的字段如下：

| 字段 | 含义 |
| --- | --- |
| `original` | 原文姓名，当原文不是由拉丁字母写成时 |
| `lang` | 原文的语言 |
| `translit` | 拉丁字母转写 |
| `ipa` | 国际音标 |
| `years` | 生卒年 |

日文原名可以标注读音，写法与术语翻译相同（见 @help:notices），
例如 `original="米<よね>田<だ> 信<のぶ>夫<お>"`。

标签太长时，可以在字段之间换行，续行缩进；每个字段的值要写在同一行，标签中不能有空行：

```markdown
**Johann Peter Gustav Lejeune Dirichlet**
<person lang="de" years="1805--1859"
  ipa="/ˈjoː.han ˈpeː.tɐ ˈɡʊs.taf lə.ˈʒœn di.ʁi.ˈkleː/" />，
```

## 特殊字符

- 正文中的美元符号写成 `\$`，反斜杠写成 `\\`。
  
- 需要方括号 `[`、`]` 但引起语法错误时，写成 `&#91;`、`&#93;`。
