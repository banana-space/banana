本文介绍页面顶部的提示框，以及页面底部的学科导航、术语翻译的写法。

## 提示

提示框显示在页面标题之下、正文之前，写在页面信息的 `notices` 中：

```yaml
notices:
  - name: 问题
    items:
      - “例子”一节需要扩充。
      - 命题 2.3 的证明不完整。
  - name: 消歧义
    about: 代数拓扑中的上同调
    see:
      - topic: 层的上同调
        page: 层上同调
```

可用的提示如下：

| 提示 | 参数 | 显示 |
| --- | --- | --- |
| 问题 | `items`：问题的列表 | “本条目存在以下问题：”及问题列表 |
| 消歧义 | `about`：本条目介绍的含义，可省略；`see`：其他含义的列表，每项有 `page`（条目标题）和 `topic`（这些条目的含义） | “本条目介绍的是……。关于……，请参见……。” |
| 区分 | `pages`：条目列表；或 `text`：一句话 | “注意与……区分。” |
| 提示 | `text` | 文字本身 |

在这些字段中支持数学公式，但暂时不支持 `@` 引用。

### 消歧义与区分

同一个名称有几种含义时，在介绍其中一种含义的条目上加“消歧义”提示。
例如，在“结合代数”中：

```yaml
notices:
  - name: 消歧义
    about: 作为代数结构的结合代数
    see:
      - topic: 它在范畴代数中的推广
        page: 代数对象
```

这将显示“本文介绍的是作为代数结构的结合代数。关于它在范畴代数中的推广，请参见代数对象”。

这里，条目标题 `page` 也可以是一个列表。

名称相似、容易混淆的条目，用“区分”提示：

```yaml
notices:
  - name: 区分
    pages: [Auslander–Buchsbaum 公式]
```

## 学科导航

百科页面底部的学科导航框列出相关学科中的主要条目。
在页面信息中写上导航框的名称即可：

```yaml
navboxes: [代数拓扑]
```

一个条目可以带有多个导航框，例如 `navboxes: [代数拓扑, 同伦论]`。

每个导航框是仓库中 `content/navboxes/` 下的一个文件，文件名就是导航框的名称，
例如 `content/navboxes/代数拓扑.yaml`：

```yaml
title: '[[代数拓扑]]'
groups:
  - title: 同调论
    subgroups:
      - title: 同调
        items:
          - '[[奇异同调]]'
          - '[[胞腔同调]]'
      - title: 上同调
        items:
          - '[[奇异上同调]]'
          - '[[de Rham 上同调]]'
  - title: 同伦论
    items:
      - '[[基本群]]'
      - '[[同伦群]]'
```

当然实际的导航框里有更多的链接。

在导航框的文件开头写 `collapsed: true`，导航框默认收起。

## 术语翻译

条目中术语的外文翻译写在 `terms` 代码块中，显示在页面底部。
请不要在正文中用括号标注外文术语。

````markdown
```terms
群:
  en: group
  fr: groupe :m
  de: Gruppe :f
  ja: 群<ぐん>
```
````

- 语言用语言代码表示，例如 `en`、`fr`、`de`、`ru`、`ja`、`la`、`grc`。

- 同一语言有几个译名时写成列表：`en: [partially ordered set, poset]`。

- 名词的语法性别写在译名之后，用一个空格隔开：
  `:m` 阳性，`:f` 阴性，`:n` 中性，`:mf` 通性。

- 日文的读音写在汉字之后的尖括号中：
  `群<ぐん>` 只给“群”一个字注音，`[位相]<いそう>` 给整个词注音。

### 人物条目

人物条目的这一部分显示为“译名”。
以人名的原文为键，用 `lang` 注明原文的语言，再列出各语言的写法：

````markdown
```terms
米田 信夫:
  lang: ja
  en: Nobuo Yoneda
  zh: 米田信夫
```
````
