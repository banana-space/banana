本文介绍页面顶部的提示框，以及页面底部的学科导航、术语翻译的写法。

## 提示

提示框显示在页面标题之下，写在正文的开头，用以下三种标签：

```markdown
<problems>
- “例子”一节需要扩充。
- @prop:main 的证明不完整。
</problems>

<disambiguation>
本条目介绍的是代数拓扑中的上同调。关于层的上同调，请参见[[层上同调]]。
</disambiguation>
```

| 标签 | 用途 | 显示 |
| --- | --- | --- |
| `<problems>` | 页面存在的问题 | “本条目存在以下问题：”（讲义等其他页面中为“本页面”）及其中的内容，通常是问题的列表 |
| `<disambiguation>` | 消歧义与区分 | 其中的文字 |
| `<tip>` | 其他提示 | 其中的文字 |

标签中的内容与正文的写法相同，可以使用数学公式、百科链接和 `@` 引用。

只涉及某一节的问题，也可以把 `<problems>` 写在这一节中，提示框就显示在那里。

### 消歧义与区分

同一个名称有几种含义时，在介绍其中一种含义的条目开头加消歧义的提示，
写明本条目介绍的含义，以及其他含义所在的条目。
例如，在“结合代数”中：

```markdown
<disambiguation>
本条目介绍的是作为代数结构的结合代数。关于它在范畴代数中的推广，请参见[[代数对象]]。
</disambiguation>
```

不必说明本条目介绍的含义时，可以只写“关于其他含义，请参见[[……]]。”

名称相似、容易混淆的条目，也用这个标签：

```markdown
<disambiguation>
注意与[[Auslander–Buchsbaum 公式]]区分。
</disambiguation>
```

## 学科导航

百科页面底部的学科导航框列出相关学科中的主要条目。
在页面信息中写上导航框的名称即可：

```yaml
navboxes: [代数拓扑]
```

一个条目可以带有多个导航框，例如 `navboxes: [代数拓扑, 同伦论]`。

每个导航框是仓库中 `content/navboxes/` 下的一个文件，文件名就是导航框的名称，
例如 `content/navboxes/代数拓扑.yaml`：

```yaml
title: '[[代数拓扑]]'
groups:
  - title: 同调论
    subgroups:
      - title: 同调
        items:
          - '[[奇异同调]]'
          - '[[胞腔同调]]'
      - title: 上同调
        items:
          - '[[奇异上同调]]'
          - '[[de Rham 上同调]]'
  - title: 同伦论
    items:
      - '[[基本群]]'
      - '[[同伦群]]'
```

当然实际的导航框里有更多的链接。

在导航框的文件开头写 `collapsed: true`，导航框默认收起。

## 术语翻译

条目中术语的外文翻译写在 `terms` 代码块中，显示在页面底部。
请不要在正文中用括号标注外文术语。

````markdown
```terms
群:
  en: group
  fr: groupe :m
  de: Gruppe :f
  ja: 群<ぐん>
```
````

- 只列出本条目中定义的术语。
  有自己条目的术语，其翻译写在该条目中。

- 语言用语言代码表示，例如 `en`、`fr`、`de`、`ru`、`ja`、`la`、`grc`。

- 同一语言有几个译名时写成列表：`en: [partially ordered set, poset]`。

- 名词的语法性别写在译名之后，用一个空格隔开：
  `:m` 阳性，`:f` 阴性，`:n` 中性，`:mf` 通性。

- 日文的读音写在汉字之后的尖括号中：
  `群<ぐん>` 只给“群”一个字注音，`[位相]<いそう>` 给整个词注音。

### 人物条目

人物条目的这一部分显示为“译名”。
以人名的原文为键，用 `lang` 注明原文的语言，再列出各语言的写法：

````markdown
```terms
米田 信夫:
  lang: ja
  en: Nobuo Yoneda
  zh: 米田信夫
```
````
