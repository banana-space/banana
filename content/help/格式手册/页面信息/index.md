本文介绍页面开头的页面信息的写法。

## 页面信息

每个页面以两行 `---` 之间的一段信息开头，格式为 [YAML](https://yaml.org)：

```yaml
---
title: 奇异上同调
aliases: [奇异上同调环]
categories: [代数拓扑]
navboxes: [代数拓扑]
---
```

常用的字段如下：

| 字段 | 含义 |
| --- | --- |
| `title` | 标题 |
| `aliases` | 别名 |
| `categories` | 分类 |
| `sort` | 排序用的读音，标题的默认读音不合适时填写 |
| `navboxes` | 页面底部的学科导航框，见 @help:notices |

## 标题

页面标题写在 `title` 中，正文中不要再写一级标题 `# 标题`。

标题中可以写行内公式，例如：

```yaml
title: '$\infty$-范畴'
```

含有 `$`、`:`、`[` 等字符的标题要用单引号括起来，
这是 YAML 的要求。

标题按 @help:style 的规范使用全角标点，例如 `完备化（拓扑学）`。

## 别名

`aliases` 列出条目的其他名称。
指向这些名称的链接都会跳转到本页。例如：

```yaml
title: '$\infty$-范畴'
aliases:
  - 无穷范畴
  - '$\infty$ 范畴'
```

链接匹配时，公式会转成文字再比较，并且不区分全角与半角括号。
因此 `$\mathrm{GL}$` 与 `GL`、
`[[维数(向量空间)]]` 与 `[[维数（向量空间）]]`
都能匹配，不需要另设别名。

## 分类

每个百科条目都必须归入至少一个分类，也可以归入多个分类：

```yaml
categories: [同伦论, 纤维丛论]
```

请使用条目直接所属的（尽量小的）学科分类。

分类之间的关系写在 GitHub 仓库的 `data/categories.yaml` 中，每个分类注明它的上级分类：

```yaml
数学: {}
几何学:
  parent: 数学
代数几何:
  parent: 几何学
'$p$ 进几何':
  parent: 数论
```

需要新的分类时，在这个文件中加上一行，与条目一起提交即可。
没有上级的分类写成 `名称: {}`；名称中有公式时要用单引号括起来。
分类的名称也可以用 `sort` 指定排序读音（参见下节）。

## 排序读音

条目在分类中按标题的读音排序，搜索时也可以用拼音查找。
读音由标题自动生成，汉字转为拼音。
自动的读音不合适时，用 `sort` 指定排序用的读音：

```yaml
title: 行向量
sort: hang xiang liang
```

读音由小写字母和数字组成的词构成，词之间用一个空格分开，拼音不标声调。

西文人物的条目需要指定按姓氏排序的读音：姓在前、名在后，
例如 `Jean-Pierre Serre` 写 `sort: serre jean pierre`。
