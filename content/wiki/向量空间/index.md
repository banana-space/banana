**向量空间**（也称为**线性空间**、**矢量空间**）是一种[[代数结构]]，
是[[线性代数]]的主要研究对象。
我们最熟悉的向量空间包括坐标平面
\[
\mathbb{R}^2 = \{ (x, y) \mid x, y \in \mathbb{R} \},
\]
以及我们所处的三维空间
\[
\mathbb{R}^3 = \{ (x, y, z) \mid x, y, z \in \mathbb{R} \}.
\]
一般地，也有 $\mathbb{R}$ 上的 $n$ 维向量空间
\[
\mathbb{R}^n = \{ (x_1, \dotsc, x_n) \mid x_1, \dotsc, x_n \in \mathbb{R} \}.
\]
向量空间的元素称为[[向量]]。
向量可以相加而得到新的向量，也可以将向量乘以一个数而得到新的向量。
这两种操作刻画了向量空间的代数结构。

除了上述例子外，还可以有无限维的向量空间。
例如，考虑 $\mathbb{R}$ 上的所有实值[[连续函数]]的空间
\[
C (\mathbb{R}) = \{ f \colon \mathbb{R} \to \mathbb{R} \mid f \text{ 连续} \}.
\]
使用线性代数的术语，我们将这样的连续函数称为向量。
在 $C (\mathbb{R})$ 中，连续函数可以相加而得到新的连续函数，
也可以乘一个数而得到新的连续函数。
这两点说明 $C (\mathbb{R})$ 也是向量空间。

## 定义

::: definition [向量空间] {@def:vector-space}
设 $k$ 是[[域]]。
则 $k$-**向量空间**就是 $k$-[[模]]。

具体地说，$k$-向量空间是集合 $V$，带有两种运算
\[
\begin{aligned}
  {+} & \colon V \times V \to V, \\
  {\cdot} & \colon k \times V \to V,
\end{aligned}
\]
分别称为**加法**和**数乘**。
这里，表示数乘的点乘符号常常省略。
我们要求这两种运算满足以下性质：

- $(V, {+})$ 构成 [[Abel 群]]，
  其单位元记为 $0$。
  具体来说，是指加法满足以下性质：

  - 加法满足[[结合律]]：对任意 $x, y, z \in V$，有
    \[
    (x + y) + z = x + (y + z).
    \]

  - 加法满足[[交换律]]：对任意 $x, y \in V$，有
    \[
    x + y = y + x.
    \]

  - 加法具有单位元 $0 \in V$，满足[[单位律]]：对任意 $x \in V$，有
    \[
    0 + x = x.
    \]

  - 对任意 $x \in V$，存在元素 $-x \in V$，使得
    \[
    x + (-x) = 0.
    \]

- 数乘满足[[单位律]]：对任意 $x \in V$，有
  \[
  1 x = x.
  \]

- 数乘对 $V$ 中的加法满足[[分配律]]：
  对任意 $c \in k$ 及 $x, y \in V$，有
  \[
  c (x + y) = c x + c y.
  \]

- 数乘对 $k$ 中的加法满足[[分配律]]：
  对任意 $c, d \in k$ 及 $x \in V$，有
  \[
  (c + d) x = c x + d x.
  \]

- 数乘与 $k$ 中的乘法相容：
  对任意 $c, d \in k$ 及 $x \in V$，有
  \[
  (c d) x = c (d x).
  \]

此时，域 $k$ 的元素通常称为**标量**，
向量空间 $V$ 中的元素通常称为**向量**。
元素 $0 \in V$ 有时称为 $V$ 的**原点**。
:::

::: definition [线性映射] {@def:linear-map}
设 $k$ 是域，设 $V, W$ 是 $k$-向量空间。
[[映射]]
\[
f \colon V \to W
\]
称为 **[[线性映射]]**，如果它是 $k$-[[模]]同态。

具体地说，这意味着

- 对任意 $c \in k$ 和任意 $x \in V$，有
  \[
  f (c x) = c f (x).
  \]

- 对任意 $x, y \in V$，有
  \[
  f (x + y) = f (x) + f (y).
  \]

:::

::: definition [向量空间范畴]
所有向量空间（@def:vector-space）
和它们之间的线性映射（@def:linear-map）
构成[[范畴]]，
称为 $k$-[[向量空间范畴]]，
记为 $\mathsf{Vect}_{k}$。
:::

## 例子

::: example [零向量空间]
设 $k$ 是域。
[[单点集]]可以视为 $k$-向量空间，
称为 **[[零向量空间]]**，记为 $0$。
:::

::: example [域自身]
域 $k$ 可以看成自身上的向量空间，其[[维数 (线性代数)|维数]]为 $1$。
:::

::: example [坐标空间]
设 $k$ 是域，$n$ 是[[自然数]]。
集合 $k^n$ 带有逐个分量的加法和数乘，构成 $n$ 维 $k$-向量空间。

更一般地，设 $I$ 是[[集合]]。
则[[直和（线性代数）|直和]] $\bigoplus_{i \in I} k$ 是 $k$-向量空间，
其[[维数（线性代数）|维数]]等于 $I$ 的[[势]]，可能是无限的。
:::

::: example [多项式空间]
设 $k$ 是域。
一元[[多项式]]的集合 $k[x]$ 是 $k$-向量空间，
单项式 $1, x, x^2, \dotsc$ 构成它的一组基，
因此它是可数无限维的。
次数不超过 $n$ 的多项式构成 $k[x]$ 的 $n + 1$ 维子空间。
:::

::: example [矩阵空间]
设 $k$ 是域，$m$、$n$ 是正整数。
所有 $m \times n$ [[矩阵]]的集合 $\mathrm{M}_{m \times n} (k)$，
带有逐个元素的加法和数乘，构成 $mn$ 维 $k$-向量空间。
:::

::: example [域扩张]
设 $K/k$ 是[[域扩张]]。则 $K$ 可以看作 $k$-向量空间。
例如，[[复数]]域 $\mathbb{C}$ 是 $\mathbb{R}$-向量空间，其维数为 $2$。
:::

::: example [连续函数空间]
设 $X$ 是[[拓扑空间]]。则[[连续函数]]空间
\[
C (X) = \{ f \colon X \to \mathbb{R} \mid f \text{ 连续} \}
\]
是 $\mathbb{R}$ 上的向量空间。
:::

## 性质

### 基

每个 $k$-向量空间中，都能找到一组[[基]]，也就是一组[[向量]]，
例如 $B = \{ e_1, \dotsc, e_n \}$，
使得该向量空间的任意向量 $v$ 都能唯一地写成这些向量的[[线性组合]]：
\[
v = a_1 e_1 + \cdots + a_n e_n ,
\]
其中 $a_i \in k$ 是标量。
这样，选定一组基，就能用这组数 $a_1, \dotsc, a_n$ 来代表向量 $v$，有时记为
\[
v = \begin{pmatrix}
  a_1 \\ \vdots \\ a_n
\end{pmatrix} .
\]
由此，通过一组基，就能把向量空间的几乎所有操作化为数的运算。

[[基存在定理]]表明，每个向量空间都有基。
同一个向量空间的所有基都具有同样多的向量，
这一数目称为该向量空间的[[维数 (线性代数)|维数]]。

从[[模]]的角度看，向量空间是由一组基生成的[[自由模]]，
从而基存在定理表明域上的模都是自由模。

### 维数与同构

::: proposition [按维数分类]
设 $k$ 是域，$V$、$W$ 是 $k$-向量空间。
则 $V \simeq W$ 当且仅当 $\dim V = \dim W$。
:::

::: proof
“$\Rightarrow$” 是显然的。
对 “$\Leftarrow$”，只需取 $V$、$W$ 的基，
而由假设，这两组基之间存在[[双射]]，
该双射及其逆映射可延拓为 $V$、$W$ 间互逆的线性映射。
:::

特别地，给定[[自然数]] $n$，每个 $n$ 维 $k$-向量空间都同构于 $k^n$，
但同构的选取依赖于基的选取。
