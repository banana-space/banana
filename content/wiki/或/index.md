在[[逻辑学]]中，
**或**是[[逻辑连接词]]的一种，常记为 $\vee$。

在经典的[[命题逻辑]]中，对[[命题]] $p$、$q$ 而言，
命题 $p \vee q$（读作“$p$ 或 $q$”）是指 $p$、$q$ 其中之一成立。
换言之，有以下的[[真值]]表：

| $p$ | $q$ | $p \vee q$ |
| :-: | :-: | :-: |
| 真 | 真 | 真 |
| 真 | 假 | 真 |
| 假 | 真 | 真 |
| 假 | 假 | 假 |

在[[类型论–范畴论–逻辑学类比]]下，
或运算对应于[[无交并类型]]、[[无交并空间]]等运算。
大致而言，说两个类型或空间的无交并非空，
即是说原来两个类型或空间之一非空。
