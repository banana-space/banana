在[[等离子体物理]]中，**等离子体**是由大量自由的[[电子]]与[[离子]]组成、
整体上呈电中性的物质，也称为**电浆**。
把[[气体]]加热到足够高的温度，原子中的电子会挣脱[[原子核]]的束缚，
气体就变成了等离子体。
因此，人们常把等离子体称为继[[固体]]、[[液体]]、[[气体]]之后物质的第四态。

大致来说，等离子体是带电的气体。
普通气体中的分子只在相互碰撞时才发生作用，
而等离子体中的带电粒子通过长程的 [[Coulomb 力]]与 [[Lorentz 力]]，
同时与远处的大量粒子相互作用，因而表现出[[集体行为]]。
例如，等离子体中的一个电荷会吸引周围的异号电荷，被它们屏蔽，
因此其电场只能作用到很短的距离；
等离子体中的电子还可以相对离子整体地振荡。

在大尺度上，等离子体可以像导电的流体一样，用[[磁流体力学]]描述；
在较小的尺度上，或者粒子间的碰撞很少时，
则需要用[[动理学]]描述粒子的[[速度分布函数]]。

宇宙中绝大部分普通物质都处于等离子体态，
例如[[恒星]]内部、[[太阳风]]与[[星际介质]]；
实验室中的[[托卡马克]]、放电管与激光等离子体也是等离子体。

## 概念

本条目采用[[国际单位制]]。

普通气体变为等离子体是渐进的，并没有截然的分界线。
判断一团电离的气体能否视为等离子体时，关键是比较它的尺度与静电屏蔽的尺度。
等离子体中的一个电荷会吸引异号电荷、排斥同号电荷，于是被一团电荷云包围；
从远处看，这团电荷云抵消了它的电场。
这一屏蔽效应的特征尺度如下。

::: definition [Debye 长度]
设等离子体的电子数密度为 $n_\mathrm{e}$、电子[[温度]]为 $T_\mathrm{e}$，
则其 **Debye 长度**定义为
\[
\lambda_\mathrm{D} = \sqrt{\frac{\varepsilon_0 k_\mathrm{B} T_\mathrm{e}}{n_\mathrm{e} e^2}} ,
\]
其中 $\varepsilon_0$ 为[[真空介电常数]]，$k_\mathrm{B}$ 为 [[Boltzmann 常数]]，
$e$ 为[[元电荷]]。
:::

在等离子体中，点电荷 $q$ 的电势近似为
\[
\varphi (r) = \frac{q}{4 \pi \varepsilon_0 r} \, \mathrm{e}^{-r / \lambda_\mathrm{D}} ,
\]
即其电场在 Debye 长度之外迅速衰减。

::: definition (概念) [等离子体]
包含大量自由[[电子]]与[[离子]]的系统称为**等离子体**，通常是指它满足以下三个条件：

- **宏观准中性**：系统的尺度 $L$ 远大于 Debye 长度，即 $L \gg \lambda_\mathrm{D}$。
  这样，屏蔽只在系统内部的小范围内发生，系统在宏观上呈[[准中性]]。

- **集体行为主导**：以 Debye 长度为半径的球内的粒子数远大于 $1$，即
  $N_\mathrm{D} = (4 \pi / 3) \, n_\mathrm{e} \lambda_\mathrm{D}^3 \gg 1$。
  否则，粒子周围没有足够多的电荷来屏蔽它，上述屏蔽的图像不再成立。

- **电磁力主导运动**：电子集体振荡的频率，即下文的等离子体频率 $\omega_\mathrm{pe}$，
  远高于粒子的[[碰撞频率]] $\nu$，即 $\omega_\mathrm{pe} \gg \nu$。
  否则，粒子的运动主要由碰撞而非电磁力决定，其行为与普通气体相近。
:::

## 基本参数

等离子体中的现象发生在不同的时间与空间尺度上。
除 Debye 长度外，最基本的几个尺度是电子振荡的频率、
带电粒子在磁场中回旋的频率与半径，以及衡量磁场相对重要性的热压与磁压之比。

若等离子体中的电子整体相对离子偏移一小段距离，
由此产生的电场会把电子拉回，使电子在平衡位置附近振荡。
这种振荡的频率如下。

::: definition [等离子体频率]
设等离子体的电子数密度为 $n_\mathrm{e}$，电子质量为 $m_\mathrm{e}$，
则其电子**等离子体频率**为
\[
\omega_\mathrm{pe} = \sqrt{\frac{n_\mathrm{e} e^2}{\varepsilon_0 m_\mathrm{e}}} .
\]
:::

在磁场中，[[Lorentz 力]]使带电粒子绕磁力线做螺旋运动：
在垂直于磁场的平面内，粒子做圆周运动，且电子与正离子的旋转方向相反。

::: definition [回旋频率与回旋半径]
在[[磁感应强度]]为 $B$ 的磁场中，设第 $s$ 种粒子的电荷为 $q_s$、质量为 $m_s$，
则其**回旋频率**为
\[
\Omega_s = \frac{q_s B}{m_s} ,
\]
其正负号反映了旋转的方向。
垂直于磁场的速度大小为 $v_\perp$ 的粒子，其**回旋半径**（又称为 **Larmor 半径**）为
\[
r_{\mathrm{L}, s} = \frac{v_\perp}{\lvert \Omega_s \rvert} .
\]
:::

磁场对等离子体的作用可以用**磁压**，即磁场的能量密度 $p_B = B^2 / (2 \mu_0)$ 衡量，
其中 $\mu_0$ 为[[真空磁导率]]。
将它与等离子体的热压相比较，就得到下面的参数。

::: definition [等离子体 $\beta$]
设等离子体中第 $s$ 种粒子的数密度为 $n_s$、温度为 $T_s$，
则等离子体的总热压为 $p = \sum_s n_s k_\mathrm{B} T_s$。
它与磁压之比
\[
\beta = \frac{p}{p_B} = \frac{2 \mu_0 \sum_s n_s k_\mathrm{B} T_s}{B^2}
\]
称为**等离子体 $\beta$**。
:::

当 $\beta \ll 1$ 时，称为**低 $\beta$ 等离子体**，
此时磁压远大于热压，磁场在动力学中占主导地位；
当 $\beta \gg 1$ 时，称为**高 $\beta$ 等离子体**，此时热压占主导。

## 例子

::: example [太阳风]
在地球轨道附近，即距离太阳约 $1 \, \mathrm{au}$ 处，
[[太阳风]]的电子数密度约为 $5 \, \mathrm{cm}^{-3}$，[[温度]]约为 $10^5 \, \mathrm{K}$，
对应的 Debye 长度约为 $10 \, \mathrm{m}$，远小于 $1 \, \mathrm{au}$ 这一系统尺度，
因此满足宏观准中性条件。

由于太阳风极为稀薄，粒子间 Coulomb 碰撞的[[平均自由程]]可达 $1 \, \mathrm{au}$ 量级，
粒子间的碰撞几乎可以忽略。
这样的等离子体称为**无碰撞等离子体**。
在太阳风中，[[波]]的[[阻尼]]与[[不稳定性]]等集体电磁过程取代了碰撞，
主导了太阳风的加热与加速。
:::

::: example [托卡马克]
[[托卡马克]]是典型的[[磁约束聚变]]装置。
其芯部等离子体的数密度约为 $10^{20} \, \mathrm{m}^{-3}$，
[[温度]]可达 $10^8 \, \mathrm{K}$，相当于约 $10 \, \mathrm{keV}$，
对应的 Debye 长度约为 $10^{-4} \, \mathrm{m}$，远小于装置米量级的尺度。

托卡马克通常用数特斯拉的强磁场约束等离子体，
此时离子的回旋半径仅为毫米量级。
其等离子体 $\beta$ 通常只有 $1\%$–$5\%$，即处于低 $\beta$ 状态，
磁场主导其宏观平衡与稳定性。
:::
