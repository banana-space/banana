在[[等离子体物理]]中，**等离子体**（又称**电浆**）是一种由大量自由[[电子]]与[[离子]]（常伴有中性粒子）组成的宏观[[准中性]]物质形态，
也是物质继[[固体]]、[[液体]]、[[气体]]之后的第四态。

与由短程碰撞主导的普通气体不同，等离子体内部粒子由长程[[电磁力]]（[[库仑力]]与[[洛伦兹力]]）主导，
单个粒子可同时与大量远处的粒子发生相互作用，从而表现出显著的[[集体行为]]。

正因如此，等离子体既表现出类似流体的集体模式，
在微观或无碰撞尺度下又需要借助[[动理学]]描述其[[速度分布函数]]的非平衡结构。


宇宙中绝大部分普通物质处于等离子体态， 例如[[恒星]]内部、[[太阳风]]与[[星际介质]]；
实验室中的[[托卡马克]]、放电管与激光等离子体也属于此列。

## 定义

除非另有说明，本词条均采用[[国际单位制]]。

普通气体变为等离子体是渐进的，并没有一条截然的分界线。
在讨论等离子体的判据之前，需要先引入静电屏蔽的特征尺度**Debye长度**。

::: definition [Debye长度]
设电子数密度为 $n_e$、电子温度为 $T_e$，则**Debye长度**定义为
\[
\lambda_D = \sqrt{\frac{\epsilon_0 k_B T_e}{n_e e^2}} .
\]
其中 $\epsilon_0$ 为[[真空介电常数]]，$k_B$ 为[[玻尔兹曼常数]]，$e$ 为[[元电荷]]。
它表示等离子体中单个电荷的静电场能够作用的特征距离。
:::

在此基础上，一个包含大量自由[[电子]]与[[离子]]的系统要被称为**等离子体**，通常需要满足以下三个条件：

- **宏观准中性**：系统的[[特征尺度]]$L$远大于Debye长度，即$L \gg \lambda_D$。
  
- **集体行为主导**：Debye球内的粒子数远大于1，即$N_D = \frac{4\pi}{3} n_e \lambda_D^3 \gg 1$。
  
- **电磁力主导运动**：
  电子集体振荡的频率（即**等离子体频率**）$\omega_{pe}$远高于粒子的[[碰撞频率]]$\nu$，
  即$\omega_{pe} \tau \gg 1$，$\tau = 1/\nu$.

## 基本参数

除**Debye长度**外，描述等离子体还有几个基本量。

::: definition [等离子体频率]
电子**等离子体频率**为
\[
\omega_{pe} = \sqrt{\frac{n_e e^2}{\epsilon_0 m_e}},
\]
其中$m_e$为电子质量。它是电子相对离子背景发生集体振荡的固有频率。
:::

::: definition [回旋频率与回旋半径]
在磁感应强度为$B$的磁场中，洛伦兹力使带电粒子绕磁力线做螺旋运动（在垂直于磁场的平面内做圆周运动，
且电子和正离子的旋转运动相反）。
对于种类为$s$、电荷为$q_s$，质量为$m_s$的粒子，其**回旋频率**为
\[
\Omega_s = \frac{q_s B}{m_s},
\]
**回旋半径**（又称**拉莫尔半径**）为
\[
r_{L, s} = \frac{v_\perp}{\lvert \Omega_s \rvert},
\]
其中$v_\perp$为粒子垂直于磁场方向的速度大小。
:::

::: definition [等离子体$\beta$]
等离子体$\beta$是总热压$p = \sum_s n_s k_B T_s$与**磁压**$p_B = B^2 / (2\mu_0)$ 之比
\[
\beta = \frac{p}{p_B} = \frac{2 \mu_0 \sum_s n_s k_B T_s}{B^2} ，
\]
其中 $\mu_0$ 为真空磁导率。
当 $\beta \ll 1$（**低 $\beta$ 等离子体**）时，磁压远大于热压，磁场在动力学中占主导地位；
当 $\beta \gg 1$（**高 $\beta$ 等离子体**）时，热压则占主导。
:::



## 例子

::: example [太阳风]
在地球轨道（$1\,\mathrm{au}$）附近，[[太阳风]]的电子数密度约为 $5\,\mathrm{cm^{-3}}$，
[[温度]]约为 $10^5\,\mathrm{K}$，对应的Debye长度约为 $10\,\mathrm{m}$，
远小于 $1\,\mathrm{AU}$ 的系统特征尺度，满足宏观准中性条件。

此外，由于太阳风极为稀薄，粒子库仑碰撞的[[平均自由程]]可达 $1\,\mathrm{au}$ 量级，
因此它是一种典型的**无碰撞等离子体**——粒子间的二体碰撞几乎可以忽略，
[[波]]的[[阻尼]]与[[不稳定性]]等集体电磁过程主导了太阳风的加热与加速。
:::


::: example [托卡马克]
作为典型的[[磁约束聚变]]装置，[[托卡马克]]芯部等离子体的数密度约为 $10^{20}\,\mathrm{m^{-3}}$，
[[温度]]可达 $10^8\,\mathrm{K}$（约 $10\,\mathrm{keV}$），
对应的Debye长度约为 $10^{-4}\,\mathrm{m}$，
远小于装置米（$\mathrm{m}$）量级的尺度。

此外，托卡马克通常采用数特斯拉（$\mathrm{T}$）的强磁场约束等离子体，
离子回旋半径仅为毫米（$\mathrm{mm}$）量级，且通常处于低 $\beta$（$\beta \sim 1\%$–$5\%$）状态，
磁场主导其宏观平衡与稳定性。
:::
