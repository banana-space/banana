**等价关系**是[[集合]]上[[自反关系|自反]]、[[对称关系|对称]]且[[传递关系|传递]]的二元[[关系]]。

等价关系是描述集合中元素“相似性”的一种方式。
例如，“相等”是最强的相似性，故而相等是等价关系。
[[整数]]的[[同余]]也是某种相似性，也是等价关系。
又例如，[[Euclid 平面]]中[[直线]]的[[平行线|平行]]关系也是等价关系。

等价关系常用符号\(\sim\)或\(\equiv\)表示。

## 定义

### 等价关系

::: definition [等价关系]
我们称[[集合]] $X$ 上二元[[关系]]\(\sim\)
是**等价关系**，如果其满足下列性质：

- （**[[自反关系|自反性]]**）对任意 \(x \in X\)，有 \(x \sim x\)。

- （**[[对称关系|对称性]]**）对任意 \(x, y \in X\)，
  若 \(x \sim y\)，则\(y \sim x\)。

- （**[[传递关系|传递性]]**）对任意\(x, y, z \in X\)，
  若 \(x \sim y\) 且 \(y \sim z\)，则 \(x \sim z\)。

:::

::: definition [等价类]
给定集合 $X$ 上等价关系\(\sim\)。
对任意\(x \in X\)，称\(X\)的[[子集]]
\[
[x] = \{ y \in X \mid x \sim y\}
\]
为\(x\)在\(\sim\)下的**等价类**。
此时，集合\(X\)是所有等价类的[[无交并]]。
:::

::: definition [商集]
给定集合 $X$ 上等价关系\(\sim\)，**[[商集]]**
$X / {\sim}$ 是所有等价类的集合：
\[
X / {\sim} = \{ [x] \mid x \in X \}.
\]
:::

这样，有自然的[[满射]] $X \to X / {\sim}$，
将每个元素 $x$ 映到其等价类 $[x]$。

### 生成等价关系

对[[集合]] $X$ 上的任意二元[[关系]]，
都能定义它生成的等价关系，即[[包含]]它的最小等价关系。

::: definition
设 $\approx$ 是[[集合]] $X$ 上的二元[[关系]]。
则 $\approx$ 的**生成等价关系**是 $X$ 上的等价关系 $\sim$，定义如下：

- 若 $x, y \in X$，则 $x \sim y$ 当且仅当存在[[自然数]] $n$
  和元素 $x_0, \dotsc, x_n \in X$，
  使得 $x_0 = x$，$x_n = y$，且对任意 $i \in \{ 0, \dotsc, n-1 \}$，
  都有 $x_i \approx x_{i+1}$ 或 $x_{i+1} \approx x_i$。

:::

## 例子

- 集合\(X\)上的“相等”关系是等价关系，
  其等价类是所有单点子集。

- 对任意[[整数]]\(n \geq 1\)，
  “模\(n\)[[同余]]”是整数集\(\mathbb{Z}\)上的等价关系。

- [[平行线|平行]]关系是[[Euclid 空间|Euclid 平面]]中[[直线]]间的等价关系。

- 一般地，对集合间的[[映射（集合论）|映射]]\(f\colon X \rightarrow T\)，
  “被\(f\)映到同一元素”是\(X\)上的等价关系，
  其等价类为\(T\)中单点子集的[[原像]]。事实上，
  所有等价关系都能如此描述。
