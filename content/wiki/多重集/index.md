**多重集**就是允许重复元素的[[集合]]。

这样的话，$\set{1, 2, 1}$ 和 $\set{1, 2}$ 就是不同的多重集，
但 $\set{1, 2, 1}$ 和 $\set{1, 1, 2}$ 是同一个多重集。

## 定义

::: definition
**多重集**是二元组 $(X, μ_X)$，其中：

- $X$ 是[[集合]]，

- $μ_X$ 是从 $X$ 到[[基数]]的[[映射]]。对于元素 $x ∈ X$，
  $μ_X(x)$ 是它的**重数**。

:::

::: definition
多重集 $(X, μ_X)$ 的[[势]]为所有元素的重数之和。
:::

在可数或者有限的情况下，多重集有如下的等价定义：

::: definition
设 $X$ 是集合。**多重集**是 $X$ 上的[[序列]][[商集|商]]掉如下关系生成的[[等价关系]]：

\[
(x_1, x_2, x_3, \cdots) \sim (x_2, x_1, x_3, \cdots)
\]

若该序列有限，则对应的多重集有限，
若该序列可数，则对应的多重集可数。
:::

## 常用操作

- 多重集 $(X, μ_X), (Y, μ_Y)$ 的[[交集]]为：
  \[
  \left(X \cap Y, x \mapsto \min(μ_X(x), μ_Y(x)) \right)
  \]

- 多重集 $(X, μ_X), (Y, μ_Y)$ 的[[并集]]为：
  \[
  \left(X \cup Y, x \mapsto \max(μ_X(x), μ_Y(x)) \right)
  \]

- 多重集 $(X, μ_X), (Y, μ_Y)$ 的[[不交并]]为：
  \[
  \left(X \cup Y, x \mapsto μ_X(x) + μ_Y(x) \right)
  \]

- 多重集 $(X, μ_X), (Y, μ_Y)$ 的[[积]]为：
  \[
  \left(X \cap Y, x \mapsto μ_X(x) × μ_Y(x) \right)
  \]

::: definition
设 $(<) \subset X × X$ 为集合 $X$ 上的严格[[偏序]]（即不满足[[自反性]]）。
定义 $<$ 的**多重集扩展**，记作 $<_μ$，为多重集之间的二元关系，
且 $(X, μ_X) <_μ (X, μ_X')$ 需要满足如下条件：

- $μ_X ≠ μ_X'$，

- 对于任意 $x ∈ X$，如果 $μ_X'(x) < μ_X(x)$，那么必须存在 $y ∈ X$ 使得 $μ_X(y) < μ_X'(y)$。

该关系又叫做 $<$ 的**Dershowitz–Manna 序**。
:::

如上关系可以这样直观地理解：$M' <_μ M$ 的意思就是可以通过将 $M$
中的部分元素替换为有限数量个更小的元素来得到 $M'$。

::: theorem
若 $<$ 是[[良基关系]]，那么它的多重集扩展也是良基关系。
:::
