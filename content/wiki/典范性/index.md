**典范性**是[[类型论]]的一种性质，指空[[语境]]下的表达式都是由[[构造规则]]生成的。

这往往是在说类型论中所有“函数应用”都可以被消除，因为函数应用是一种[[消去规则]]。
比如，有公理的类型论就不满足典范性，因为公理往往被视为一种函数，而这些函数无法进一步展开。

典范性可以认为是空语境中的[[正规性 (类型论)|正规性]]加上对[[正规形式 (类型论)|正规形式]]的形式要求。

一些观点认为，满足典范性的类型论就可以被称为编程语言。

## 定义

::: definition
在类型论中，完全由构造规则导出的表达式叫做**典范形式**，或者说这个表达式是**典范**的。
:::

注意该定义并不局限于空语境。

### 类型论

::: definition {@强定义}
若在某类型论的空[[语境]]中，任何类型的值均有典范形式
（或者说，任何值均等价于一个典范形式），
那么这个类型论满足**典范性**。
:::

::: definition {@弱定义}
若在某类型论的空[[语境]]中，任何类型的值的正规形式也是典范形式，
那么这个类型论满足**典范性**。
:::

注意，@弱定义 没有假设值的典范形式的存在性，
仅讨论它们存在的情况下应该满足的性质。
而 @强定义 要求了正规形式必须存在，且满足这些性质。

::: definition {@弱智定义}
考虑一个有[[自然数类型]]的类型论。
如果在空语境中，$\mathbb{N}$ 类型的值均由 $0$ 和 $s$ 生成，
那么这个类型论满足**典范性**。
:::

### 立方类型论

::: definition {@立方定义}
考虑一个[[立方类型论]]。
如果在仅包含 $\mathbb{I}$ 类型的[[语境]]中，任何类型的值的正规形式都是典范形式，
那么这个类型论满足**立方典范性**。
:::

::: remark
类似 @弱定义，我们可以给出 @立方定义 的弱化版本。
:::

## 性质

::: lemma
典范性蕴涵逻辑[[一致性 (类型论)|一致性]]。
:::

::: proof
如果类型论不一致，那么存在值 $u$ 使得 $\vdash u:\varnothing$，
而[[空类型]]没有构造规则，引起矛盾。
:::
