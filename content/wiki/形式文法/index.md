在[[计算机科学]]中，**形式文法**是一种通过规则描述[[语言]]的方法。
例如，[[2 进制]][[自然数]]可以用如下规则描述：

\[
\begin{aligned}
  S &::= D~S \mid D\\
  D &::= 0 \mid 1
\end{aligned}
\]

在不加特殊说明的情况下，第一条规则是开始的规则，例如上面的规则中便是 $S$，
紧接着是关于“$S$ 规则能匹配哪些符号”的说明，竖线表示“或者”，
$D~S$ 表示“先使用 $D$ 匹配些什么，再接着用 $S$ 匹配”。

例如字符串 $010$ 可以通过如下方式匹配：

\[
S → D~S → 0~S → 0~D~S → 0~1~S → 0~1~D → 0~1~0
\]

首先，将 $S$ 展开为 $D~S$ 以便进一步展开 $D$ 并匹配第一个 $0$，
然后继续展开 $S$，以此类推。

最常见的形式文法是语境无关文法。

## 定义

::: definition [语言]
令 $V$ 为[[有限集]]，称为**字母表**，里面的元素叫做**终结符号**。
一个 **[[语言]]** 就是 $V$ 上的自由[[幺半群]] $V^*$ 的子集。
:::

### 语境无关文法

::: definition [规则]
对于字母表 $V$ 和一组表示变量名的集合 $X$（里面的元素称为非终结符号），
**规则**包含如下信息：

- 它本身的名字，使用变量名 $S ∈ X$ 表示，

- 它的内容，为该规则某种可能的展开方式。
  每一种展开方式就是一组终结或非终结符号，
  因此这个整体就是 $(X + V)^*$ 中的元素，其中 $X+V$ 是两集合的[[并集]]。

给定两种符号的集合，它们能写出的所有规则的集合为 $X × (X + V)^*$。
:::

终结符号之所以终结是因为它们不像非终结符号一样可以使用规则进一步展开，
它们直接匹配字符。

::: remark
同一个变量名可以对应多个规则，在描述时使用 $\mid$ 合并。
例如，$S ::= αβψ \mid δεφ$ 就对应了两条规则：

- $S$ 可以展开为 $αβψ$，
- $S$ 可以展开为 $δεφ$。

:::

::: definition [语境无关文法]
**语境无关文法**为四元组 $(V, X, R, s)$，其中：

- $V$ 和 $X$ 分别是字母表和变量名的集合，

- $s∈X$ 是开始的规则名，

- $R \subset X × (X + V)^*$ 是规则。

语境无关文法对应的语言 $L(V, X, R, s)$ 构造如下：

首先定义**重写关系** $(→_R) \subseteq (X + V)^* × (X + V)^*$：
令 $α, β ∈ (X + V)^*$ 且 $ (s, w)∈R $，那么有 $(α s β) →_R (α w β)$ 成立。

取由该关系构成的[[重写系统]]的自反传递闭包 $→_R^*$，这便是按规则所有可能的展开方式。

最后定义语言为：
\[
L(V, X, R, s) := \Set{
  w₁w₂ \dots w_k ∈ V^* | s →_R^* w₁w₂ \dots w_k
}
\]
:::

[[下推自动机]]可以执行语境无关文法的匹配。

### 无限制文法

::: definition {@def:unres-rule}
对于字母表 $V$ 和一组表示变量名的集合 $X$（里面的元素称为非终结符号），
**规则**表示一种重写关系。

一组终结或非终结符号可以看作 $(X + V)^*$ 中的元素，
其中 $X+V$ 是两集合的[[并集]]。
重写关系便是这样的元素上的关系。

给定两种符号的集合，它们能写出的所有规则的集合为 $(X + V)^+ × (X + V)^*$，
其中 $(X + V)^+$ 是 $(X + V)^*$ 的非空子集。
:::

::: definition [无限制文法]
**无限制文法**将语境无关文法中的规则改为 @def:unres-rule 中的规则，
其余内容不变。
:::

[[Turing 机]]可以执行语境无关文法的匹配。

## 应用

- [[类型论]]的句法一般使用语境无关文法描述，例如[[简单类型 $λ$ 演算]]、[[Martin-Löf 类型论]]。

```terms
形式文法:
  en: formal grammar
终结符:
  en: terminal symbol
语境无关文法:
  en: context free grammar (CFG)
无限制文法:
  en: unrestricted grammar
```
