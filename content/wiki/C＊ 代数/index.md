**$C^*$-代数**是一类重要的算子代数。笼统地说，
它们可以看作是某个Hilbert空间$H$上有界线性算子全体$B(H)$的$*$-子代数。

## 定义

::: definition
一个 $C^*-$代数是一个 [[Banach 代数]] $A$ 与 $A$ 上的一个映射 $*:A\to A$，
$a\mapsto a^*$ 构成的有序对。
其中映射$*$满足如下性质：（以下 $a,b\in A,\lambda\in\mathbb{C}$）

- $(a^*)^*=a$。

- $(ab)^*=b^*a^*$。

- $(a+b)^*=a^*+b^*$。

- $(\lambda a)^*=\bar{\lambda}a^*$。

- $\| a^*a\|=\| a\| ^2$。

:::

::: remark
注意，不同于本百科对于代数的定义，在算子代数的讨论中，我们默认$C^∗$-代数不总是含幺的。
尽管我们总是可以对一个不含幺的$C^*$-代数进行[[单位化]]或者考虑其上的[[乘子代数]]，
但它们与原代数有着本质性的不同。
:::

::: remark
- 在$C^*-$代数 $A$ 中，对任意 $a\in A$，均成立 $\|   a \|=\|  a^*  \|$。这是因为
  $\|  a  \|\cdot \|   a^* \|\ge  \| a^*a\|=\| a   \|^2$。
  故 $\| a^*   \|\ge \|   a \|$。
  在上式中以 $a^*$ 替换 $a$ 又可以得到 $\|  a  \|\ge \|  a^*  \|$。

- 由 $(a^*)^*=a$ 可知 $*$ 为双射，且其逆映射就是自己。

:::

::: example {@eg:C-X}
对于紧 Hausdorff 空间$X$，考虑 $X$ 上全体连续复值函数 $C(X)$。
$C(X)$ 关于逐点相加、逐点相乘、逐点数乘与范数 $\|f\|:=\max\{|f(x)|: x\in X\}$ 构成一个 Banach 代数。
定义 $f^*(x):=\overline{f(x)}$ 后，$C(X)$ 成为一个有幺元的 $C^*$-代数，
幺元是 $f(x)\equiv 1$（$\forall x\in X$）。
:::

::: remark
1. 在 @eg:C-X 中取 $X=\{1,2\}$ 与离散拓扑。
   则 $\chi_{\{1\}}\cdot \chi_{\{2\}}=0$（其中 $\chi_E$ 为 $E$ 的示性函数）。
   这说明 $C^*-$代数作为环不一定是无零因子的。

2. 仍取 $X=\{1,2\}$ 与离散拓扑。
   则 $C(X)$ 的子集 $\{f\in C(X): f(2)=0\}$ 本身也成一个 $C^*-$代数，
   且幺元是 $\chi_{\{1\}}$。
   这说明一个含幺 $C^*-$代数 $A$ 的子 $C^*-$代数 $B$ 如果也是含幺的$C^*-$代数，
   那么 $A, B$ 的幺元不一定相等。
   $A$ 的子 $C^*-$代数 $B\ne A$含幺且 $A, B$ 幺元相等的例子有
   $A=C(X)$（$X$ 如上），$B=\{f\in C(X): f(1)=f(2)\}$。

:::

::: definition
称$A$中元素$a$是**自伴的**，若$a^*=a$；

称$a$是**正规的**，若$a^*a=aa^*$；

称正规元$a$是**正的**，如果$a$的谱$\sigma(a)\subset [0,\infty]$。

对于$A$中自伴元$a$和$b$，若$b-a$是正的，则记$b\ge a$或$a\le b$。
这给出了$C^*$代数自伴元上的一个[[序结构]]。
:::

## 基本性质

::: theorem [Gelfand–Naimark 定理]
交换的含幺$C^*$代数$A$同构于$A$极大理想空间上全体连续函数。
:::

::: corollary
交换$C^*$代数同构于某个局部紧Hausdorff空间$X$上在无穷远处消失的全体连续函数$C_0(X)$。
:::

::: theorem [Gelfand–Naimark–Segal]
任何$C^*$代数均同构于某个Hilbert空间$H$上有界线性算子全体$B(H)$的$*$-子代数。
:::

::: remark
特别地，对于可分$C^*$-代数可以要求$H$是可分的；当$A$作为$\mathbb{C}$线性空间仅有有限维时，
$A$是矩阵代数的（有限）直和。
:::

下面近似单位的存在性给出合理化了对于不含幺$C^*$-代数的讨论。

::: theorem [近似单位]
$C^*$-代数$A$上存在如下近似单位，即$A$中[[网]]$\{e_j\}_{j\in J}$满足如下条件：

(a) $e_j$是正的且$\|e_j\|\le 1$，对于任意$j\in J$。

(b) 映射$j\mapsto e_j$是保序的。

(c) $\lim_j{e_ja-a} = \lim_j{ae_j-a} = 0$，对于任意$a\in A$。
:::

::: remark
类似地，对于可分$C^*$-代数，我们可以取出一列近似单位。
:::
