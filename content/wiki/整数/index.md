**整数**是指[[自然数]]或者自然数的[[相反数]]。
全体整数构成的[[集合]]记为
\[
\mathbb{Z} = \set{ \dotsc, -3, -2, -1, 0, 1, 2, 3, \dotsc }.
\]
记号 $\mathbb{Z}$ 来自于德语 <lang de>Zahlen</lang>（数）。

## 定义

::: definition
全体**整数**构成的集合是
\[
\mathbb{Z} = \set{ n, -n | n ∈ \mathbb{N}, ~ 0 = -0 },
\]
其中 $\mathbb{N}$ 是所有[[自然数]]的集合。
:::

我们熟知整数的[[加法]]、[[乘法]]。
这两种[[运算]]赋予整数的集合 $\mathbb{Z}$ 一个[[交换环]]的结构。

::: remark
等价地说，$\mathbb{Z}$ 是[[幺半群]] $(\mathbb{N}, +)$
的[[群化]]。
:::

## 性质

::: proposition
整数的加法[[群]] $(\mathbb{Z}, +)$ 是一个生成元生成的[[自由群]]。
:::

::: proposition
在[[同构]]的意义下，整数的加法[[群]] $(\mathbb{Z}, +)$ 是唯一一个无穷[[阶]]的[[循环群]]。
:::

::: proposition
整数环是[[环]][[范畴]]的[[始对象]]。
:::
