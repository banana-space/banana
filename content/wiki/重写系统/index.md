**重写**是一种将表达式的一部分替换为其它表达式的过程，可以看作一种关系或者一组规则。
在此之上，**重写系统**或**抽象重写系统**就可以看作是由一个表达式的[[集合]]和表达式到表达式之间的**重写关系**组成的结构，
以及类似的推广结构。

重写系统可以看作[[箭图]]或者[[有向图]]，以表达式为顶点，重写关系为边。
从[[范畴论]]的视角看，计算规则也可以看作一种重写。

## 记号

令表达式的集合为 $E$，重写关系为 $(→)\subset E × E$（这里意思是说 $→$ 是一个二元关系）。

::: definition [自反传递闭包] {@def:rtc}
记 $→^*$ 为“将 $→$ 应用任意[[自然数]]次”的关系。换言之，

- **（自反性）** $→^*$ 是一个[[自反关系]]。
- 对于 $a, b ∈ E$，若 $a → b$ 那么 $a →^* b$。
- **（传递性）** 对于 $a, b, c ∈ E$，若 $a → b$ 且 $b →^* c$ 那么 $a →^* c$。

:::

::: definition [对称传递闭包]
对于 $a, b ∈ E$，
若 $a →^* b$ 或者 $b →^* a$ 则 $a \leftrightarrow^* b$ 为 $→^*$。
这对应 @def:rtc 的[[对称性|对称]]版本。
:::

::: lemma
$\leftrightarrow^*$ 是一个等价关系。
:::

## 性质

### 正规性

<see>[[正规性 (重写系统)]]</see>

::: definition [正规形式]
对于重写系统 $E$ 和 $a, b ∈ E$，
若 $a→^* b$ 当且仅当 $a=b$，那么 $a$ 是一个**正规形式**。
:::

### 合流性

<see>[[合流性]]</see>

::: definition [合流性]
若对于重写系统 $E$ 和任意 $a,b,c∈E$ 有 $b←^*a→^*c$，都存在 $d$ 使得 $b→^*d←^*c$，
那么 $E$ 是**合流**的。
:::

## 例子

- 由[[整数]]和加减乘法作为[[生成元]]的表达式集合，配上运算化简（例如 $1+1 → 2$），构成一个重写系统。
- 各种[[$λ$ 演算]]的变体都可以被视为一种重写系统。
