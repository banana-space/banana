在[[逻辑学]]中，
**非**是[[逻辑连接词]]的一种，常记为 $\neg$。
对[[命题]] $p$ 而言，命题 $\neg p$ 也称为 $p$ 的**否定**或**否命题**。

在经典的[[命题逻辑]]中，对[[命题]] $p$ 而言，
命题 $\neg p$（读作“非 $p$”）成立是指 $p$ 不成立。
有以下的[[真值]]表：

| $p$ | $\neg p$ |
| :-: | :-: |
| 真 | 假 |
| 假 | 真 |

在[[类型论–范畴论–逻辑学类比]]下，
非运算对应于某类型到[[空类型]]的[[映射类型]]，
或某空间到[[空空间]]的[[映射空间]]。

```terms
非:
  en: [negation, not]
  fr: [négation :f, non]
  de: [Negation :f, nicht]
```
