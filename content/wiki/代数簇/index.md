**代数簇**（简称**簇**）是[[代数几何]]的主要研究对象之一。
正如[[流形]]由 [[Euclid 空间]]沿[[光滑映射]]粘合而成，
代数簇由[[仿射代数簇]]沿[[多项式]]映射粘合而成。

最简单的仿射代数簇是[[仿射空间]]，
这包括我们熟悉的直线、平面、三维空间等。
在仿射空间中，由[[多项式]]所刻画出的集合也是仿射代数簇。
例如，在平面上由方程 $x^2 + y^2 = 1$ 定义的[[圆周]]就是一例。
但需要注意，如果想得到正确的构造，需要在[[代数闭域]]（如[[复数]]域）
上考虑这些对象，或者在构造这些对象时加入更多的点（参见[[素谱]]的构造）。

一般而言，代数簇就是由若干个这样的多项式的零点集粘起来得到的形状。
这里，我们也要求沿着多项式映射来粘合。
例如，[[射影空间]]就是一个非仿射的代数簇，它可以由若干个仿射空间粘出来。
具体来说，现代定义中的代数簇就是满足一定条件的[[概形]]，
而概形正是由若干个仿射概形粘起来。

## 定义

我们给出两种定义代数簇的方式。
前一种是现代的[[代数几何]]中通常使用的定义（除去一些细节差别）。
后一种定义更加直接，但由于损失了[[概形]]带有的丰富信息，实际操作起来有诸多不便。

### 现代定义

::: definition [代数簇]
设 $k$ 是[[域]]，
$X$ 是 [[相对概形|$k$-概形]]。
称 $X$ 为 $k$ 上的**代数簇**，如果满足以下条件：

- $X$ [[分离态射|分离]]。

- $X$ [[有限型态射|有限型]]。

代数簇间的**态射**就是相应[[概形]]间的态射。
:::

::: remark
一些文献中会在上述代数簇的定义中加入额外条件，
例如要求代数簇[[不可约概形|不可约]]、[[既约概形|既约]]。
这里采取最一般的定义。
:::

::: definition
域 $k$ 上所有代数簇以及它们之间的态射构成一范畴，称为**代数簇范畴**，记为
$\mathsf{Var_k}$。
:::

::: definition
设 $X$ 是域 $k$ 上的代数簇。

- 称 $X$ 为**仿射代数簇**，如果 $X$ 同时是[[仿射概形]]。

- 称 $X$ 为**射影代数簇**，如果 $X$ 同时是 $k$ 上的[[射影态射|射影概形]]，
  即 $k$ 上[[射影空间 (代数几何)|射影空间]]的[[闭子概形]]。

- 称 $X$ 为**拟射影代数簇**，如果 $X$ 是 $k$ 上射影空间的[[子概形]]。

:::

### 古典定义

下面给出古典意义下的代数簇概念。

::: definition
设 $k$ 是[[代数闭域]]。
$k$ 上的**仿射代数簇**是形如下式的[[仿射空间]]子集：
\[
\{x = (x_1, x_2, \dots, x_n) \in \mathbb{A}_k^n
\mid f_1(x) = \cdots = f_m(x) = 0\}
\]
其中 $f_1, \ldots, f_m \in k[x_1, \dots, x_n]$
为 $n$ 元多项式。
:::

::: definition
设 $k$ 是代数闭域，
$k$ 上的**射影代数簇**是形如下式的[[射影空间]]子集：
\[
\{x = [x_0: x_1: \cdots: x_n] \in \mathbb{P}_k^n
\mid f_1(x) = \cdots = f_m(x) = 0\}
\]
其中 $f_1, \ldots, f_m \in k[x_0, \dots, x_n]$
为 $n+1$ 元齐次多项式。
:::

::: definition [Zariski 拓扑]
在[[代数闭域]] $k$ 上，
仿射空间、射影空间的 **Zariski 拓扑**定义为由以下性质确定的拓扑：

- 仿射空间中，所有闭集恰为所有仿射代数簇。

- 射影空间中，所有闭集恰为所有射影代数簇。

由此，仿射代数簇、射影代数簇可以视为仿射空间、射影空间的子空间，
故而带有[[子空间拓扑]]，称为这些代数簇上的 **Zariski 拓扑**。
:::

::: definition
射影代数簇的非空开集被称为**拟射影代数簇**，
简称**代数簇**。
仿射代数簇的非空开集被称为**拟仿射代数簇**。
:::

::: remark
由于[[射影空间]] $\mathbb{P}_k^n$ 由 $n+1$ 个[[仿射空间]] $\mathbb{A}_k^n$
粘成（分别由 $x_i \neq 0, i = 0, \dots, n$ 定义）。
仿射代数簇可以视为射影代数簇的开集，
射影代数簇可以视为仿射代数簇的粘合。
:::

::: definition
从 $\mathbb{A}_k^n$ 中拟仿射代数簇到 $\mathbb{P}_k^m$
中代数簇的**正则映射**为相应集合间的映射 $f$，使其形如
\[
f(x) = [f_0(x) : \cdots : f_m(x)], \quad f_0, \dots, f_m \in k[x_1, \dots, x_n]
\]
从$\mathbb{P}_k^n$ 中代数簇到 $\mathbb{P}_k^m$
中代数簇的**正则映射**为相应集合间的映射，使其在每个形如
$x_i \neq 0, i = 0, \dots, n$
的开集上的限制均为上述定义的拟仿射代数簇到代数簇的正则映射。
:::

::: definition
代数闭域 $k$ 上所有代数簇以及它们之间的正则映射构成一范畴，
称为（古典意义下）**代数簇范畴**。
:::

## 性质

::: proposition
对代数闭域 $k$，存在[[全忠实]]的[[函子]]，
从古典意义下的代数簇范畴到现代意义下的代数簇范畴。
其[[本质像]]为现代意义下的 $k$ 上既约拟射影代数簇。
:::

由此现代代数几何完全覆盖了古典代数几何。
