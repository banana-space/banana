**差集**是指在一个[[集合]]中，而不在另一个集合中的所有元素的集合。

## 定义

::: definition [差集]
设 $X, Y$ 是[[集合]]。其**差集**定义为
\[
X \setminus Y =
\{ x \in X \mid x \notin Y \}.
\]
特别地，当 $Y$ 为 $X$ 的[[子集]]时，差集 $X \setminus Y$
也称为 $Y$ 在 $X$ 中的**补集**。
:::

差集 $X \setminus Y$ 有时也记为 $X - Y$。

```terms
差集:
  en: set difference
补集:
  en: complement
  fr: complémentaire :m
```
