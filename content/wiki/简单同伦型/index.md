**简单同伦型**是[[简单同伦论]]的基本研究对象，
是有限[[单纯复形]]或有限 [[CW 复形]]按特定初等操作划分的等价类。
对这类空间而言，简单同伦型是比[[同伦型]]更细致的不变量。

## 定义

### 几何拓扑定义

::: definition [坍塌]
设 $K$ 是单纯复形，$\tau\subsetneqq\sigma$ 是其两个面，
满足包含 $\tau$ 的每个面都包含于 $\sigma$。则定义
$K$ 沿 $\tau$ 的**坍塌**为 $K$ 去掉所有真包含
$\tau$ 而包含于 $\sigma$ 的面。如 $K$
可经有限个坍塌变为单点，则称 $K$ 为**可塌**。
:::

::: remark
$K$ 沿 $\tau$ 的坍塌是 $K$ 的[[强形变收缩]]，
因此可塌的单纯复形必然[[可缩]]。反之不然，
见[[傻瓜帽]]与[[两房厅]]。
:::

::: definition [简单同伦型] {@简单同伦型}
两个有限单纯复形 $K$ 与 $L$ 之间的**简单同伦**指一列有限单纯复形
$K=K_0,K_1,\ldots,K_n=L$，使得对 $i=1,\ldots,n$，
要么 $K_i$ 是 $K_{i-1}$ 的坍塌，要么 $K_{i-1}$ 是
$K_i$ 的坍塌。**简单同伦型**指有限单纯复形关于简单同伦构成的等价类。
:::

::: remark
因此简单同伦的单纯复形必然[[同伦等价]]。反之不然，
见 [[Wall 障碍]]。
:::

使用[[高阶范畴论]]，可把[[同伦型]]升级为[[生象]]构成的
[[$(\infty,1)$-范畴]]，空间的同伦论因而成为生象范畴的理论。
简单同伦型并无良好的映射概念，只能升级为 [[$\infty$-群胚]]。

::: definition [高阶简单同伦型] {@高阶简单同伦型}
定义[[单纯集]] $\mathcal{M}$ 如下：
- 对 $n\in\mathbb{N}$，$\mathcal{M}$ 的一个 $n$
维单形为一个紧[[分片线性空间|分片线性]]子空间
$K\subseteq\mathbb{R}^\infty\times\Delta^n$，使得自然投影
$K\to\Delta^n$ 为[[分片线性纤维化]]。换言之，
$\mathcal{M}([n])$ 为这样的 $K$ 组成的集合。这里
$\mathbb{R}^\infty$ 指 $\bigcup_{d=0}^\infty\mathbb{R}^d$，
$\Delta^n$ 指 $n$ 维标准单形，均视为[[分片线性空间]]。
- 保序映射 $[m]\to[n]$ 通过几何实现给出标准单形的映射
$\Delta^m\to\Delta^n$，对应的映射
$\mathcal{M}([n])\to\mathcal{M}([m])$ 为纤维化的拉回。

称 $\mathcal{M}$ 代表的 $\infty$-群胚为简单同伦型的
$\infty$-群胚，**简单同伦型**则指 $\mathcal{M}$
的点。
:::

::: remark
这里使用 $\mathbb{R}^\infty$ 的子空间是为了避免集合论麻烦。
直观上可以把 $\mathcal{M}([n])$ 想成 $\Delta^n$
上“相对简单同伦型”的集合。
:::

::: remark
@高阶简单同伦型 与 @简单同伦型
的一致性依赖于如下一些命题：
- 紧分片线性空间的不同单纯剖分在 @简单同伦型
的意义下简单同伦。
- 如 $K\to\Delta^1$ 为分片线性纤维化，则 $0,1\in\Delta^1$
的纤维 $K_0,K_1$ 在 @简单同伦型 的意义下简单同伦。

这些虽不显然，但都是正确的。
:::

### 同伦论定义

简单同伦型也有从[[生象]]出发的纯同伦论定义，使用[[聚集映射]]。

::: definition [简单同伦型] {@thm:同伦论定义}
**简单同伦型**指数据 $(X,\chi)$，其中
$X\in\mathsf{Ani}^{\aleph_0}$ 为[[紧对象|紧]]生象，
$\chi\in\Omega^\infty(K(\mathsf{Sp})\otimes X)$
为常层 $\mathbb{1}_X\in\mathsf{Sp}^X$ 的
[[代数 K 理论|$K$ 类]]沿[[聚集映射]]
$K(\mathsf{Sp})\otimes X\to K(\mathsf{Sp}^X)$
的提升。
:::

::: remark
对[[紧生成稳定 $\infty$-范畴]] $\mathcal{C}$，
这里用 $K(\mathcal{C})$ 表示小范畴
$\mathcal{C}^{\aleph_0}$ 的[[代数 $K$ 理论]]。
这样的好处是可以推广到 $\mathcal{C}$ 为[[紧聚集范畴]]。
:::

::: remark
@thm:同伦论定义 的简单同伦型显然构成 $\infty$-群胚，
虽然它和 @高阶简单同伦型 的 $\mathcal{M}$
的等价性很不显然。
:::

## 性质

::: theorem
设 $K$ 是[[紧空间|紧]]的[[绝对邻域收缩]]。
则 $K$ 典范决定简单同伦型 $(\mathrm{h}K,\chi_K)$，
其中 $\mathrm{h}K$ 为 $K$ 的同伦型，视为[[生象]]。
:::
