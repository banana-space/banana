**凸空间**（也称为**重心代数**）
是一种带有[[凸组合]]运算的[[代数结构]]。

在实向量空间中，两个点 $x,y$ 的凸组合是
\[
(1-p)x+py,
\qquad 0\leq p\leq1.
\]
当 $p=0$ 时得到 $x$，当 $p=1$ 时得到 $y$，
当 $p=\frac12$ 时得到它们的中点。

凸空间将这种运算抽象出来，
不预先要求向量加法和数乘存在，
而是直接给定两个元素按任意权重混合的运算，
并要求这些运算满足相应的代数规律。

## 定义

::: definition [凸空间] {@def-convex-space}
**凸空间**是集合 $X$，
带有一族二元运算
\[
c_p\colon X\times X\to X,
\qquad p\in[0,1],
\]
满足以下公理：

- **端点律**：
  \[
  c_0(x,y)=x.
  \]

- **幂等律**：
  \[
  c_p(x,x)=x.
  \]

- **对称律**：
  \[
  c_p(x,y)=c_{1-p}(y,x).
  \]

- **加权结合律**：
  对任意 $p,q,r\in[0,1]$，若
  \[
  p(1-q)=(1-pq)r,
  \]
  则
  \[
  c_p\bigl(x,c_q(y,z)\bigr)
  =
  c_{pq}\bigl(c_r(x,y),z\bigr).
  \]

上述等式对任意 $x,y,z\in X$ 成立。
:::

运算 $c_p(x,y)$ 应当理解为
以权重 $1-p$ 取 $x$、以权重 $p$ 取 $y$。
因此，也常记作
\[
c_p(x,y)=(1-p)x+py.
\]
右边是整体运算的记号，
不要求 $(1-p)x$、$py$ 或加法分别有定义。

由端点律与对称律，立即得到
\[
c_1(x,y)=y.
\]

加权结合律表示，对三个元素取加权平均时，
可以改变分组方式，但要相应调整组内权重。
在通常的向量空间中，
\[
c_p\bigl(x,c_q(y,z)\bigr)
=
(1-p)x+p(1-q)y+pqz,
\]
而
\[
c_{pq}\bigl(c_r(x,y),z\bigr)
=
(1-pq)(1-r)x+(1-pq)ry+pqz.
\]
条件 $p(1-q)=(1-pq)r$
恰好保证两边各个元素的权重相同。

::: definition [仿射映射]
设 $X,Y$ 是凸空间。
映射 $f\colon X\to Y$ 称为**仿射映射**，
如果它保持所有凸组合运算：
\[
f(c_p(x,y))=c_p(f(x),f(y)),
\qquad p\in[0,1].
\]
:::

凸空间及其间的仿射映射构成[[凸空间范畴]]，
记为 $\mathsf{Conv}$。

## 例子

::: example [向量空间中的凸集]
设 $V$ 是实[[向量空间]]，$X\subseteq V$ 是[[凸集]]。
定义
\[
c_p(x,y)=(1-p)x+py.
\]
凸集的封闭性保证结果仍然属于 $X$，
向量运算的规律保证上述四条公理成立。

因此，每个实向量空间及其中的每个凸集，
都是凸空间。
:::

::: example [概率单纯形]
对于 $n\geq1$，概率[[单形|单纯形]]
\[
\Delta^{n-1}
=
\left\{
(x_1,\dotsc,x_n)\in\mathbb R^n
\;\middle|\;
x_i\geq0,\ \sum_{i=1}^n x_i=1
\right\}
\]
是凸空间，其运算逐分量定义：
\[
c_p(x,y)
=
\bigl((1-p)x_1+py_1,\dotsc,(1-p)x_n+py_n\bigr).
\]

这里的点表示 $n$ 个可能结果上的概率分布，
凸组合表示按照给定概率混合两个分布。
:::

::: example [半格]
设 $S$ 是具有上确界运算 $\vee$ 的[[半格]]。
定义
\[
c_p(x,y)
=
\begin{cases}
x,&p=0,\\
x\vee y,&0<p<1,\\
y,&p=1.
\end{cases}
\]
这些运算使 $S$ 成为凸空间。

其有限凸组合就是所有具有正权重的元素的上确界。
改变分组方式不改变这些元素的总上确界，
所以加权结合律成立。

特别地，集合 $\{0,1\}$ 可以取 $\vee=\max$。
在这个凸空间中，有
\[
c_{1/2}(0,1)=1.
\]
因此，抽象凸空间中的“中点”
不一定具有通常的几何性质。
:::

## 性质

### 有限凸组合

二元凸组合可以反复使用，
从而定义任意有限凸组合
\[
p_1x_1+\cdots+p_nx_n,
\qquad
p_i\geq0,\quad \sum_i p_i=1.
\]

例如，当 $p+q+r=1$ 且 $p+q>0$ 时，
可以定义
\[
px+qy+rz
=
c_r\left(c_{\frac{q}{p+q}}(x,y),z\right).
\]
当 $p+q=0$ 时，结果直接取 $z$。

对称律与加权结合律保证，
只要保持各个元素的最终权重不变，
改变排列与分组方式不会改变结果。
幂等律则保证可以合并重复出现的元素。

::: proposition
有限凸组合满足展开律
\[
\sum_i p_i\left(\sum_j q_{ij}x_{ij}\right)
=
\sum_{i,j}p_iq_{ij}x_{ij},
\]
其中所有权重非负，
$\sum_i p_i=1$，
并且对每个 $i$ 都有 $\sum_jq_{ij}=1$。

凸空间之间的仿射映射保持所有有限凸组合。
:::

### 凸子空间

::: definition [凸子空间]
设 $X$ 是凸空间。
子集 $A\subseteq X$ 称为**凸子空间**，
如果对任意 $x,y\in A$ 及 $p\in[0,1]$，都有
\[
c_p(x,y)\in A.
\]
:::

凸子空间继承原来的凸组合运算，
因而本身也是凸空间。
任意一族凸子空间的交仍然是凸子空间。

包含子集 $S\subseteq X$ 的最小凸子空间，
称为 $S$ 的[[凸包]]。
它恰好由 $S$ 中元素的所有有限凸组合构成。

### 消去律与凸集

普通凸集还有一条抽象凸空间未必满足的性质：
若固定一个端点与一个非零权重，
凸组合的结果便能确定另一个端点。

::: definition [可消去凸空间]
凸空间 $X$ 称为**可消去的**，
如果对任意 $x,y,z\in X$ 及 $0<p<1$，有
\[
c_p(x,y)=c_p(x,z)
\quad\Longrightarrow\quad
y=z.
\]
:::

::: theorem
凸空间可以通过单射仿射映射嵌入某个实向量空间，
当且仅当它是可消去的。
:::

因此，可消去凸空间恰好是通常凸集的抽象刻画。

::: example [不能嵌入向量空间的凸空间]
在上述两点半格凸空间 $\{0,1\}$ 中，
\[
c_{1/2}(1,0)=1=c_{1/2}(1,1),
\]
但 $0\ne1$。
所以这个凸空间不满足消去律，
不能嵌入实向量空间。
:::
