在[[逻辑学]]中，
**蕴涵**是[[逻辑连接词]]的一种，
在逻辑学中常记为 $\to$，而在数学的其他分支中常记为 $\Rightarrow$。

在经典的[[命题逻辑]]中，对[[命题]] $p$、$q$ 而言，
命题 $p \to q$（读作“$p$ 蕴涵 $q$”）
定义为 $\neg p \vee q$。
这是指当 $p$ 成立时，$q$ 也必定成立；
而当 $p$ 不成立时，$q$ 可以成立也可以不成立。
有以下的[[真值]]表：

| $p$ | $q$ | $p \to q$ |
| :-: | :-: | :-: |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

  de: [Implikation :f, implizieren]
