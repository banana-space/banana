- $\overline{X}$ 代表 $X_1, X_2,\cdots,X_n$ 这样的列表的简写。

**归纳类型**（又叫**代数数据类型**）是一类[[类型]]，
在[[简单类型论]]和[[依值类型论]]里面有各自的版本。
大致来说，归纳类型就是可以在它上面用[[归纳法]]的类型，它由一组[[生成元]]（又叫**构造子**）指定，
并且配备一个函数来进行归纳（又叫**消去子**，因为这个函数对应了消去规则），
比如[[自然数类型]]就是一种归纳类型。

归纳类型的构造子的类型有严格限制。若生成元的类型引用了这个归纳类型自身，
那么它需要确保这些引用不能出现在某些位置。这是为了确保类型论的[[正规性 (类型论)|正规性]]。

归纳类型在[[范畴语义]]上对应一种有[[始代数]]的[[自函子]]。

归纳类型有非常多种方式推广，比如[[高阶归纳类型]]、[[归纳族]]、[[归纳递归]]、[[互归纳]]等。
推广方式可以从语法的角度出发，也可以从语义的角度出发。

归纳类型的对偶是[[余归纳类型]]。

## 定义

由于归纳类型推广的方式太多，导致太多的类型可以被称作归纳类型，
且这个概念随着时间在不断变化，因此很难给出普适的定义。

以下定义尽可能在不同类型论中给出一种足够通用的版本的归纳类型，仅供参考。

### 简单类型

首先我们给出基本的语法框架，再在此之上给出一些必要的限制。

::: definition [数据类型] {@def:s-rec}
令 $Γ, x : X ⊢ D(x) : \mathcal U$ 为一类型。
接下来将它的构造规则由一组如下形式的函数符号给出（称为**构造子**）：
\[
\cfrac{Γ, x : X, D : X \to \mathcal U ⊢ u : C_i}
{Γ, x : X ⊢ \operatorname{con}_i(u): D(x)}
\]
其中，$C_i$ 是一个类型，它可以引用当前正在被定义的类型 $D(x)$ 自身，
以及其中涉及的变量 $x : X$。
用这种方式定义的类型叫做**数据类型**。

数据类型的消去规则是类似这样的函数（称为**消去子**）：
给定类型 $A$、一组函数 $\overline f$，其中
\[
f_i:C_i → A
\]
代表“处理第 $i$ 个构造规则”的函数，然后再给出一个 $u:D(x)$ 类型的实例，
返回 $A$，写法如下：
\[
\operatorname{rec}_{D(x)}(\overline f, u):A
\]
数据类型的消去也常常使用[[模式匹配]]的语法书写。
其中，$f_i$ 可以引用 $\operatorname{rec}_{D(x)}$。

计算规则便是将 $u$ 根据它具体的构造规则，选择合适的函数处理。
:::

[[自然数类型]]就是一种数据类型，它和如上定义的对应关系如下
（注意区分下文中的各种数字：$0$ 代表[[自然数]]，$1$ 代表[[单位类型]]）：

- $D(x)$ 对应自然数类型本身 $\mathbb N$，这意味着 $X = 1$，
- $C_1$ 不包含任何数据，因此 $C_1 = 1$，
- $\operatorname{con}_1(u)$ 对应自然数 $0$，类型为 $1 → \mathbb N$，
  和标准定义中的 $\mathbb N$ 等价，
- $C_2(x)$ 递归地引用自身，对应 $\mathbb N$，
- $\operatorname{con}_2(u)$ 对应取后继的操作 $s(u)$，类型为 $\mathbb N → \mathbb N$。

这样的递归类型非常通用，而且允许不太有意义的消去规则，例如我们可以定义
$f_i(x)=\operatorname{rec}_D(\overline f, \operatorname{con_i}(x))$，根据计算规则，
表达式 $f(\operatorname{con_i}(x))$ 不存在更简单的形式，这给出了[[正规性 (类型论)|正规性]]的反例。

为了解决这个问题，需要引入两个限制：

::: proposition [结构递归] {@def:s-ter}
$f(x)$ 的定义不能不受限制地引用 $\operatorname{rec}_D$，
它必须确保每次引用的时候，会传入一个满足如下规定（称之为“更小”）的参数：

- $x$ 的子表达式，或者
- 对一个更小的表达式的函数应用。

满足这样的限定条件的消去规则叫做**结构递归**。
:::

::: proposition [严格正性] {@def:s-sp}
<see>[[严格正性]]</see>

$C$ 的定义不能不受限制地引用 $D(x)$，它必须确保自己是如下形式：
\[
C = \prod_{i : I} E(i)
\]
其中 $I$ 不能引用 $D$，然后 $E(i)$ 满足如下条件：

- 不（直接或间接）引用 $D$，或者
- 形如 $F → D$，其中 $F$ 不引用 $D$。

这样的定义出的类型 $D$ 是**严格正**的。
:::

::: example
如下类型作为 $D(x)$ 的构造子的参数类型是严格正的。
\[
C=X → (X → D(x))
\]
其中 $X$ 是一个具体的类型，和 $D$ 无关。
原因是我们可以将它看作 $\prod_{i : I} E(i)$ 的特例，
其中 $I = 1$，$E(i) = X → (X → D(x))$。
:::

容易验证自然数类型的定义满足这两个限制。

::: definition [归纳类型]
将 @def:s-rec 中定义的类型加上 @def:s-ter、@def:s-sp
的限定条件得到的类型就是简单类型情况的**归纳类型**。
:::

### 简单类型

将上述所有定义中的 $X$ 换成[[宇宙 (类型论)|宇宙]]或者它们的积就得到了[[简单类型论]]中的归纳类型。
自然数类型就是一个简单类型的归纳类型，因为单位类型可以看作零元的积。

### 宇宙层级

在有宇宙层级时，若 $D(x) : \mathcal U_k$，那么必须也有 $C_i : \mathcal U_k$。
换言之，类型本身所在的层级必须和构造子的参数所在的层级匹配。

### 类型签名

很多时候需要考虑多个参数的归纳类型，可以用[[积类型]]来将这些参数类型拼起来：
$D(x)$ 中 $x : X_1 × X_2 × \cdots × X_n$。
其中 $X_i$ 是任意类型（在简单类型的情况中，可以看作是 $∀i, X_i=\mathcal U$）。
为了直观，这种情况下会写作
\[
D: X₁ → X₂ → \cdots → X_n → \mathcal U
\]
这意味着 $D$ 在给足所有参数后，变成一个类型。
但这并不意味着 $D$ 变成了一个函数，相反，它更接近一种 [[$\Sigma$ 类型]]：
它不会因为有了参数就像函数一样被消去，
而是会将这些参数收集起来提供给构造子。

## 范畴语义

一言蔽之，归纳类型的[[范畴语义]]是某种[[余极限]]，非常接近某种[[自由代数]]。

首先考虑简单类型的情况：此时类型是某[[范畴]] $\mathcal C$ 里的对象，实例就是态射，
暂时不考虑类型带参数的情况。一个归纳类型在定义的时候含有如下数据：

- 被定义的归纳类型本身，即 $D$
- 它的所有构造子，$\operatorname{con_i}:C_i → D$。
  此时我们忽略构造子的名字，只用下标区分它，毕竟名字只是写给人看、便于区分用的。

构造子可以视为一组万剑归宗的态射：

\[
\begin{tikzcd}
  C_1 \ar[r] &D&\\
  C_2 \ar[ur] & \cdots \ar[u] & C_n \ar[ul]
\end{tikzcd}
\]

对 $\overline C$ 取[[余积]]就可以将这些构造子全部整合起来，
打包成一个态射。这就是归纳类型的构造子的范畴语义。
具体来说，考虑如下[[自函子]]：

\[
\begin{aligned}
  F&: \mathcal C → \mathcal C\\
  F&(X)=\coprod_{i=1}^n C_i
\end{aligned}
\]

该类型的构造子对应一态射 $c:F(X) → X$。
注意，$C_i$ 在满足严格正的条件下是可以引用 $X$ 的。

满足等式 $F$ 的始代数 $X$ 就是该归纳类型的范畴语义。

## 推广

- [[高阶归纳类型]]允许构造子构造出该类型上的[[相等类型]]的实例。
- [[归纳族]]允许构造子构造出该类型的特化。
- [[归纳递归]]允许构造子中出现一些对当前类型进行消去的函数。
- [[互归纳]]允许构造子构造出该类型的特化，且这一组参数的类型用到了当前归纳类型。
  即：有 $A:\mathcal U, B:A \to \mathcal U$ 两归纳类型，后者是类型族，且 $A$ 的构造子引用 $B$。
