一个[[基数]]的**后继**是大于它的最小基数。
若一个基数是另一个基数的后继，则称它为**后继基数**。
若一个无限基数不是后继基数，则称为**极限基数**。

通常只对不可数基数使用这个概念。

## 定义

::: definition [基数的后继]
设 $\kappa$ 为基数。
大于 $\kappa$ 的最小基数称为 $\kappa$ 的**后继**，
记为 $\kappa^+$。
:::

::: definition [后继基数与极限基数]
设 $\kappa$ 为基数。
若存在基数 $\lambda$ 使得 $\kappa = \lambda^+$，
则称 $\kappa$ 为**后继基数**。

若 $\kappa$ 无限且不为后继基数，则称它为**极限基数**。
:::

## 性质

注意 $\omega_\alpha^+ = \omega_{\alpha+1}$，由此立得：

::: lemma
设 $\kappa = \omega_\alpha$ 为不可数基数，
其中序数 $\alpha > 0$。
则 $\kappa$ 为后继基数当且仅当 $\alpha$ 为后继序数；
$\kappa$ 为极限基数当且仅当 $\alpha$ 为极限序数。
:::
