**Mathieu 群**是一类[[有限单群|散在单群]]，
它们是一些 [[Steiner 系]]的[[自同构]]群。
具体来说，Mathieu 群可以分为**大 Mathieu 群**和**小 Mathieu 群**。

大 Mathieu 群有 [[$M_{22}$]]、[[$M_{23}$]]、[[$M_{24}$]] 三个，其中：

- $M_{24}$ 是 Steiner 系 $S(5,8,24)$ 的自同构群；

- $M_{23}$ 是 Steiner 系 $S(4,7,23)$ 的自同构群；

- $M_{22}$ 是 Steiner 系 $S(3,6,22)$ 的自同构群。

列表中每一个 Steiner 系都是下一个的一点扩张，
而 $S(3,6,22)$ 则是[[射影空间]] $\mathbb{P}^2(\mathbb{F}_4)$
对应的 Steiner 系 $S(2,5,21)$ 的一点扩张（这些扩张均存在且唯一）。

小 Mathieu 群有 [[$M_{11}$]]、[[$M_{12}$]] 两个，其中：

- $M_{12}$ 是 Steiner 系 $S(5,6,12)$ 的自同构群；

- $M_{11}$ 是 Steiner 系 $S(4,5,11)$ 的自同构群。

其中前者的 Steiner 系是后者的一点扩张。
后者删除两个点后则是[[仿射空间]] $\mathbb{A}^2(\mathbb{F}_3)$
对应的 Steiner 系 $S(2,3,9)$。
