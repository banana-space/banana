在本文中，

- 所有环均指[[交换环]]。

:::

**赋值**为[[环]]的每个元素对应[[全序群]]中的元素，
以表示它们的“大小”，从而在配有赋值的环上可以定义[[拓扑]]。

从[[代数–几何对偶]]的角度来看，
环是[[空间]]的[[函数环]]，
域是空间的[[有理函数域]]。
环或域上的赋值可以视为相应空间中的“[[点]]”，
而全体赋值则构成的[[赋值谱]]则视为此空间。
例如，对素数 $p$（它是整数的[[素谱]]中的点），
有理数 $\mathbb{Q}$ 上的函数

\[
v_p \colon \mathbb{Q} \to \mathbb{Z} \cup \{\infty\}
\]

（$v_p(q)$ 是最大的自然数 $n$，满足 $p^n$ 整除 $q$）
是 $\mathbb{Q}$ 上的（加性）赋值。
这种看法在 [[$p$ 进几何]]中很常用，
因为环的[[极大理想]]或[[素理想]]给出的点经常不够多。

## 定义

### 基本定义

有以下两种常见的赋值概念，它们完全等价，
只是有时用某种方法叙述可能更方便。
在行文中，以 $v$ 表示的默认为加性赋值，
以 $|\cdot|$ 表示的默认为乘性赋值。

::: definition [加性赋值]
对[[全序群]] $(\Gamma, +, 0)$
和[[环]] $R$，
$R$ 以 $\Gamma$
为**值群**的**加性赋值**是[[映射]]
\[
v\colon R \to \Gamma \cup \{\infty\}
\]
这里 $\infty$ 是一个元素，它比 $\Gamma$ 的所有元素都大。
满足条件
- $v(0) = \infty$，$v(1) = 0$。
- 对任意 $a, b \in R$，$v(ab) = v(a) + v(b)$。
- 对任意 $a, b \in R$，$v(a+b) \geq \min\{v(a), v(b)\}$。
- 它的像生成 $\Gamma$。

:::

::: definition [乘性赋值]
对[[全序群]] $(\Gamma, \times, 1)$
和[[环]] $R$，
$R$ 以 $\Gamma$
为**值群**的**乘性赋值**，
也称为**范数**是[[映射]]
\[
|\cdot| \colon R \to \Gamma \cup \{0\}
\]
这里 $0$ 是一个元素，它比 $\Gamma$ 的所有元素都小。
满足条件
- $|0| = 0$，$|1| = 1$。
- 对任意 $a, b \in R$，$|ab| = |a||b|$。
- 对任意 $a, b \in R$，$|a+b| \leq \max\{|a|, |b|\}$。
- 它的像生成 $\Gamma$。

:::

可以看出，将加性赋值取相反数，并将加法群视为乘法群，就得到乘性赋值。反之亦然。

::: definition [核]
环 $R$ 的乘性赋值 $|\cdot|$ 的**核**是
\[
\ker{|\cdot|} = \{x \in R \mid |x| = 0\}.
\]
可以验证它是 $R$ 的[[素理想]]。
对加性赋值，将 $0$ 改为 $\infty$ 即可。
:::

### 域的赋值

环的赋值并不等价于[[赋值环]]，
事实上后者等价于[[域]]的赋值。

::: definition
设有域 $K$ 上的乘性赋值 $|\cdot|$，
以 $\Gamma$ 为值群。
它的**整数环**是子集
\[
K^\circ = \{x \in K \mid |x| \leq 1\}.
\]
可以验证它是以 $\Gamma$ 为值群的[[赋值环]]，
此环的[[极大理想]]是
\[
K^{\circ\circ} = \{x \in K \mid |x| < 1\}.
\]
:::

反过来，[[赋值环]]可以诱导它的[[分式域]]到它的[[值群]]的赋值。

### 连续赋值

如果环本身带有拓扑，可以谈论赋值与拓扑的相容性。

::: definition [连续赋值]
对拓扑环 $A$，
如赋值 $|\cdot| \colon A \to \Gamma\cup\{0\}$
满足对任意 $\gamma \in |A|$，
$\{x \in A \mid |x| < \gamma\}$ 为开集，
则称 $|\cdot|$ 为 $A$ 的**连续赋值**。
:::

## 例子

- 对任意[[整环]]，将它的非零元素都映到单位元的映射是赋值，称为它的**平凡赋值**。

- $\mathbb{Q}$ 的赋值（在同构意义下）为上述平凡赋值，或引言中所述之 $v_p$，
  这些分别对应于[[整数]]的[[素谱]] $\operatorname{Spec}(\mathbb{Z})$ 的[[普遍点]]和[[闭点]]。

- 设 $K$ 是某个[[代数闭域]] $k$ 上[[超越度]]为 $1$ 的[[域]]，
$K$ 上所有满足 $|k^\times| = 1$ 的赋值构成以
  $K$ 为[[有理函数域]]的[[光滑态射|光滑]][[代数曲线]]。

- 考虑赋予 [[$p$ 进拓扑]]的环 $\mathbb{Z}_p$，
  则平凡赋值并不连续：$\{x \in \mathbb{Z}_p\mid |x|<1\} = \{0\}$ 不为开集。
  $\mathbb{Z}_p$ 的连续赋值在同构意义下只有两个：
  一个由 $\mathbb{F}_p$ 的平凡赋值沿着 $\mathbb{Z}_p \to \mathbb{F}_p$ 拉回诱导，
  另一个就是引言中所述之 $v_p$。
  事实上它们分别是[[进制谱]] $\operatorname{Spa}(\mathbb{Z}_p, \mathbb{Z}_p)$ 的闭点和普遍点。
