**Categorical Logic and Type Theory**（中译**范畴逻辑与类型论**）
是[[Bart Jacobs]]写的一本关于[[范畴逻辑]]和[[类型论]]的[[范畴语义]]的书。

## 内容

- 第 0 章给出了本书的动机，大致解释了各种类型论的变种，
  指出[[纤维范畴]]、[[初等意象]]和[[范畴语义]]的重要性。
  该章节指出，逻辑总是建立在类型论之上，
  而类型论也可以在 [[Curry–Howard 对应]]的视角下建立在逻辑之上。
  该章节定义了[[谓词范畴]]、[[二元谓词范畴]]等构造并介绍相关的[[纤维范畴]]和[[伴随函子]]。

- 第 1 章从[[族纤维化]]作为例子引入了[[纤维范畴]]的定义，介绍了[[集合范畴]]、
  [[$ω$-集]] 的范畴之间的各种函子。

- 第 2 章给出了[[简单类型 $λ$ 演算]]和[[单一类型 $λ$ 演算]]的[[范畴语义]]。

## 部分定义

书中定义了许多奇特的概念，以下列出一些。

::: definition {@def:s}
对于含有[[积 (范畴论)|积]]的范畴 $B$，定义范畴 $s(B)$：

- [[对象]]为 $B$ 中对象的二元组 $\braket{I, X}$。

- [[态射]]为 $B$ 中的态射 $\braket{u, f} ∈ s(B)(\braket{I,X},\braket{J,Y})$，
  其中 $u∈B(I,J)$，$f∈B(I×X,Y)$。

- 态射复合由显然的组合给出。

:::

::: definition
如下[[遗忘函子]] $s(B)$ 叫做**简单纤维化**：
\[
\begin{aligned}
  s(B) & → B \\
  \braket{I,X} &↦ I\\
  \braket{u,f} &↦ u
\end{aligned}
\]
容易验证这是一个[[纤维范畴]]。
:::

::: definition {@def:ct}
对于范畴 $B$ 和 $T \subset \operatorname{Ob}B$，
二元组 $\braket{B,T}$ 叫做一个**语境–类型结构**。
语境–类型结构之间的[[态射]] $\braket{B, T} → \braket{A, S}$
由满足如下条件的函子 $K\colon B → A$ 组成：

- 保持有限积，且

- $X ∈ T \implies K(X) ∈ S$。

:::

::: definition
语境–类型结构 $\braket{B,T}$ 满足如下条件时是**非平凡**的：
至少对于一个对象 $X∈T$ 存在 $u∈B(1, X)$，其中 $1$ 是[[终对象]]。
:::

非平凡的语境–类型结构类比为闭语境中有类型的[[类型论]]。
若 $T$ 是单点集合，那么该语境–类型结构对应[[单一类型 $λ$ 演算]]。

如下定义将 @def:ct 和 @def:s 联系起来。

::: definition
对于语境–类型结构 $\braket{B,T}$，定义其上的简单纤维化 $s(T)$ 为 $s(B)$ 的[[全子范畴]]，
要求对象 $\braket{I, X}$ 满足 $X∈T$。
:::
