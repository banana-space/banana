在本文中，

- [[范畴]]都指 [[$(\infty,1)$-范畴]]。
- [[意象]]都指 [[$(\infty,1)$-意象]]。

**连合性**是[[高阶范畴论]]中与[[截断 (范畴论)|截断]]相对偶的基本属性。
直观上，若截断对应于“抹去高阶同伦群”，
那么连合性则对应于“低阶同伦群均消没”。
二者共同构成了意象中的[[连合–截断分解系]]。

## 定义

::: definition
令 $\mathcal{T}$ 为意象，$n \geq -1$。

- 称 $X \in \mathcal{T}$ 为 **$n$-连合对象**，
  是指其 $(n-1)$-截断为终对象，即 $\tau_{n-1} X \simeq \ast$。

- 称态射 $f \colon X \to Y$ 为 **$n$-连合态射**，
  是指其视为[[俯范畴]] $\mathcal{T}_{/Y}$ 中的对象时为 $n$-连合对象。

记 $\mathcal{T}^{\geq n} \subseteq \mathcal{T}$ 为全体 $n$-连合对象所张成的全子范畴。
:::

::: remark
展开定义：$X$ 为 $n$-连合对象即要求 $\tau_{n-1} X \simeq \ast$，
亦即 $X$ 的全部 $k$ 阶同伦信息在 $k \leq n-1$ 时均消没。
而 $f \colon X \to Y$ 为 $n$-连合态射则是“纤维层面”的条件：
直观上它要求 $f$ 的每条纤维都是 $n$-连合的。
:::

::: remark
部分文献使用术语“$n$-连通”。
此时 $n$-连通对象相当于本定义中的 $(n+1)$-连合对象，二者的编号差 $1$。
:::

## 例子

- $\mathcal{T}$ 中的每个对象都是 $(-1)$-连合对象，每个态射都是 $(-1)$-连合态射。
  这是因为 $\tau_{-2} X \simeq \ast$ 对任意对象 $X$ 自动成立（$(-2)$-截断对象恰好是终对象）。

- $0$-连合对象就是“非空”的对象，即满足 $\tau_{-1} X \simeq \ast$ 的对象。
  在生象范畴 $\mathsf{Ani}$ 中，这就是非空的生象。

- $0$-连合态射恰好就是[[有效满态射]]。

- $1$-连合对象在 $\mathsf{Ani}$ 中即为连通生象（即 $\pi_0(X) \simeq \ast$）。
  更一般地，$n$-连合对象对应于满足 $\pi_k(X,x) = 0$ 对所有 $k < n$ 成立的空间。

## 性质

### 与截断的正交性

连合态射与截断态射之间存在提升性质，
这正是连合–截断分解系的核心。

::: proposition
令 $\mathcal{T}$ 为意象。
$\mathcal{T}$ 中的态射 $f \colon X \to Y$ 是 $n$-连合态射，当且仅当对于以下形式的交换图表：
\[
\begin{tikzcd}
X \ar[d,"f"'] \ar[r] & U \ar[d,"g"]\\
Y \ar[r,equal] \ar[ur,dashed] & Y
\end{tikzcd}
\]
如果 $g$ 是 $(n-1)$-截断态射，则虚线所示的对角线提升不仅存在，且所有这种提升所构成的生象是可缩的
（即 $n$-连合态射左正交于 $(n-1)$-截断态射）。
:::

::: remark
这一正交性的直观含义是：$n$-连合态射“看不见”$(n-1)$-截断态射。
因为 $(n-1)$-截断态射仅涉及 $(n-1)$ 阶及以下的同伦信息，
而 $n$-连合态射恰好在这些低阶信息上是平凡的，因此提升本质上是唯一的。
:::

### 分解系与封闭性

::: proposition
令 $\mathcal{T}$ 为意象，则有以下性质：

- 对于任意 $n \geq -2$，
  二元组 $((n+1)\text{-连合态射},\; n\text{-截断态射})$ 构成 $\mathcal{T}$ 上的一个[[分解系]]。
  换言之，
  $\mathcal{T}$ 中的每个态射都可以唯一地（在本质唯一的意义下）分解为一个 $(n+1)$-连合态射后接一个
  $n$-截断态射。

- $n$-连合态射关于拉回封闭。

- 态射 $f \colon X \to Y$ 为 $n$-连合态射当且仅当拉回函子
  \[
  f^* \colon (\mathcal{T}_{/Y})_{\leq n-1} \to (\mathcal{T}_{/X})_{\leq n-1}
  \]
  是全忠实的。

:::

::: remark
第三条给出了连合性的另一种理解方式：
$f$ 是 $n$-连合的，当且仅当沿 $f$ 拉回不丢失 $(n-1)$-截断信息。
直观地说，$f$ 的纤维在 $(n-1)$ 阶及以下是“透明”的。
:::

### 递归刻画

::: proposition
对于 $n \geq 1$，
态射 $f \colon X \to Y$ 为 $n$-连合态射当且仅当其为有效满射且对角态射
$\Delta_f \colon X \to X \times_Y X$
为 $(n-1)$-连合态射。
:::

::: remark
此命题与截断的递归定义形成完美的对偶：
截断性通过对角态射“向下递归”至同构（$(-2)$-截断），
而连合性同样通过对角态射“向下递归”至有效满射（$0$-连合）。
这一结构上的对称性是连合–截断分解系的根源。
:::

::: remark
当考虑对所有 $n$ 同时为 $n$-连合的“$\infty$-连合”态射时，
相应的正交补给出了超完备对象的概念，
进而引出意象的超完备性。详见词条[[超完备性]]。
:::
