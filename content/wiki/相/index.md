在[[凝聚态物理]]中，**相**是多体系统的一种稳定的[[涌现]]行为。
它由大量自由度在[[热力学极限]]下
的集体行为决定。

固态、液态和气态是最熟悉的相。
凝聚态物理中还研究[[铁磁体|铁磁相]]、[[超流体|超流相]]、
[[超导体|超导相]]、[[拓扑序]]等更一般的相。

相之间的转变称为[[相变]]。
改变[[控制参数]]时，
系统可以保持原有的相，也可能在某处发生相变而进入另一相。

## 现象

在引入一般概念之前，先列举一些可直接观察或测量的现象。
这些现象本身并不依赖于某种相的数学定义；
理论的任务是寻找能够统一描述它们的结构。

::: example [冰、水与水蒸气]
在通常压强下加热冰，
温度升至 $0^\circ\mathrm{C}$ 时，冰开始熔化为水。
继续加热，温度升至 $100^\circ\mathrm{C}$ 时，
水开始沸腾并产生水蒸气。

在熔化和沸腾的过程中，
物质的密度、体积、热容量等宏观量发生明显变化。
:::

::: example [晶体与熔化]
食盐、石英、金刚石和冰等物质可以形成晶体。
晶体常具有规则的外形、确定的晶面和方向相关的物理性质。

用 X 射线、电子或中子照射晶体时，
可以观察到规则排列的衍射斑点。
这类衍射图样在晶体存在的温度和压强范围内保持稳定。

升高温度时，晶体会在熔点附近熔化为液体。
熔化后，规则的衍射斑点消失，
并被与液体相应的较宽散射环取代。
同时，材料失去确定的晶面与稳定形状，
可以像普通液体一样流动。

改变温度、压强或化学成分后，
衍射图样也可能突然改变，
表明材料进入另一种晶体结构。
例如，碳可以形成石墨或金刚石，
二者的硬度、电导率和光学性质明显不同。
:::

::: example [铁磁体失去磁性]
一块铁磁材料可以在未施加外磁场时保有磁性。
加热后，它的磁性逐渐减弱；
温度超过某一数值时，宏观磁性消失。

再将材料冷却，
它又可能重新获得磁性。
这一现象可以通过测量样品的磁矩随温度的变化观察到。
:::

::: example [液晶显示]
液晶在外观上能够流动，
但置于偏振光之间时会呈现明显的明暗纹理和颜色变化。
改变温度或施加电场，
这些纹理可以突然消失或重组。

这一性质构成液晶显示器工作的基础。
:::

::: example [超导]
某些材料冷却到特定温度以下后，
直流电阻降至实验精度下不可测的程度。
同时，磁场难以穿透样品内部。

改变温度、外加磁场或通过样品的电流，
都可以使这种现象消失。
:::

::: example [超流氦]
液态氦冷却到足够低温后，
可以出现异常的流动现象。
例如，液体能够沿容器壁爬升，
或通过极细的孔隙而几乎不出现流动阻力。

旋转容器时，流体中还可以观察到规则排列的涡旋。
:::

::: example [液气临界点附近的混浊]
将液体与其蒸气密封在容器中并逐渐升温，
两相的界面会变得模糊。
接近临界温度时，
容器中的样品可呈现乳白色或强烈散射光线的现象，
称为[[临界乳光]]。

超过临界温度后，
原先清楚可见的液体与气体界面消失。
:::

::: example [二维电子气中的 Hall 平台]
在低温和强磁场下测量二维电子系统，
可以发现 Hall 电阻在一段磁场范围内保持几乎不变，
然后突然跳到另一数值。

在某些样品中，
这些平台的数值是基本常数的简单分数倍。
即使改变样品中的少量杂质或电子密度，
平台仍可在一定范围内保持稳定。
:::

::: example [玻璃化]
将某些液体快速冷却，
它们不会形成通常可见的晶体，
而会逐渐变得极其黏稠，最后形成玻璃。

这一过程没有像冰熔化那样清楚的相界面或确定温度。
样品的性质还会依赖于冷却速率与等待时间。
:::

::: example [一维量子材料的低温幂律]
某些近似一维的导电材料在低温下，
电导、热容或散射强度并不呈现通常金属中的行为，
而会随温度或能量按幂律变化。

不同材料在低能量下可以出现相同的幂律指数与尺度关系。
:::

## 普适性

前一节的现象表明，凝聚态物理研究的对象并不只是某一种具体材料。

不同的金属都可能在低温下成为超导体；
不同的流体都可能出现液气共存与临界乳光；
不同的磁性材料都可能在适当条件下产生宏观磁性；
不同的二维电子样品都可能出现量子 Hall 平台。

这些现象的共同之处是：
它们对许多微观细节并不敏感。
原子种类、晶格结构、杂质浓度、样品形状和临界温度可以不同，
但在适当的实验条件下，
同一类现象会以相同或非常相近的方式反复出现。
这种现象称为 **[[普适性]]**。

因此，一个相通常不是指某个固定的微观 Hamilton 算子，
而是指一大类系统共享的稳定宏观性质。
改变材料中的某些微观参数后，
只要这些性质持续存在，
实验上便仍将系统认作同一类相。

::: example [超导的普适现象]
铅、铌、汞以及许多铜氧化物等材料的化学成分和临界温度
都很不相同。
但在进入超导状态后，
它们都会表现出极低的直流电阻和排斥磁场的现象。

临界温度、能够承受的磁场和电流强度属于材料的具体性质；
零电阻和 Meissner 效应则是超导相的共同现象。
:::

::: example [超流的普适现象]
在不同容器、不同几何形状和不同实验条件下，
超流氦都可以表现出异常流动与量子化涡旋。

涡旋的具体位置和数目取决于容器形状、转速及杂质等因素，
但涡旋所呈现的量子化规律不依赖于这些细节。
:::

::: example [铁磁性的普适现象]
铁、钴、镍及许多磁性合金具有不同的晶体结构与 Curie 温度。
但在适当的低温区域，
它们都能够在无外磁场时保留宏观磁矩，
并形成可观测的[[磁畴]]。

磁畴的尺寸、材料的磁化强度和转变温度因材料而异，
但宏观磁性及其对外磁场的响应是共同现象。
:::

::: example [量子 Hall 平台]
不同半导体异质结、石墨烯样品或二维电子器件，
都可以在低温和强磁场下观察到 Hall 电阻平台。

平台出现的磁场范围、电子密度和样品迁移率各不相同。
但某些平台的电阻值总是稳定地接近由基本常数给出的数值，
并且在一定程度的样品不均匀和杂质扰动下仍然存在。
:::

有些普适性质表现为定性行为，
例如是否具有宏观磁性、是否排斥磁场或是否存在量子化涡旋。
有些则表现为精确或近乎精确的数值关系，
例如[[量子 Hall 电导]]的平台值。

还有一类特别重要的普适性出现在[[临界点]]附近。
此时，不同系统的热容量、磁化率和关联长度
可以具有相同的幂律行为。
这些幂律中的[[临界指数]]以及某些无量纲比值，
构成临界现象的普适性质。

具有相同普适性质的一类系统，
在适当语境下称为属于同一个相；
具有相同临界幂律行为的一类相变，
则称为属于同一个[[普适类]]。

## 历史

### 热学与热力学

早期的热学研究集中于热、温度、蒸汽机和物态变化等可直接观察的现象。
人们已经知道，同一种物质可以呈现固、液、气等不同状态，
并在熔化和沸腾时吸收或放出热量。

十九世纪的[[热力学]]将这些现象组织为一套宏观理论。
它用温度、压强、体积、熵和自由能等宏观量来约束物质在平衡时的行为。

### 统计力学

[[统计力学]]随后试图将热力学建立在原子和分子的运动之上。
Boltzmann 和 Gibbs 引入[[系综]]与[[配分函数]]，
将压强、热容量、自由能等宏观量
联系到大量[[微观状态]]的统计分布。

但这一计划曾遇到一个根本困难。
对有限系统，配分函数是有限项之和，
因而通常是控制参数的[[解析函数]]。
由配分函数得到的[[自由能]]也不会真正出现奇异性。
然而，熔化、沸腾和铁磁体失去磁性等现象
显然对控制参数具有突变行为。

因此，在二十世纪早期，
人们并不普遍相信简单的原子模型和解析的统计计算
足以严格描述相变。

[[Ising 模型]]使这个问题变得特别清楚。
Lenz 和 Ising 考虑由只有两个可能方向的格点自旋组成的模型。
Ising 对一维模型的计算表明，
它在任何非零温度下都不会出现铁磁相变。
这曾加强了如下疑虑：
也许由简单局域相互作用构成的统计模型
根本不能产生真实的相变。

后来的结果改变了这一看法。
Peierls 证明二维 Ising 模型在低温下可以保持磁性。
1944 年，Onsager 给出了二维正方晶格 Ising 模型
在零磁场下的严格解。
这个解显示，在热力学极限中，
自由能在临界温度处确实具有非解析性。

随后，Yang 从 Onsager 解中严格导出了低温相的自发磁化。
因而，同一个明确的微观模型中，
高温无磁性状态与低温有磁性状态
可以通过一个严格的相变分隔。

这一结果具有重要的哲学意义。
非解析性并不需要被额外加入微观理论；
它可以在无限多自由度的极限中涌现出来。
热力学极限则是连接解析的微观描述与非解析的宏观现象的关键。

从数学上看，
Ising 模型也成为后来研究相变的原型。
它表明相变可以是明确的可证明现象。

### Landau 理论与对称性破缺

二十世纪中叶，
Landau 提出了以[[序参量]]和[[自发对称性破缺]]描述相变的框架。
例如，铁磁体的磁化强度可以作为序参量：
在高温相中它为零，
在低温相中它取非零值。

Landau 理论成功地说明，
很多相由系统所呈现的对称性不同来区分。
它也给出了连续相变附近许多可计算的预测。

但后来的实验和理论表明，
对称性破缺并不能描述全部的相。
有些系统没有通常的局部序参量，
却仍然具有稳定而可重复观察到的集体现象。

### 重整化群与普适性

临界现象推动了[[重整化群]]理论的发展。
Wilson 的观点是：
逐步忽略短距离细节后，
一个系统的描述会流向某种长距离有效理论。

这一观点解释了为什么不同的微观材料
可以具有相同的[[临界指数]]和关联函数的尺度行为。

### 共形场论

在二维经典统计系统的临界点，
或一维量子系统的连续量子相变点，
长距离理论常常具有[[共形不变性]]。
这使[[共形场论]]成为研究临界现象最成功的理论之一。

二维共形场论的成功尤其突出。
无穷维的[[Virasoro 代数]]将局域共形变换组织为严格的代数结构。
在适当条件下，
共形对称性可以强烈限制关联函数、允许的临界指数和边界行为。

Belavin、Polyakov 与 Zamolodchikov 在二十世纪八十年代的工作表明，
某些二维共形场论可以被精确分类和求解。
这使二维 Ising 模型等统计模型的临界行为可以由明确的代数和表示论结构刻画。

共形场论展示了一个更一般的可能性。
当系统进入适当的长距离极限时，
微观粒子和晶格的描述可以让位于简单的数学理论。

### 拓扑相与范畴论

二十世纪末以来，
[[量子 Hall 效应]]、[[量子自旋液体]]等现象推动了
[[拓扑序]]的研究。

在某些二维有隙量子相中，
低能激发的性质不能用通常的序参量充分描述。
它们可以具有分数电荷、[[任意子]]统计，
并表现出依赖空间拓扑的稳定性质。

在长距离极限下，
这类系统可由[[拓扑量子场论]]描述。
任意子的种类、融合规律和交换规律，
则自然组织为[[张量范畴]]；
在许多重要情形中，它们构成[[模张量范畴]]。

这使相的分类和刻画与[[范畴论]]发生了实质联系。
