**意象**是一类[[范畴]]。
意象的概念可以从多个不同的角度来理解：

- 一方面，
  意象可以视为由某一类[[空间]]的全体构成的范畴，
  其中的空间局部上看起来像是某种给定的空间。
  并且，这里空间的概念需要足够一般，即需要允许很多空间存在，
  以使得整个意象具有类似[[集合范畴]]的性质。
  这样，很多一般的操作，例如任意多个空间的[[积 (范畴论)|积空间]]，
  或两个空间的[[映射空间]]等，都可以在该意象内进行。
  例如，[[光滑流形]]并不构成意象，
  但对应的[[广义对象|广义]]的空间概念，
  即[[光滑集合]]，构成一个意象。

- 另一方面，也可以不将意象的对象视为空间，
  而是将意象自身视为一个抽象的[[空间]]。
  意象是[[景]]上取值在集合的[[层]]构成的范畴，
  它反映了相应的景的本质信息。
  景可以视为一种抽象的空间，例如在[[代数几何]]中，
  常常将[[概形]]的[[平展景]]、[[平坦景]]等与概形自身等同起来，
  从而将这些景视为空间；一般的景则代表更一般的空间。
  而意象的概念则是进一步的抽象：我们将意象视为相应的景所代表的空间，
  从而意象的[[对象]]可以视作该空间上的层。
  这种视角有时比景的观点更加自然，
  例如景之间有时不能定义好的态射，
  但相应的意象之间却可以。

## 定义

### 意象

::: definition {@thm:意象}
称[[范畴]] $\mathcal{X}$ 为**意象**，
或称为 **Grothendieck 意象**，
如果存在[[景]] $\mathcal{C}$，使得
$\mathcal{X}$ [[范畴等价|等价]]于 $\mathsf{Sh}(\mathcal{C})$，
其中 $\mathsf{Sh}(\mathcal{C})$
是景 $\mathcal{C}$ 上取值在[[集合范畴]]上的[[层]]构成的范畴。
:::

意象之间可以定义态射，它们是层的[[前推层|前推]]和[[拉回层|拉回]]的类比。

::: definition
两意象之间的**态射** $f \colon \mathcal{X} \to \mathcal{Y}$，
有时称为**几何态射**，
是一对[[伴随函子]]
\[
(f^{-1} \dashv f_*) \colon \mathcal{Y} \rightleftarrows \mathcal{X},
\]
其中 $f^{-1}$ 是[[正合函子]]。
函子 $f_*$ 和 $f^{-1}$ 分别称为**前推**和**拉回**。
:::

### 初等意象

还有一种更弱的意象的概念，称为初等意象。
所有上面定义的意象都是初等意象。

::: definition
称[[范畴]] $\mathcal{X}$ 为**初等意象**，
如果满足以下条件：

- $\mathcal{X}$ 具有有限[[极限 (范畴论)|极限]]。

- $\mathcal{X}$ 为[[积闭范畴]]。

- $\mathcal{X}$ 具有[[子对象分类子]]。

有时也会额外加入以下条件：

- $\mathcal{X}$ 为[[局部积闭范畴]]。

- $\mathcal{X}$ 具有有限[[余极限]]。

- $\mathcal{X}$ 为[[Heyting 范畴]]。

- $\mathcal{X}$ 为[[预意象]]。

:::

## 例子

- [[集合范畴]]是意象，
  它是[[单点空间]]上所有集合层构成的范畴。
  作为空间，该意象对应于单点空间。

- [[光滑集合]]的范畴是意象，
  它是 [[Euclid 空间]]及其之间[[光滑映射]]构成的景上所有集合层构成的范畴。

- 对[[代数几何]]中使用的[[景]]，例如 [[Zariski 景]]、[[平展景]]、
  [[平坦景]]、[[晶体景]]，均对应相应的意象。
  作为空间，这些意象对应于相应的[[概形]]。

## 性质

### 与景的关系

::: proposition
景之间的态射 $f \colon \mathcal{C} \to \mathcal{D}$
（将其下范畴间的函子记为 $u \colon \mathcal{D} \to \mathcal{C}$）
诱导了意象之间的态射 $f \colon \mathsf{Sh}(\mathcal{C})\to \mathsf{Sh}(\mathcal{D})$，
定义为：
\[
\begin{gathered}
  f_* \mathcal{F}(U) = \mathcal{F}(u(U)) \\
  f^{-1} \mathcal{G}(V) = \operatornamewithlimits{colim}_{U \in I^{\mathrm{op}}} \mathcal{G}(U)
\end{gathered}
\]
其中 $I$ 是由所有态射 $V \to u(U)$
以及它们之间的相容态射构成的范畴。
:::

::: remark
意象间的态射未必由景之间的态射诱导，
例如[[晶体意象]]的态射一般无法由[[晶体景]]诱导。
:::

### 点与茎

::: definition [点]
意象 $\mathcal{X}$
上的**点**是指形如
$p \colon \mathsf{Set} = \mathsf{Sh}(*) \to \mathcal{X}$ 的态射。

特别地，由定义可以看出，拓扑空间中的一个点诱导了相应的意象中的点。
:::

::: definition [茎]
对意象 $\mathcal{X}$ 中的对象（即 $\mathcal{C}$ 上的层）
$\mathcal{F}$ 在点 $p$ 处的**茎**为 $p^{-1}\mathcal{F}$。
:::
