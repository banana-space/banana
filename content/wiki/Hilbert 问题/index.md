**Hilbert 问题**指德国数学家 [[David Hilbert]] 于 1900 年提出的
23 个问题。它们在当时都是未解问题，且很多对后世数学的发展影响深远。
但由于那个年代数学刚刚开始进行严格的公理化，一些问题陈述得比较笼统。

## 问题列表

| 序号 | 问题 | 状态 |
| --- | --- | --- |
| [[Hilbert 第一问题\|一]] | [[连续统假设]]：不存在[[基数]]严格介于[[自然数]]和[[实数]]之间的集合。 | 已解决。已证明其与 [[ZFC 集合论]]相容且独立。相容性由 [[Kurt Gödel]] 于 1940 年证明，独立性由 [[Paul Cohen]] 于 1963 年证明。 |
| [[Hilbert 第二问题\|二]] | [[Peano 公理]]的相容性。 | 已解决。[[Kurt Gödel]] 于 1931 年证明其著名的[[Gödel 不完备性定理\|不完备性定理]]，说明 Peano 公理无法证明自身相容。而 [[Gerhard Gentzen]] 于 1936 年使用[[初级递归算术]]理论，假设直至 [[Epsilon 数\|$\varepsilon_0$]] 的[[超限归纳法]]，证明了 Peano 公理相容。 |
| [[Hilbert 第三问题\|三]] | 给定体积相等的两个[[多面体]]，是否总能将一个切成有限个多面体，然后通过平移、旋转组合成另一个？ | 已解决。[[Max Dehn]] 于 1900 年用其[[Dehn 不变量\|不变量]]证明不能。 |
| [[Hilbert 第四问题\|四]] | 找出所有使得[[直线]]都是[[测地线]]的[[度量]]。 | 过于笼统，难以讨论。 |
| [[Hilbert 第五问题\|五]] | 连续群是否都是 [[Lie 群]]？ | 如理解成“拓扑流形群是否都是 Lie 群”，则回答是肯定的，由 [[Andrew Gleason]]、[[Deane Montgomery]]、[[Leo Zippin]] 于 1953 年证明。但如理解成“流形自同胚群的局部紧子群都是 Lie 群”，则其尚未解决。 |
| [[Hilbert 第六问题\|六]] | [[物理学]]的公理化：(1) [[统计物理]]的基石——[[概率论]]的公理化；(2) 从原子观点出发，严格地推出连续体的运动规律。 | [[Andrey Kolmogorov]] 于 1933 年将概率论公理化。 |
| [[Hilbert 第七问题\|七]] | 是否对于[[代数数]] $a$ 以及[[无理数\|无理]]代数数 $b$，$a^b$ 都是[[超越数]]？ | 已由 [[Alexander Gelfond]] 与 [[Theodor Schneider]] 于 1934 年独立解决。参见 [[Schneider–Lang 定理]]。 |
| [[Hilbert 第八问题\|八]] | 理解素数分布：(1) [[Riemann 猜想]]及其[[广义 Riemann 猜想\|推广]]；(2) [[Goldbach 猜想]]；(3) [[孪生素数猜想]]。 | Riemann 猜想几无进展，后两猜想也只有一些弱形式。如[[张益唐]]于 2013 年证明素数间隔的[[下极限]]有限，不大于 $7\times10^7$；其后该数被缩小至 $246$。 |
| [[Hilbert 第九问题\|九]] | 找到一般[[数域]]中[[二次互反律\|互反律]]的最广形式。 | [[Emil Artin]] 于 1930 年完成的 [[Artin 互反律]]解决此问。也可认为 [[Langlands 纲领]]才是最广形式。 |
| [[Hilbert 第十问题\|十]] | 找到[[算法]]来确定任意给定的[[整数不定方程]]有没有解。 | [[Yuri Matiyasevich]] 于 1970 年证明不存在此种算法。见 [[Matiyasevich–Robinson–Davis–Putnam 定理]]。 |
| [[Hilbert 第十一问题\|十一]] | 理解一般[[数域]]上的[[二次型]]。 | [[类域论]]部分地解决了这一问题。 |
| [[Hilbert 第十二问题\|十二]] | 将 [[Kronecker–Weber 定理]]推广至一般[[数域]]。 | [[Goro Shimura]] 与 [[Yutaka Taniyama]] 于 1961 年解决了 [[CM 域]]情形。一般情形则是 [[Langlands 纲领]]的一部分，尚未解决。 |
| [[Hilbert 第十三问题\|十三]] | 七次方程是否有求根公式，其中只含有二元[[连续函数]]及其[[复合]]？ | [[Vladimir Arnold]] 于 1957 年证明存在。但他认为 Hilbert 想要[[解析函数]]，这样则尚未解决。 |
| [[Hilbert 第十四问题\|十四]] | [[代数群]]作用在[[多项式环]]上，其不动元组成的子环是否[[有限生成代数\|有限生成]]？ | [[Masayoshi Nagata]] 于 1959 年给出反例。 |
| [[Hilbert 第十五问题\|十五]] | 严格化 [[Schubert 演算]]。 | 随着现代[[代数几何]]特别是[[计数几何]]的发展，此问题已完全解决。用现代的语言说，Schubert 演算就是在 [[Grassmann 簇]]或[[旗簇]]中算一些[[相交数]]。 |
| [[Hilbert 第十六问题\|十六]] | 实代数对象的拓扑学：(1) 实[[代数曲线]]的连通分支数及其相对位置；(2) 平面实代数[[向量场]]的[[极限环]]个数及其位置。 | 早在 1876 年，[[Axel Harnack]] 就证明了 $n$ 次实代数曲线的连通分支数不超过 $\frac{n^2-3n+4}{2}$，且这是最优上界。但其相对位置，如同胚于圆的分支有何互相包含之关系，我们仍知之甚少。关于代数向量场的极限环，[[Yulii Ilyashenko]] 与 [[Jean Écalle]] 于 1992 年证明了其只有有限个，但是否有关于次数的一致上界尚为未知。 |
| [[Hilbert 第十七问题\|十七]] | 将恒非负的实[[有理函数]]表为平方和。 | 由 [[Emil Artin]] 于 1927 年用其[[序域]]理论解决。 |
| [[Hilbert 第十八问题\|十八]] | 空间堆积问题：(1) $\mathbb{R}^n$ 上具有有界[[基本域]]的离散等距群作用是否只有有限多种？(2) 是否存在 $\mathbb{R}^3$ 的有界子集，如只允许其平移、旋转则无法密铺 $\mathbb{R}^3$，但允许反射就可以？(3) $\mathbb{R}^3$ 的球最密堆积长什么样，密度有多少？ | 第一问由 [[Ludwig Bieberbach]] 于 1911 年解决，回答为肯定。第二问由 [[Karl Reinhardt]] 于 1928 年解决，亦为肯定；提问题时 Hilbert 认为其答案在 $\mathbb{R}^2$ 为否定，但 1933 年 [[Heinrich Heesch]] 作出了 $\mathbb{R}^2$ 中的例子。第三问由 [[Thomas Hales]] 于 1998 年解决。 |
| [[Hilbert 第十九问题\|十九]] | 具有[[解析函数\|解析]]系数的正则[[变分问题]]，其解是否总为解析？ | 由 [[Ennio de Giorgi]] 与 [[John Nash]] 于 1957 年以不同的方法独立解决，回答为肯定。 |
| [[Hilbert 第二十问题\|二十]] | 给定[[边值]]的[[变分问题]]是否总有解？ |  |
| [[Hilbert 第二十一问题\|二十一]] | 构造全纯[[线性微分方程]]，具有给定的[[同道群]]。 | 其现代陈述为 [[Riemann–Hilbert 对应]]，[[Masaki Kashiwara]] 与 [[Zoghman Mebkhout]] 于 1984 年独立得到其最广形式。 |
| [[Hilbert 第二十二问题\|二十二]] | [[复流形]]的一致化问题。 | [[Paul Koebe]] 于 1907 年解决了一维情形，即[[一致化定理]]。高维情形这相当于问复流形分类，至今仍公认十分困难。 |
| [[Hilbert 第二十三问题\|二十三]] | [[变分法]]的进一步发展。 | 过于笼统，难以讨论。 |
