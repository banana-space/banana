在[[图论]]中，**图同态**是[[图]]之间的[[映射]]，保持图中边和顶点的关系。

## 定义

### 图同态

::: definition [图同态]
对于[[图]] $G₁ = (V₁, E₁, d₁), G₂ = (V₂, E₂, d₂)$，
它们之间的**图同态**，记作 $f \colon G₁ → G₂$，
包含如下信息：

- 映射 $f\colon V₁ → V₂$，

- 映射 $f\colon E₁ → E₂$，

且满足如下条件：

- 对任何 $e ∈ E₁$，若 $d_1 (e) = (x, y)$，
  则在 $\bigl< {V_2 \atop 2} \bigr>$ 中有
  \[
  d_2 (f (e)) = (f (x), f (y)).
  \]

:::

::: definition [图范畴]
所有[[图]]及其间的图同态构成[[范畴]] $\mathsf{Graph}$，
称为**图范畴**。
:::

### 有向图同态

::: definition [有向图同态]
对于[[有向图]] $G₁ = (V₁, E₁, s₁, t₁), G₂ = (V₂, E₂, s₂, t₂)$，
它们之间的**有向图同态**，记作 $f \colon G₁ → G₂$，
包含如下信息：

- 映射 $f\colon V₁ → V₂$，

- 映射 $f\colon E₁ → E₂$，

且满足如下条件：

- 对任何 $e ∈ E₁$，都有
  \[
  \begin{aligned}
    s_2 (f (e)) & = f (s_1 (e)), \\
    t_2 (f (e)) & = f (t_1 (e)).
  \end{aligned}
  \]

:::

::: definition [有向图范畴]
所有[[有向图]]及其间的有向图同态构成[[范畴]] $\mathsf{Quiv}$，
称为**有向图范畴**或**箭图范畴**。
:::

## 性质

- 图范畴和有向图范畴中，[[始对象]]是[[空图]]，[[终对象]]是只有一个顶点、一条边的图。

- 有向图范畴有[[子对象分类子]]，证明参见该文。
