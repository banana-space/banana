**势**是[[集合]]的[[元素]]个数。
例如，若一[[有限集]]含 $n$ 个元素，则其势为 $n$。
而不同的无穷集合之间也可比较大小，
故引入势的概念，将集合的元素个数用一个[[基数]]描述，
以刻画不同大小的无穷大。

集合 $X$ 的势通常记为 $|X|$ 或 $\#X$ 或 $\operatorname{card} X$。

## 定义

::: definition [势]
设 $X$ 是[[集合]]。
$X$ 的**势**是指最小的[[序数]] $\alpha$，
使得 $X$ 与 $\alpha$ 之间存在[[双射]]。
这里，$\alpha$ 的存在性由[[良序定理]]（依赖于[[选择公理]]）得到。
$X$ 的势通常记作
\[
|X| \ 或 \ \# X \ 或 \ \operatorname{card} X
\]
:::

这样由[[基数]]的定义，集合 $X$ 的势即是一个[[基数]]，
且是唯一的能与它建立双射的基数。

## 性质

作为合理的“元素个数”概念，势应当满足，也确实满足以下符合直观的性质。

::: proposition
设 $X, Y$ 是集合。

- 若存在[[双射]] $f \colon X \to Y$，则 $|X| = |Y|$。

- 若存在[[单射]] $f \colon X \to Y$，则 $|X| \leq |Y|$。

- 若存在[[满射]] $f \colon X \to Y$，则 $|Y| \leq |X|$。

:::

## 例子

- [[有限集]]的势为[[自然数]]。
  这是其元素个数的严格定义，
  事实上也是所有[[计数]]的严格定义。

- 势等于 $|\mathbb{N}|$ 的集合称为[[可数集]]；
  势大于 $|\mathbb{N}|$ 的集合称为[[不可数集]]。
