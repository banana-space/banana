在[[逻辑学]]中，
**与**是[[逻辑连接词]]的一种，常记为 $\wedge$。

在经典的[[命题逻辑]]中，对[[命题]] $p$、$q$ 而言，
命题 $p \wedge q$（读作“$p$ 与 $q$”或“$p$ 且 $q$”）
是指 $p$、$q$ 均成立。
换言之，有以下的[[真值]]表：

| $p$ | $q$ | $p \wedge q$ |
| :-: | :-: | :-: |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 假 |
| 假 | 假 | 假 |

在[[类型论–范畴论–逻辑学类比]]下，
与运算对应于[[积类型]]、[[积空间]]等运算。
大致而言，说两个类型或空间的积非空，
即是说原来两个类型或空间均非空。
