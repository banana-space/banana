**代数群**指的是[[域]]上[[有限型态射|有限型]][[群概形]]。
直观地说，代数群即一个[[群]]，同时具有[[代数簇]]的结构，
使得群运算都是代数簇的态射。

代数群是 [[Lie 群]]在[[代数几何]]中的类比，
许多 Lie 群上的性质都可以类比到代数群上，
例如[[半单 Lie 群]]的类比是[[半单代数群]]，
它们的表示论也类似。
不过，正[[特征 (环论)|特征]]基域上的代数群还会有更复杂的结构，
例如它可能不是[[既约]]的。

[[线性代数群]]是一类常见的代数群，
例如[[一般线性群]] $\mathrm{GL} (n; k)$ 等。

## 定义

::: definition
域 $k$ 上**代数群**指 $k$ 上[[有限型态射|有限型]][[群概形]]，
即四元组 $(G,m,e,i)$，$G$ 为 $k$ 上有限型概形，
$m\colon G\times_kG\to G$，
$e\colon\operatorname{Spec}k\to G$，
$i\colon G\to G$ 为 $k$-态射，分别满足[[群]]乘法、
单位元、逆元需满足的公理。如乘法满足[[交换律]]，
则称其为**交换代数群**。
:::

::: remark
有时也用代数群一词专指[[仿射代数群]]。由 [[Chevalley 结构定理]]，
[[完美域]]上[[光滑态射|光滑]]代数群都有仿射正规子群，
商掉之后为 [[Abel 簇]]。这样，
代数群的研究便多多少少可化归为仿射代数群与 Abel 簇的研究。
:::

::: remark
代数群的子群、同态、单、满等概念和一般的[[群概形]]没什么区别，
见该条目。
:::

## 例子

- $\operatorname{Spec}k$ 本身是代数群，
  称为**平凡群**，记作 $1$ 或 $0$。

- 更一般地，[[有限群]]都是代数群。

- [[仿射直线]] $\mathbb{A}^1$ 关于加法构成代数群，
  记作 $\mathbb{G}_a$。

- $\mathbb{A}^1\setminus0$ 关于乘法构成代数群，
  记作 $\mathbb{G}_m$。

- 各种[[线性代数群]]都是代数群，如[[一般线性群]]、
  [[正交群]]等。

- [[椭圆曲线]]是代数群。

- 设 $k$ 为特征 $p$，考虑函子
  $\alpha_p(S)=\{x\in\Gamma(S,\mathcal{O}_S)\mid x^p=0\}$，
  即 $\mathbb{G}_a$ 的 [[Frobenius 态射]]的核。
  这是不既约的代数群。

- 设 $k$ 为特征 $p$，考虑函子
  $\mu_p(S)=\{x\in\Gamma(S,\mathcal{O}_S^\times)\mid x^p=1\}$，
  即 $\mathbb{G}_m$ 的 [[Frobenius 态射]]的核。
  这是不既约的代数群。

- 设 $k$ 为特征 $p$，$a\in k\setminus k^p$，
  则 $x^p+ay^p\in k[x,y]$ 是不可约多项式。
  考虑代数群 $\operatorname{Spec}k[x,y]/(x^p+ay^p)=
    \ker(x^p+ay^p\colon\mathbb{G}_a^2\to\mathbb{G}_a)$。
  它是[[整概形]]，特别地[[既约概形|既约]]，但不在 $k$ 上光滑。

## 性质

代数群的齐性带来很多好性质。

::: proposition
代数群都[[分离态射|分离]]。一般地，域上[[群概形]]都分离。
:::

::: proposition
代数群只要[[连通概形|连通]]就[[几何不可约]]。
事实上这也对域上群概形都成立。所以对 $k$ 上群概形 $G$，
其单位元处连通分支 $G^0$ 是 $k$ 上几何不可约群概形。
:::

::: proposition
代数群只要[[几何既约]]就[[光滑态射|光滑]]。
特别地，[[完美域]]上代数群只要既约就光滑。
:::

::: proposition
代数群的子群都是[[闭子概形]]。
:::

::: proposition
$G$ 是 $k$ 上代数群。则 $\Omega_{G/k}$ 是 $G$
上平凡向量丛。
:::

::: corollary [Cartier]
特征 $0$ 域上代数群光滑。
:::

::: proof
这是因为特征 $0$ 域上[[有限型概形]][[光滑态射|光滑]]当且仅当其
[[Kähler 微分]]是向量丛，参见相关条目。
:::

::: theorem [商]
设 $G$ 是 $k$ 上代数群，$H$ 是其子群。则 [[fpqc 层]]
$G/H$ 为[[可表函子|可表]]。换言之，可以定义**商概形**
$G/H$，在 $H$ 正规时为代数群，称为**商群**。
:::

::: proof
依定义 $G/H$ 为 $k$ 上有限表现[[代数空间]]。
域上有限表现代数空间必有开稠子空间是概形，
而 $G$ 可迁作用于 $G/H$，故整个 $G/H$ 都是概形。
在 $H$ 正规时，$G/H$ 本身就是群层，所以是群概形。
:::

::: remark
也有使用[[群表示]]的证明，但这个证明是康庄大道。
域上有限表现的齐性代数空间是概形。
:::
