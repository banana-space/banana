在 [[Euclid 几何]]中，
**正多胞体**是一类高度对称的（凸）[[多胞体]]，
包括二维的[[正多边形]]、三维的[[正多面体]]以及它们在高维空间中的推广。
直观上，正多胞体的所有顶点、线、面等各维组成部分均等价。
例如下图就是四维空间中[[正一百二十胞体]]的透视投影。

![](120-cell.png?width=200)

从群论角度看，任何一个正多胞体的对称群都是有限 [[Coxeter 群]]，
使其能够通过 [[Coxeter 图]]完全分类：
正多胞体到有限、无分岔且“定向”（即有从左到右的顺序）的 Coxeter 图有一一对应。

正多胞体等价于[[球面]]的[[正镶嵌]]：
取正多胞体的表面，并把它“吹”到球面上，即给出了球面的正镶嵌。
在这种观点下，也可以将 [[Euclid 空间]]和[[双曲空间]]的正镶嵌视为正多胞体。
此外，如果允许凹多胞体或自交多胞体，也有类似的对称图形，称为[[星形正多胞体]]。

## 定义

::: definition
设 $P$ 是 $n$ 维 [[Euclid 空间]] $\mathbb{E}^n$ 中的 $n$ 维（凸）[[多胞体]]。
$P$ 的**旗**是指严格递增的面序列
\[
F_0 \subset F_1 \subset \cdots \subset F_{n-1} \subset P,
\]
其中每个 $F_k$ 是 $P$ 的 $k$ 维面。
若 $P$ 的[[对称群]]（所有保持 $P$ 作为点集不变的[[等距变换]]构成的群）
在 $P$ 的所有旗组成的集合上的[[群作用|作用]]是[[传递作用|传递的]]，
则称 $P$ 为**正多胞体**。
换言之，对 $P$ 的任意两个旗，均存在一个对称变换将其中之一映为另一个。
:::

如果两个正多胞体相似，则视为一样的。

::: remark
上述定义与以下更直观的递归定义等价：

- 当 $n = 2$ 时，正多边形即所有边等长且所有内角相等的凸多边形。

- 当 $n \geq 3$ 时，多胞体是正的当且仅当它的所有[[面 (几何)|面]]
  （各维度的面）都是正多胞体，且所有[[顶点图]]也都是正多胞体。

:::

## 性质

### 对称群

正多胞体的对称群由反射生成，构成 [[Coxeter 群]]。

::: theorem [与 Coxeter 图的对应]
正多胞体与有限型、连通、无分岔的 Coxeter 图（带有定向）一一对应。

具体来说，设 $P$ 是 $n$ 维正多胞体，
取 $P$ 的一个旗 $F_0 \subset F_1 \subset \cdots \subset F_{n - 1} \subset F_n = P$，
记 $x_i$ 为面 $F_i$ 的中心，这些点张成 $n$ 维单形。则有

- 令 $s_i$（$0 \leq i \leq n - 1$）为关于此单形中与 $x_i$ 相对的面所在超平面的反射，
  则这些反射生成 $P$ 的对称群。

- 此单形是 $P$ 在其对称群下的[[基本区域]]。

- 相邻反射 $s_i$ 与 $s_{i + 1}$ 的乘积的[[阶]]为某个整数 $p_i \geq 3$，
  其中 $0 \leq i \leq n - 2$；
  而当 $|i - j| > 1$ 时 $s_i$ 与 $s_j$ 可交换（即乘积的阶为 $2$）。
  由此，$P$ 的对称群是 Coxeter 群，
  且它的 [[Coxeter 图]]没有分岔，还有一个从 $s_0$ 到 $s_{n - 1}$ 的方向。
  这 $n - 1$ 个整数 $(p_0, p_1, \dots, p_{n - 2})$ 称为 $P$ 的 **Schläfli 符号**，
  记作 $\{p_0, p_1, \dots, p_{n - 2}\}$。

反过来，对上述 Coxeter 图，
存在 $\mathbb{E}^n$ 中的单形，
它沿除了一个面之外的所有面的反射对应于 Coxeter 群的生成元。
此单形在 Coxeter 群作用下拼成正多胞体。
:::

这一构造也可以推广到 [[Euclid 空间]]或[[双曲空间]]的[[正镶嵌]]上，
也可以用来构造[[半正多面体]]。

### 几何性质

正多胞体还有一系列源自对称性的几何性质。

::: proposition [几何性质]
正多胞体的所有顶点均位于同一个[[球面]]上，
且所有[[二面角]]相等。类似地，各维面的中心也分别位于共心的超球面上。
:::

::: proposition [对偶]
任一正多胞体 $P$ 均存在一个[[对偶多胞体]] $P^*$，
其顶点为 $P$ 的胞腔（$n - 1$ 维面）的中心。$P^*$ 也是正多胞体，
且对称群与 $P$ 相同。若 $P$ 的 Schläfli 符号为 $\{p_0, p_1, \dots, p_{n - 2}\}$，
则 $P^*$ 的符号为 $\{p_{n - 2}, \dots, p_1, p_0\}$。
在 Coxeter 群的观点下，将生成反射的排列顺序反转即得到对偶多胞体。
:::

::: proposition [子群与子结构]
设 $P$ 是 $n$ 维正多胞体，对称群 $W$ 由反射 $s_0, \dots, s_{n - 1}$ 生成，
相应的 Schläfli 符号为 $\{p_0, \dots, p_{n - 2}\}$。

- $P$ 的[[顶点图]]是 $n - 1$ 维正多胞体，
  其 Schläfli 符号为 $\{p_1, \dots, p_{n - 2}\}$，
  对称群由 $s_1, \dots, s_{n - 1}$ 生成的[[子群]]给出。

- $P$ 的一个胞腔（$n - 1$ 维面）是 $n - 1$ 维正多胞体，
  其 Schläfli 符号为 $\{p_0, \dots, p_{n - 3}\}$，
  对称群由 $s_0, \dots, s_{n - 2}$ 生成。

- 更一般地，对任意 $0 \leq k \leq n - 1$，
  其余生成元 $s_0, \dots, s_{k - 1}, s_{k + 1}, \dots, s_{n - 1}$ 生成的子群
  是上述旗的记号下，面 $F_k$ 的[[稳定化子]]。

:::

## 分类

根据上述群论表述，
凸正多胞体的分类等价于有限型、无分岔、定向 [[Coxeter 图]]的分类，
其完整分类如下。

::: example [二维：正多边形]
对每一个整数 $m \geq 3$，
平面上的正 $m$ 边形是二维正多胞体。
其Schläfli 符号为 $\{m\}$，
对称群是[[二面体群]] $I_2(m)$，阶为 $2m$。
常见的例子包括正三角形（$\{3\}$）、正方形（$\{4\}$）、
正五边形（$\{5\}$）等。
:::

::: example [三维：Plato 立体]
三维空间中存在五种正多胞体，即 [[Plato 立体]]：

- [[正四面体]]：符号 $\{3, 3\}$，对称群 $A_3$，阶 $24$。属于[[正单形]]系列。

- [[正方体]]：符号 $\{4, 3\}$，对称群 $B_3$，阶 $48$。属于[[超立方体]]系列。

- [[正八面体]]：符号 $\{3, 4\}$，对称群 $B_3$，阶 $48$。属于[[正轴体]]系列，且是正方体的对偶。

- [[正十二面体]]：符号 $\{5, 3\}$，对称群 $H_3$，阶 $120$。例外类。

- [[正二十面体]]：符号 $\{3, 5\}$，对称群 $H_3$，阶 $120$。例外类，与正十二面体互为对偶。

:::

::: example [四维正多胞体]
四维空间中存在六种正多胞体：

- [[正五胞体]]（$4$-正单形）：$\{3, 3, 3\}$，对称群 $A_4$，阶 $120$。

- [[正八胞体]]（$4$-超立方体）：$\{4, 3, 3\}$，对称群 $B_4$，阶 $384$。

- [[正十六胞体]]（$4$-正轴体）：$\{3, 3, 4\}$，对称群 $B_4$，阶 $384$。与正八胞体互为对偶。

- [[正二十四胞体]]：$\{3, 4, 3\}$，对称群 $F_4$，阶 $1152$。自对偶的例外类。

- [[正一百二十胞体]]：$\{5, 3, 3\}$，对称群 $H_4$，阶 $14400$。例外类。

- [[正六百胞体]]：$\{3, 3, 5\}$，对称群 $H_4$，阶 $14400$。例外类，与正一百二十胞体互为对偶。

其中前三类分别为三维三类无穷系列在四维的延伸，后三类是四维特有的例外正多胞体。
:::

::: example [五维及以上：三类无穷系列]
当空间维数 $n \geq 5$ 时，正多胞体仅有以下三个无穷系列，不再有例外。

- **正单形**（$n$-单形）：
  Schläfli 符号为 $\{3, 3, \dots, 3\}$（共 $n - 1$ 个 $3$），
  对称群为 $A_n$。其顶点数为 $n + 1$，每个顶点处有 $n$ 条棱相交。

- **超立方体**（$n$-立方体）：
  Schläfli 符号为 $\{4, 3, \dots, 3\}$（一个 $4$ 后接 $n - 2$ 个 $3$），
  对称群为 $B_n$。顶点数为 $2^n$。

- **正轴体**（$n$-正轴体）：
  Schläfli 符号为 $\{3, \dots, 3, 4\}$（$n - 2$ 个 $3$ 后接一个 $4$），
  对称群亦为 $B_n$。顶点数为 $2n$，且与超立方体互为对偶。

当 $n = 3, 4$ 时，上述三类均存在，只是出现了额外的例外类。
:::
