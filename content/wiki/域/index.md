**域**是一种[[代数结构]]，
它是具备[[加法|加]]、[[减法|减]]、[[乘法|乘]]、[[除法|除]]四则运算的[[集合]]，
并且，加法、乘法满足通常的运算律，包括[[交换律]]、[[结合律]]、[[分配律]]。
例如，

- 我们常见的数系中，
  [[有理数]]集 $\mathbb{Q}$、
  [[实数]]集 $\mathbb{R}$、
  [[复数]]集 $\mathbb{C}$ 都是域。

- [[整数]]集 $\mathbb{Z}$ 不是域，因为整数相除的结果不一定是整数。

研究域的理论称为[[域论]]。
域论中一个重要的分支是 [[Galois 理论]]，
研究域之间的[[域扩张]]的结构。
该理论也是现代[[代数学]]的前驱，
促使了[[群论]]的发展。
通过 Galois 理论，可以证明一类经典问题，
包括[[三等分角问题]]、[[倍立方问题]]、[[五次方程求根问题]]，是不可解的。

在[[代数学]]和[[几何学]]中，常常选取一个域作为“所有[[数]]的集合”，
然后再研究这个域上的各种数学结构。
因此，在[[线性代数]]、[[同调代数]]、[[表示论]]、[[代数几何]]等等学科中，
域都是最基本的概念之一。

在某种意义下，域是最简单的[[环]]。
例如，在[[代数–几何对偶]]的观点下，环对应于[[空间]]，而域对应于[[单点空间]]。

## 定义

::: definition [域]
**域**是非[[零环|零]]的[[交换环]]，
其中所有非零元素都关于乘法可逆。

具体地说，域是三元组 $(F, {+}, {\cdot})$，
其中 ${+}, {\cdot}$ 是 $F$ 上的[[二元运算]]，
并满足以下条件：

- $(F, {+})$ 构成 [[Abel 群]]，其单位元记为 $0$。
  具体来说，加法应满足以下性质：

  - 加法满足[[结合律]]：对任意 $a, b, c \in F$，有
    \[
    (a + b) + c = a + (b + c).
    \]

  - 加法满足[[交换律]]：对任意 $a, b \in F$，有
    \[
    a + b = b + a.
    \]

  - 加法具有单位元 $0 \in F$，称为**零元**，
    满足[[单位律]]：对任意 $a \in F$，有
    \[
    0 + a = a.
    \]

  - 对任意 $a \in F$，存在元素 $-a \in F$，使得
    \[
    a + (-a) = 0.
    \]

- $(F, {\cdot})$ 构成交换[[幺半群]]，其单位元记为 $1$，
  且 $(F \setminus \{ 0 \}, {\cdot})$ 构成 [[Abel 群]]。
  常常记 $F^\times = F \setminus \{ 0 \}$。
  具体来说，乘法应满足以下性质：

  - 乘法满足[[结合律]]：对任意 $a, b, c \in F$，有
    \[
    (a b) c = a (b c).
    \]

  - 乘法满足[[交换律]]：对任意 $a, b, c \in F$，有
    \[
    a b = b a.
    \]

  - 乘法具有单位元 $1 \in F$，称为**幺元**或域的**单位元**，
    满足[[单位律]]：对任意 $a \in F$，有
    \[
    1 a = a.
    \]
    并且，我们要求 $1 \neq 0$。

  - 对任意 $a \in F \setminus \{ 0 \}$，存在元素 $a^{-1} \in F$，
    称为 $a$ 的**逆元**，满足
    \[
    a a^{-1} = 1.
    \]

- 乘法对加法满足[[分配律]]：对任意 $a, b, c \in F$，有
  \[
  a (b + c) = a b + a c.
  \]

:::

::: definition [域同态]
两个域之间的**域同态**为其间的[[环同态]]。
:::

::: definition [域范畴]
所有域和域同态构成一个[[范畴]]，称为**域范畴**，记为
$\mathsf{Field}$。
:::

## 例子

- 在通常的四则运算下，
  [[有理数]]集 $\mathbb{Q}$、
  [[实数]]集 $\mathbb{R}$、
  [[复数]]集 $\mathbb{C}$ 都是域。

::: example [有限域]
**[[有限域]]** 是一类特殊的域，这些域只有有限个元素。
最简单的有限域形如 $\mathbb{F}_p$，其中 $p$ 是[[素数]]。该域的元素为
\[
\mathbb{F}_p = \{ 0, 1, \dotsc, p-1 \},
\]
其加法、乘法就是[[模算术|模]] $p$ 意义下的加法、乘法。
由于 $p$ 是素数，[[Bézout 引理]]保证了
$\mathbb{F}_p$ 中的非零元素都有乘法逆元，
从而 $\mathbb{F}_p$ 是域。
:::

::: example
\[
\mathbb{Q}(\sqrt{2})
=
\{a+b\sqrt{2}\mid a,b\in\mathbb{Q}\}.
\]
它是 $\mathbb{R}$ 的子域。对任意非零元素
$a+b\sqrt{2}$，其乘法逆元为
\[
(a+b\sqrt{2})^{-1}
=
\frac{a-b\sqrt{2}}{a^2-2b^2}.
\]
因此 $\mathbb{Q}(\sqrt{2})$ 是域。
:::

::: example [高斯有理数]
\[
\mathbb{Q}[i]
=
\{a+bi\mid a,b\in\mathbb{Q}\}
\]
是 $\mathbb{C}$ 的子域，称为[[高斯有理数]]域。
非零元素 $a+bi$ 的乘法逆元为
\[
(a+bi)^{-1}
=
\frac{a-bi}{a^2+b^2}.
\]
:::

更一般地

::: example
若 $d$ 是一个非平方的有理数，则
\[
\mathbb{Q}[\sqrt{d}]
=
\{a+b\sqrt{d}\mid a,b\in\mathbb{Q}\}
\]
是域，称为一个[[二次域]]。
它是 $\mathbb{Q}$ 的二次[[域扩张]]。
:::

::: example [有理函数域]
若 $F$ 是任意域，则以 $F$ 为系数的[[有理函数]]构成域
\[
F(t)
=
\left\{
  \frac{f(t)}{g(t)}
  \mathrel{}\middle|\mathrel{}
  f(t),g(t)\in F[t],\quad g(t)\neq 0
\right\}.
\]
这里 $t$ 是一个[[不定元]]。
:::

多项式环 $F[t]$ 本身通常不是域，但它的[[分式域]]
$F(t)$ 是域。

::: example [分圆域]
设 $n$ 是正整数，
\[
\zeta_n=e^{2\pi i/n}
\]
是一个本原 $n$ 次[[单位根]]。
由 $\zeta_n$ 在 $\mathbb{Q}$ 上生成的域
\[
\mathbb{Q}(\zeta_n)
\]
称为第 $n$ 个[[分圆域]]。
:::

## 性质

- 域的所有[[理想]]为 $\{ 0 \}$ 和其自身。

- 域同态一定是[[单射]]，因为其[[核 (代数)|核]]是域中的[[理想]]，从而必然是 $\{ 0 \}$。
  因此，每个域同态都给出一个[[域扩张]]。

- 不同[[特征 (代数)|特征]]的域之间不存在域同态。

