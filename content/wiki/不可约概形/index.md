在[[代数几何]]中，
**不可约概形**是一类[[概形]]。
大致说，这类概形仅由一个“部分”组成。
例如，下图中，左边的概形有两个“部分”，
即直线 $x = 0$ 与 $y = 0$。
因此，虽然该概形是[[连通空间|连通]]的，但它不是不可约的。
而右边的概形是不可约的，因为它只有一个“部分”。

```tikz
\begin{tikzpicture}
    \begin{scope}
        \draw[thick] (-1.5, 0) -- (1.5, 0) (0, -1.5) -- (0, 1.5);
        \node at (0, -2) {$x y = 0$};
    \end{scope}
    \begin{scope}[shift={(5,0)}]
        \draw[scale=0.75, domain=-1.4:1.4, smooth, thick] plot ({\x}, {\x*\x});
        \node at (0, -2) {$y-x^2=0$};
    \end{scope}
\end{tikzpicture}
```

上面所说的“部分”称为**不可约分支**，
也就是概形中极大的不可约[[闭子概形]]。

## 定义

::: definition [不可约空间] {@不可约空间}
[[拓扑空间]] $X$ 称为**不可约**的，如果

- $X$ 非空。

- 如果 $X = X_1 \cup X_2$，其中 $X_1, X_2$ 是 $X$ 的闭子集，
  那么 $X_1 = X$ 或 $X_2 = X$。

:::

::: remark
由于[[平凡对象不是单对象]]，[[空集]]不算做不可约空间。
:::

::: definition [不可约概形]
[[概形]] $X$ 称为**不可约**的，
如果 $X$ 的底[[空间拓扑|空间]]是不可约空间（@不可约空间）。
:::

## 性质

注意到不可约性仅与底空间有关而与结构层无关，有：

::: lemma [局部性质] {@局部性质}
- 不可约概形的每个[[开子概形]]都是不可约的。

- 如连通概形存在一组开覆盖，使得其中每个开集均不可约，
  则它是不可约概形。

:::

::: definition [不可约分支]
对任何概形，称其极大的不可约子集为该概形的**不可约分支**。
易见不可约分支是闭的。
:::

由于不可约子集的升链之并依然不可约，利用[[Zorn 引理]]易知

::: proposition
概形中的任何点均含于某个不可约分支中。
:::
