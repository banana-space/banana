在这一节中，我们要介绍拓扑学中构造空间的一个基本手段：粘贴。
比如，圆周 \(\mathbb{S}^{1}\) 应该可以通过将闭区间 \([0,1]\) 的两个端点 \(0\)、
\(1\) 粘接在一起而得到；
Möbius 带应该可以通过将方形\([0,1]\times[0,1]\) 的一对对边沿相反方向粘接而得到。
在拓扑中描述“粘贴”这个概念可以通过“商映射”和“商拓扑”来实现。

## 关系与等价关系 {@situation:relation}

我们的目的是要“粘合”拓扑空间。
作为准备工作，我们先来描述如何在集合的层面上实行“粘合”。
它在数学上对应的概念叫做“等价关系的等价类”。

::: definition {@definition:relation}
令 \(X\) 为一个集合。

1. \(X\) 上的一个**关系（relation）**，
   或**对应（correspondence）**
   是乘积集合 \(X \times X\) 的一个子集 \(R\)。
   如果 \((x,x') \in R\)，我们用符号“\(xRx'\)”表示，并且称元
   素 \(x\) 与 \(y\)（关于关系 \(R\)）相关。

   \(X\) 上的关系通常用下图
   \[
   \begin{tikzcd}
     R \ar[shift left]{r}{p_1} \ar[shift right,swap]{r}{p_0} & X
   \end{tikzcd}
   \]
   来表示。横着的两个箭头是两个投影映射在 \(R\) 上的限制。
   更一般地，任何两个映射
   \(p_{0},p_{1}: T \rightrightarrows X\) 可以给出一个映射
   \(p_0 \times p_1: T \to X \times X\)。
   从而给出一个关系 \(p(T) \subset X \times X\)。

2. 关系 \(R\) 叫做**自反（reflexive）** 的，如果 \(xRx\) 对任何 \(x \in X\) 都成立。
   关系 \(R\) 叫做**对称（symmetric）** 的，如果 对任何 \(x,x' \in X\)，\(xRx'\) 推出 \(x'Rx\)。
   关系 \(R\) 叫做**传递（transitive）** 的，如果对任何 \(x,x',x'' \in X\)，
   \(xRx'\) 和 \(x'Rx''\) 推出 \(xRx''\)。
   关系 \(R\) 叫做一个 **等价关系（equivalence relation）**，
   如果它是对称的、自反的、传递的。

3. 显然，\(X \times X\) 自己就是一个等价关系。这个等价关系下，
   任何两个元素都“相关”。
   任何关系 \(R\) 都决定了一个等价关系 \(\mathcal{R}\)，这里 \(\mathcal{R}\) 是
   一切包含 \(R\) 的等价关系的交（这个交是非空的，因为 \(R \subset X \times X\)）。
   等价关系 \(\mathcal{R}\)
   叫做
   **由 \(R\) 生成的等价关系（equivalence relation generated by \(R\)）**。

4. 设 \(R\) 是集合 \(X\) 上的一个等价关系。
   则对任何 \(x \in X\)，元素 \(x\) 关于 \(R\)
   的**等价类（equivalence class）** 是集合
   \[
   [x] = \{y \in X : x R y\}.
   \]
   即 \(x\) 的等价类包括了一切“与 \(x\) 有关”的 \(X\) 中元素。
   集合 \([x]\) 中任何元素都叫做等价类 \([x]\) 的**代表元（representative）**。对同一等价类的
   两个代表元 \(x,y\)，我们有 \([x] = [y]\)。

5. 集合 \(X\) 关于等价关系 \(R\) 的一切等价类的全体构成一个集合，称为 \(X\) 关于
   \(R\) 的**商集（quotient set）**，记作 \(X/R\)。

:::

我们提供几个简单的例子。

::: example
假设我们要将下图所示的方形区域 \(S\) 的两条竖边纵坐标相等的点粘合起来，
作为集合我们所需要实行的操作如
下。我们在矩形纸条这个集合上引入等价关系 \(\sim\)，我们宣布

- \((a,b) \sim (a,b)\)，\(\forall (a,b) \in S\)，

- \((0,b) \sim (1,b)\)，\(\forall b \in [0,1]\)

![图 1：粘合正方形两条边](Topology_image6.svg?width=150)

则 \(S\) 关于 \(\sim\) 的商集，作为集合，就与圆柱的边界曲面一一对应了。
:::

::: example
在算术中常见的等价关系是同余。令 \(n\) 为整数，我们说整数 \(a\) 与 \(b\)
**模\(n\) 同余（congruent modulo \(n\)）**，记做
\(a \equiv b \mod n\)，如果 \(a - b\) 能够被 \(n\) 整除。容易验证
\(\bullet \equiv \bullet \mod n\) 是 \(\mathbb{Z}\) 上的等价关系。它的等价类被记
作 \(\mathbb{Z}/(n)\)。
:::

::: example {@example:fiber-of-map-define-equiv-relation}
令 \(f\colon  X \to Y\) 为一个映射。
我们宣布
\(x \sim_f y\) 当且仅当 \(f(x) = f(y)\)。
容易验证 \(\sim_f\) 是等价关系。它的等价类恰好是映射 \(f\) 的纤维。
事实上，任何等价关系都可以实现为某个映射 \(f\)。
如果 \(R\) 是 \(X\) 上等价关系，则将元素 \(x \in X\) 映射到它的等价类 \([x]\) 定
义了一个满映射 \(\pi:X \to X/R\)。这个映射在等价类 \([x]\) 上的纤维就是这个等价类里
的元素。于是 \(R = \sim_{\pi}\)。

映射 \(\pi:X \to X/R\) 满足如下泛性质：如果 \(f\colon X \to Y\) 是任何映射，满
足
\[
x R y \; \Longrightarrow \; f(x) = f(y)
\]
（即在 \(\pi\) 的纤维上，\(f\) 是常值，或
等价地，\(f\circ p_0 = f\circ p_1\)，其中 \(p_i\) 是投影映射在 \(R\) 上的限制），
则存在唯一的映射 \(\overline{f}: X/R \to Y\)，使得 \(f = \overline{f}\circ\pi\)。
:::

## 商拓扑

::: definition {@definition:quotient-topology}
令 \(X\) 为拓扑空间，\(Y\) 为集合，
\(f: X \to Y\) 为一个满射。
则 \(Y\) 的关于 \(f\) 的**商拓扑（quotient topology）**
定义如下：\(Y\) 的子集 \(U\) 被称为商拓扑下的开集，当且仅当 \(f^{-1}(U)\)
是 \(X\) 的开集。
:::

如果赋予 \(Y\) 关于映射 \(f: X \to Y\) 的商拓扑，那么很容易刻画什么样的从 \(Y\)
**映出**的映射是连续的。

::: proposition {@proposition:universal-property-final-topology}
记号如上。赋予 \(Y\) 商拓扑。
令 \(Z\) 为拓扑空间。
令 \(g\colon  Y \to Z\) 为映射。
则 \(g\) 连续的必要且充分条件是 \(g\circ f\) 连续。
:::

::: proof
如果 \(g\) 连续，那么 \(g \circ f\) 自然连续。
今设 \(g \circ f\) 连续。则对任何 \(Z\) 的开子集 \(V\)，
\((g\circ f)^{-1}(V) = f^{-1}(g^{-1}(V))\) 是 \(X\)
的开子集。根据商拓扑的定义，\(Y\) 的子集 \(g^{-1}(V)\)
是商拓扑下的开集。因此 \(g\) 是连续的。
:::

::: definition {@definition:quotient-map}
称拓扑空间之间连续映射 \(f\colon X\to Y\) 为**商映射（quotient map）**，
如果它是满射，且 \(Y\) 原本的拓扑与关于 \(f\) 的商拓扑一致。

拓扑空间 \(X\) 关于映射 \(f\colon  X \to Y\) 的**饱和（saturated）** 子集
是指形如 \(f^{-1}(Z)\)，\(Z \subset Y\) 的子集。映射 \(f\) 为商映射的必要且充
分条件为它是连续满射，并且将饱和开（闭）集映成开（闭）集。
:::

::: remark [等价关系的商空间] {@situation:quotient-with-respect-to-equivalence-relation}
若 \(X\) 是一个拓扑空间，\(R \rightrightarrows X\) 为 \(X\) 上的一个等价关系。则
我们赋予等价类的集合 \(X/R\) 关于映射 \(\pi: X \to X/R\) 的商拓扑。
这个拓扑叫做 \(X/R\) 的**商拓扑（quotient topology）**。
商集 \(X/R\) 以及其上的商拓扑叫做拓扑空间 \(X\) 关于等价关系 \(R\)
的**商空间（quotient space）**。
今后若无特别申明，当我们使用记号 \(X/R\) 时，我们总是使用商拓扑。
:::

::: proposition {@proposition:universal-property-quotient-space}
令
\[
\begin{tikzcd}
  R \ar[shift left]{r}{p_0} \ar[shift right,swap]{r}{p_1} & X
\end{tikzcd}
\]
为拓扑空间 \(X\) 上的等价关系。令 \(\pi:X \to X/R\) 为商映射。
设 \(f\colon  X \to Y\) 为连续映射，且满足 \(f\circ p_0 = f\circ p_1\)。
则存在唯一的连续映射 \(\overline{f}: X/R \to Y\) 使得 \(f=\overline{f}\circ \pi\)。
:::

::: proof
由于 \(f\) 在等价类上是常值，它在集合的层面上诱导了一个唯一的映射
\(\overline{f}\colon X/R \to Y\)。
我们要说明它是连续的。
根据 @proposition:universal-property-final-topology，
\(\overline{f}\) 的连续性由 \(f\) 的连续性导出。
:::

## 商映射的判据

考虑实数空间 \(\mathbb{R}\) 上的等价关系
\(a \sim b \Leftrightarrow a - b \in \mathbb{Z}\)。
映射
\[
p\colon \mathbb{R} \to \mathbb{S}^1,\quad
x \mapsto (\cos(2\pi x), \sin(2\pi x))
\]
的纤维恰好是关系 \(\sim\) 的等价类。根据之前的讨论，
我们已经能赋予商空间 \(\mathbb{R}/{\sim}\) 商拓扑了。
通过 @proposition:universal-property-quotient-space，
映射 \(p\) 给出了一个连续的双射
\(\overline{p}\colon\mathbb{R}/{\sim} \to \mathbb{S}^{1}\)。
我们希望说明 \(\overline{p}\) 是同胚。也就是说，\(\mathbb{S}^{1}\)
自己原本的拓扑与通过双射 \(\overline{p}\) 所获得的拓扑一致，即
\(\mathbb{S}^{1}\) 自身的拓扑是 \(p\) 的商拓扑。
换言之，我们必须说明 \(p\) 是一个商映射。

在这一小节里，我们介绍几个验证映射是商映射的方法。

### 通过证明截面的局部存在性*

首先我们给出一个一般的观察，它说明 对连续满射来说，它是“商映射”这个性质是
**一个靶空间上的局部性质（a property that is local on the target）**。

::: proposition {@proposition:quotient-local-on-target}
令 \(f\colon X \to Y\) 为连续满射。
如果 \(Y = \bigcup_{i\in I} U_{i}\)，且 \(U_i\) 是开集，
则连续满射 \(f\) 是商映射的必要充分条件是 \(f|_{f^{-1}(U_i)}:f^{-1}(U_i) \to U_i\)
都是商映射。
:::

::: proof
我们只验证充分性，将必要性留给读者验证。
如果 \(f^{-1}(V)\) 是 \(X\) 的开集，那么
\(f^{-1}(V) \cap f^{-1}(U_{i}) = f^{-1}(V \cap U_i)\) 为 \(f^{-1}(U_i)\) 的开集。
由于 \(f\) 在 \(f^{-1}(U_{i})\) 上的限制是商映射，
\(f(f^{-1}(U_i \cap V)) = U_i \cap V\) 是 \(U_i\) 的开集。
因此它也是 \(Y\) 的开集。最后，由拓扑的定义，我们有
\[
V = \bigcup_{i\in I} V \cap U_i
\]
为 \(Y\) 的开集。这就证明了 \(f\) 是商映射。
:::

::: proposition {@proposition:section-quotient-map}
令 \(f\colon X \to Y\) 为连续映射。
设 \(f\) 拥有一个**截面（section）** \(s\colon Y \to X\)
（即 \(s\) 是一个满足 \(f\circ s = \mathrm{Id}_{Y}\) 的连续映射）。
则 \(f\) 是商映射。
:::

::: proof
由于 \(y = f(s(y))\)，\(f\) 是满射。
设 \(f^{-1}(V)\) 为开集，则由 \(s\) 的连续性
\(V = \mathrm{Id}_{Y}^{-1}(V)=s^{-1}(f^{-1}(V))\) 是开集。
因此 \(f\) 是商映射。
:::

因此，如果一个连续映射在靶空间上局部有截面，它就是一个商映射。

我们可以利用截面来验证小节开始时的映射 \(p\) 为商映射。
整体上，\(p\) 没有截面。（为什么？）
但是只要我们选择合适的“主值”，
我们就可以通过反三角函数来用 \(\cos\) 或者 \(\sin\) 来决定角度，
从而定义局部截面。
由于余弦函数在开区间 \(\left]{0},{\pi}\right[\) 单调，上半个开圆周上就可以定义连续映射
\[
(x,y)   \mapsto \frac{1}{2\pi}\arccos x \colon \{(x,y) \in \mathbb{S}^1 : y > 0 \} \to \left]{0},{\pi}\right[,
\]
它是 \(p\) 的局部截面。在下半个开圆周也可以定义 \(p\) 的局部截面
\[
(x,y)   \mapsto \frac{1}{2\pi}\arccos x \colon \{(x,y) \in \mathbb{S}^1 : y < 0 \} \to \left]{-\pi},{0}\right[.
\]
类似地，通过选择反正弦函数的恰当主值就可以在左右开半圆周定义出局部截面。
这样，\(p: \mathbb{R} \to \mathbb{S}^{1}\) 就在 \(\mathbb{S}^1\) 局部有截面。
因此它是商映射。

### 通过证明映射是开映射或闭映射*

其次，按照定义，连续满射是商映射当且仅当它将饱和开（闭）集映成开（闭）集。
因此我们有如下结果。

::: proposition {@proposition:open-closed-quotient-map}
若拓扑空间之间连续满射 \(f: X \to Y\)
是开映射或者闭映射，那么 \(f\) 是商映射。
:::

比如，我们可以通过验证导引里的映射 \(p\) 是开映射来说明它是商映射。
一种验证映射是开映射的方法是利用微分学。

::: remark [使用微分学来验证映射是开映射]
设 \(U \subset \mathbb{R}^{n}\) 和 \(V \subset \mathbb{R}^{m}\)，其中 \(n \geq m\)，
都是开集，\(f = (f_1,\ldots,f_m): U \to V\) 是 \(C^{\infty}\) 映射，隐函数定理的一个推论
（所谓的[[常秩定理]]）说，
如果 Jacobi 矩阵 \((\frac{\partial f_i}{\partial x_j})\) 的秩在 \(U\) 上每一点都是
\(m\)，那么 \(f\) 是一个开映射。因此 \(f: U \to f(U)\) 是商映射。
:::

使用微分学的判据可以验证导言中的 \(p\) 是开映射。
一种计算方法是可以使用球极投影将 \(\mathbb{S}^1 \setminus \{(0,1)\}\)
同胚地等同于 \(\mathbb{R}\)，然后计算复合映射
\[
\mathbb{R} \setminus p^{-1}\{(0,1)\} \xrightarrow{p} \mathbb{S}^{1} \setminus \{(0,1)\}
\to \mathbb{R}
\]
的微分，验证它处处非零。（类似地处理 \(\mathbb{S}^1 \setminus \{(1,0)\}\)。）
这个计算留给读者进行。

::: remark [利用紧性验证映射是闭映射]
我们将在第 @sec:compactness 节介绍紧性。
利用紧性相关的概念可以比较方便地证明映射是闭映射。
我们将证明紧空间到 Hausdorff 空间连续映射是闭映射
（@corollary:compact-to-t2-closed-map）。

在 @exercise:proper-map 中，我们将证明下列闭映射的判据：
如果 \(f: X \to Y\) 是连续映射，\(Y\) 的紧子空间在 \(f\) 下的原像也紧，
且 \(Y\) 局部紧 Hausdorff，那么 \(f\) 是闭映射。
:::

## 商拓扑的简单例子 {@sec:initial-example-quotient-topology}

1. 在 \(\mathbb{R}\) 上引入等价关系 \(\sim\) 如下：\(x \sim y\)
   当且仅当存在非零实数 \(\lambda\)，使得 \(\lambda x = y\)。
   则这个等价关系共有两个不同的等价类 \([0]\) 和 \([1]\)。
   而这个等价关系的商空间同胚于 Sierpiński 空间
   （我们有 \([0] \in \overline{[1]}\)）。因此，Hausdorff 空间的商空间未必是
   Hausdorff 的。

2. 令 \(X\) 为拓扑空间。令 \(A \subset X\) 为子空间。
   引入由 \(a\sim b\)，\(\forall a,b \in A\) 生成的等价关系。所得到的商空间有时记为 \(X/A\)。
   商映射 \(X \to X/A\) 将整个子空间“坍缩”成了一个点。
   比如，将空间 \(X \times [0,1]\)  的子空间 \(X\times\{1\}\) 坍缩掉。
   此商空间叫做 \(X\) 的**锥（cone）**。
   又比如，商空间 \([0,1]/\{0,1\}\)同胚于 \(\mathbb{S}^{1}\)。事实
   上，映射 \(s\mapsto(\cos(2\pi s),\sin(2\pi s))\) 诱导了所需的同胚。

3. 在研究曲面的时候经常会使用下面这样的示意图：

   ![图 2：环面与 Klein 瓶](Topology_image7.svg?width=250)

   它的意思是将用同一种方法标记的边按照所示方向粘接在一起。
   左图粘出了环面，而右图粘出了所谓的 Klein 瓶。
   比如在这两个图中，虚线边缘所示的点被粘合了，并且矩形的四个顶点也被粘合了。

4. 令 \(B\) 为拓扑空间。\(A \subset B\) 是 \(B\) 的子空间。
   令 \(\varphi\colon A \to X\) 为连续映射。
   我们定义 \(X\) 沿着 \(\varphi\) 的**推出（pushout）**（记号：
   \(X\amalg_{\varphi}B\) 或者 \(X\amalg_{A}B\)）
   为 \((X \amalg B)/{\sim}\)，其中 \(\sim\) 是由 \(a\sim \varphi(a)\)，
   \(a \in A\) 生成的等价关系。我们有如下连续映射的交换图
   \[
   \begin{tikzcd}
     A \ar[hook]{r} \ar{d}{\varphi} & B \ar{d}{\beta} \\
     X \ar{r}{\alpha} & X \amalg_{\varphi} B
   \end{tikzcd}
   \]

   如果 \(A = \mathbb{S}^{n-1}\)，\(B=D^{n}\)，则空间 \(X \amalg_A B\)
   被称为是往拓扑空间 \(X\) 沿着 \(\varphi\) 安装了一个 **\(n\) 维胞腔** 得到的空间。

   推出满足如下泛性质：
   对任何满足 \(u|_{A} = v\circ \varphi\) 的连续映射 \(u\colon B \to Y\)，
   \(v\colon X \to Y\)，存在唯一的连续映射 \(\psi\colon X \amalg_A B \to Y\)
   使得 \(\psi\circ \beta = u\)，\(\psi\circ \alpha=v\)。

5. 最后，我们给出一个例子，说明商映射的积不一定是商映射。
   令 \(X = \mathbb{R}_{+}\)，\(A = \mathbb{N}_{+}\)。
   令 \(\pi \colon X \to X^{\ast} = X/A\) 为商映射。
   令 \(b\) 为坍缩 \(\mathbb{N}_{+}\) 所得的点。
   我们来证明
   \[
   \pi \times \mathrm{Id}_{\mathbb{Q}} \colon
   X \times \mathbb{Q} \to X^{\ast}\times \mathbb{Q}
   \]
   不是商映射。

   令 \(c_n = \left(n,\frac{\sqrt{2}}{n}\right)\)。
   令 \(U_n\) 是如图 3 所示阴影区域构成的开集。

   ![图 3：集合 \(U_{n}\)](Topology_image8.svg?width=400)

   令 \(U = \bigcup_{n=1}^{\infty} U_n\)。
   由于 \(c_n\) 的第二个坐标是无理数，\(U\) 是一个饱和开集。
   我们断言 \(V=(\pi\times \mathrm{Id})(U)\) 不是开集。
   如果是，它就会是 \((b,0)\) 的一个邻域。
   因此存在 \((b,0)\) 的邻域 \(W\)，和实数 \(\delta >0\)，
   使得 \(W\times(\left]{-\delta},{\delta}\right[\cap\mathbb{Q})\subset V\)。
   因此 \(\mathbb{N}_{+}\times(\left]{-\delta},{\delta}\right[\cap\mathbb{Q})\)
   落在 \(U\) 中。这与 \(c_n \to 0\) 矛盾。

## 粘贴开集

本段里我们讨论如何从小片开始粘合空间。
一组**粘贴开集的素材**是指如下的数据：

- （用什么粘）一族拓扑空间 \((U_{i})_{i\in I}\)，

- （在哪里粘）一族开子集 \(U_{ij} \subset U_{i}\)，\((i,j) \in I\times I\)，
  满足 \(U_{ii} = U_{i}\)，

- （怎么粘）同胚 \(f_{ij}\colon U_{ij} \to U_{ji}\)，满足下列条件：

  1. \(f_{ii} = \mathrm{Id}_{U_i}\)，

  2. \(f_{ij}(U_{ij} \cap U_{ik}) \subset U_{ji} \cap U_{jk}\)，

  3. \(f_{ik}|_{U_{ij} \cap U_{ik}} = f_{jk}|_{U_{ji}\cap U_{jk}} \circ f_{ij}|_{U_{ij}\cap U_{ik}}\)。

有了粘贴的素材，我们引入等价关系来粘贴 \(U_i\)。
在集合 \(U = \coprod_{i\in I} U_{i}\) 上引入关系
\[
x \sim y \Longleftrightarrow \exists i, j \in I, x \in U_{ij}, y \in U_{ji}, f_{ij}(x) = y.
\]
我们来验证 \(\sim\) 是一个等价关系。由于 \(f_{ii}=\mathrm{Id}_{U_i}\)，我们有
\(x \sim x\) 对任何 \(x \in U\) 成立。
如果 \(x \sim y\)，则存在 \(i,j \in I\)，使得 \(y = f_{ij}(x)\)。
由于 \(f_{ji} \circ f_{ij} = f_{jj} = \mathrm{Id}_{U_{j}}\)，
我们有 \(x = f_{ji}(f_{ij}(x))=f_{ji}(y)\)。因此关系 \(\sim\) 是对称的。
最后，如果 \(x \sim y\)，\(y \sim z\)，那么存在 \(i,j,k\)，使得
\(z = f_{jk}(y) = f_{jk}(f_{ij}(x))=f_{ik}(x)\)，即 \(z\sim x\)。
由此验证了 \(\sim\) 的传递性。

我们称商空间 \(X = U/{\sim}\) 为通过开集粘贴素材 \((U_i, U_{ij},f_{ij})\)
粘贴所得的拓扑空间。

::: proposition {@proposition:open-glue}
记号如上。我们有如下结论。

1. {@item:open-glue-open-map} 商映射 \(\pi\colon U \to X\) 是开映射。

2. {@item:open-in-open-glue} 复合映射 \(\iota_i\colon U_i \to U \to X\) 诱导了 \(U_i\) 与
   \(\iota_i(U_i)\) 的同胚，并且 \(\iota_i(U_i)\) 是 \(X\) 的开子空间。

3. {@item:open-intersction-in-open-glue} 复合映射 \(\iota_{ij}\colon U_{ij} \to U_i \to U \to X\)
   诱导了 \(U_{ij}\) 与
   \(X\) 的开集 \(\iota_i(U_i) \cap \iota_j(U_j)\) 的同胚。

:::

::: proof
由于开映射可以在定义域上局部检验，而 \((U_i)_{i\in I}\) 是 \(U\) 的开覆盖，为
了证明 @item:open-glue-open-map 成立。
我们只需证明，对任意 \(i\)，任意 \(U_i\) 的开子集 \(V\)，
\(\iota_i(V)\) 是 \(X\) 的开子集。为此，根据商空间的性质，我们要验证
饱和集 \(\pi^{-1}(\iota_i(V))\) 是 \(U\) 的开集。由于 \(U\) 的拓扑是空间
\(U_k\) 的不交并拓扑，我们需要验证，对任何 \(k \in I\)，
\(\pi^{-1}(\iota_i(V)) \cap U_k\)
是 \(U_{k}\) 的开集。这个集合包含了一切 \(U_k\) 中的点 \(x\)，它与某个
\(y \in V\) 关于 \(\sim\) 等价。这些点正好是集合 \(U_{ki}\) 中的子集
\(\varphi_{ik}(V\cap U_{ik})\)。
根据粘贴素材的定义，\(U_{ki}\) 是 \(U_k\) 的开集，\(U_{ik}\) 是 \(U_i\) 的开集，
所以\(V\cap U_{ik}\)是\(U_{ik}\)的开集，又\(\varphi_{ik}\) 是同胚，
因此 \(\varphi_{ik}(V\cap U_{ik})\)
是 \(U_{ki}\) 的开集。进而它是 \(U_{k}\) 的开集。

根据 @item:open-glue-open-map 的结论，
为了证明 @item:open-in-open-glue、
@item:open-intersction-in-open-glue，
我们只需证明\(U_i \to \iota_i(U_i)\) 以及
\(U_{ij} \to \iota_i(U_i) \cap \iota_j(U_j)\) 为连续单射，
我们只验证后者。
如果存在 \(x, x' \in U_{ij}\)，使得
\(\iota_{ij}(x') = \iota_{ij}(x) \in \iota_i(U_i) \cap \iota_j(U_j)\)，
那么根据 \(\sim\) 的定义，必有 \(y \in U_{ji}\)，使得
\(x \sim y\)，\(x' \sim y\)。于是我们有
\(x = f_{ji}(y) = x'\)。这就完成了单射的证明。
:::

现实中验证条件 (1) – (3)
会比较繁琐。一个比较简单的情形如下。设我们事先已经有了一个集合 \(X\)，
且 \(X = \bigcup_{i\in I} U_{i}\) 是一些子集的并，每个 \(U_i\) 都事先给定了一个拓扑空间结构。
令 \(U_{ij} = U_i \cap U_j\)，\(f_{ij}\) 为恒等映射，
则条件 (1) – (3) 就自动成立。
如果所有 \(U_{i}\cap U_{j}\) 都是 \(U_i\) 的开集，
那么我们就得到了一个开集粘贴素材。

::: example {@example:affine-line-with-double-origin}
令 \(U_1 = \mathbb{R}\)，\(U_2 = \mathbb{R}\)，
\(U_{12} = U_{21} = \mathbb{R} \setminus \{0\}\)。
由于只有两片开集，条件 (3) 是显然的。
因此我们可以将两条实数轴沿着开集 \(\mathbb{R}\setminus\{0\}\) 使用恒等映射
\(\varphi_{12}(x)=x\) 粘接起来。
所得到的空间叫做**有两个原点的仿射直线（affine line with double origin）**（见图 4）。
它不是一个 Hausdorff 空间。红色的原点的任何邻域一定是蓝色原点的去心邻域。

![图 4：有两个原点的仿射直线](Topology_image9.svg?width=250)

我们也可以用另一种方法来粘合 \(U_{12}\) 和 \(U_{21}\)，我们可以令
\(\varphi_{12}(x)=1/x\)。如果这样粘合的话，我们得到了 \(\mathbb{S}^{1}\)。见图 5。

![图 5：用两个实轴粘合圆周](Topology_image10.svg?width=250)

具体的商映射可以用南极和北极分别的球极投影给出。
:::

## 流形

一个 \(n\) 维**拓扑流形（topological manifold）**
是指一个具有可数拓扑基的 Hausdorff 拓扑空间 \(M\)，它有开覆盖
\(M = \bigcup_{i\in I} U_{i}\)，其中每一个 \(U_i\) 都同胚
于 \(\mathbb{R}^{n}\) 的开子集。在这个覆盖中，同胚
\(\varphi_i\colon U_i \to \varphi_i(U_i) \subset \mathbb{R}^{n}\)
叫做一个**图表（chart）**[^1]。

为了构造拓扑流形，可以使用 \(\mathbb{R}^{n}\) 的开子集为
\(U_{i}\) 作为开集粘贴素材（这些 \(U_i\) 叫做**图表（chart）**）。
粘贴的时候要小心，因为有可能会粘出不 Hausdorff
的空间（比如有两个原点的仿射直线）。一个能够保证粘合空间为 Hausdorff 的条件如下：
对任何 \(p, q \in M\)，要么存在一个 \(U_i\) 使得
\(p,q \in U_i\)，要么存在两个不相交的 \(U_i\)，\(U_{j}\)，使得 \(p \in U_i\)，
\(q \in U_j\)。在下一小节中我们会通过这个方法来说明射影空间是流形。

\({}^{\star}\)
在粘贴的过程中，同胚 \(f_{ij}\) 叫做**坐标转移函数**。
使用特别的坐标转移函数允许我们定义特殊类别的流形。
如果 \(U_i\) 是 \(\mathbb{R}^n\)（或者 \(\mathbb{C}^n\)）的子集，
并且同胚 \(f_{ij}\colon U_{ij} \to U_{ji}\) 是可微的（或复解析的），
那么粘贴所得的流形就叫做**微分流形（differentiable manifold）**
（或**复流形（complex manifold）**）。
如果 \(U_i\) 是 \(\mathbb{R}^{n}\)，而 \(f_{ij}\) 是仿射映射，
那么粘出来的流形就叫做**仿射流形（affine manifold）**。
在微分（复，仿射）流形之间可以定义可微（全纯，仿射）映射的概念。
上述结构的存在允许我们使用更多的工具来研究流形，并且会为流形的拓扑提供特殊的限制。\({}_{\star}\)

另一个构造流形的方法是借助下述命题。

::: proposition {@proposition:nice-intersection-of-hypersurfaces}
令 \(f_{1},\ldots,f_{r}\) 为欧氏空间中开集
\(U \subset \mathbb{R}^{n}\)
上一族可微函数[^2]。
假设 Jacobi 矩阵
\[
\begin{bmatrix}
  \frac{\partial f_{1}}{\partial x_{1}} & \cdots &    \frac{\partial f_{1}}{\partial x_{n}}  \\
  \vdots & & \vdots \\
  \frac{\partial f_{r}}{\partial x_{1}} & \cdots &    \frac{\partial f_{r}}{\partial x_{n}}
\end{bmatrix}
\]
在 \(U\) 上每一点的秩都是 \(r\)。则
\[
M = \{x \in U : f_1(x) = \cdots = f_{r}(x) = 0\}
\]
是一个 \(n-r\) 维流形。
:::

::: proof
由于 \(\mathbb{R}^{n}\) 是度量空间，它是 Hausdorff 的。因此 \(M\) 也是
Hausdorff 空间（@proposition:hausdorff-one-point-closed 第 5 项）。
\(U\) 中坐标为有理数的点的有理半径的球与 \(M\) 的交为 \(M\) 的可数拓扑基，
因此只需对任何 \(p \in M\) 构造一个同胚于 \(\mathbb{R}^{n-r}\) 的邻域即可。

无妨 \(p\) 为原点（通过平移），且 Jacobi 矩阵的前
\(r\times r\) 子矩阵在原点附近可逆（如有必要，重排坐标次序）。
令
\(x=(x_1,\ldots,x_r)\)，\(y=(x_{r+1},\ldots,x_{n})\)。
根据隐函数定理，存在欧氏球
\(B(0;\epsilon) \subset \mathbb{R}^{r}\)，
\(B(0;\eta) \subset \mathbb{R}^{n-r}\)，
以及可微映射
\[
\Phi\colon B(0;\eta) \to B(0;\epsilon)
\]
使得
\(V = B(0;\epsilon) \times B(0;\eta) \subset U\)，
以及
\[
M \cap V = \{(\Phi(y),y) : y \in B(0;\eta)\}.
\]
特别地，开集 \(M \cap V\) 是 \(B(0;\eta)\) 上可微函数的图像，因此同胚于
\(B(0;\eta) \cong \mathbb{R}^{n-r}\)。
:::

\({}^{\star}\) 读者应该能验证，上述方式定义的流形实际上是微分流形。\({}_{\star}\)

## 射影空间 (I) {@sec:projective-space-1}

作为集合，\(n\) 维实射影空间 \(\mathbb{R}\mathrm{P}^{n}\) 是一切线性空间
\(\mathbb{R}^{n+1}\) 的 1 维线性子空间的全体。即：\(\mathbb{R}\mathrm{P}^n\)
中的一个点，是 \(\mathbb{R}^{n+1}\) 经过原点的一条直线。
我们用符号 \([z_0,\ldots,z_n]\) 来代表经过非零向量 \((z_0,\ldots,z_n)\) 的唯一的
一维子空间。
因此 \(\mathbb{R}\mathrm{P}^{n}=\{[z_0,\ldots,z_n]:z_i \text{\;不全为零}\}\)。

令 \(U_{i}\) 是 \(\mathbb{R}^{n+1}\) 中不包含在超平面 \(z_i=0\) 中的一维子空间的全体。
令
\[
V_i = \{(z_0,\ldots,z_n) \in \mathbb{R}^{n+1} : z_i = 1\}.
\]
则 \(V_i\) 作为 \(\mathbb{R}^{n+1}\) 的子空间同胚于  \(\mathbb{R}^{n}\)。
对于任何 \(U_i\) 中的点 \(\ell\)，\(\ell\) 与 \(V_i\) 有唯一的交点。
如果 \(z_{i} \in \ell \setminus\{0\}\)，则这个交点为
\((z_0/z_i, \ldots, z_n/z_i)\)。
由此定义双射
\[
\varphi_i \colon U_i \to \mathbb{R}^{n},
\quad
\ell \mapsto
\left(\frac{z_0}{z_i},\ldots,\frac{z_{i-1}}{z_i},\frac{z_{i+1}}{z_i},\ldots,\frac{z_{n}}{z_i}\right).
\]
因此，我们可以通过双射 \(\varphi_i\colon U_i \to \mathbb{R}^{n}\)
来赋予 \(U_i\) 拓扑。在此拓扑下，\(U_i \cap U_j\) 都是 \(U_i\) 的开集。
如果 \((x_1,\ldots, x_n)\) 是 \(\mathbb{R}^n\) 的坐标，
\(U_i \cap U_j\) 在 \(\varphi_i\) 下的像是 \(\mathbb{R}^{n}\) 中由不等式
\(x_{j+1}\neq 0\)（如果\(j<i\)）
或 \(x_{j}\neq 0\)（如果 \(j > i\)）定义的区域。

因此集合 \(\mathbb{R}\mathrm{P}^{n}\)，伴以 \(U_i\) 的上述拓扑，给出了粘贴开集的素材。
我们用此赋予 \(\mathbb{R}\mathrm{P}^{n}\) 拓扑。
通过上述构造，我们能看出
\(\mathbb{R}\mathrm{P}^{n}\) 是一个流形
（留给读者检验 Hausdorff 性质）。
根据上述定义，以及 @example:affine-line-with-double-origin，
我们发现 \(\mathbb{R}\mathrm{P}^1 \cong \mathbb{S}^{1}\)。
将 \(\mathbb{R}\) 换成 \(\mathbb{C}\)，同样的操作可以给出复射影空间
\(\mathbb{C}\mathrm{P}^{n}\) 的拓扑结构。

- 商映射 quotient map

## 习题

::: exercise [闭映射] {@exercise:closed-map}
设 \(f: X \to Y\) 为拓扑空间之间的连续映射。

1. 证明下述陈述等价。

   - 对任意 \(X\)的闭子集 \(A\)，\(f(A)\) 是 \(Y\) 的闭子集。

   - 对任意 \(y \in Y\)，任意包含 \(f^{-1}(y)\) 的 \(X\) 的开集 \(W\)，
     存在 \(y\) 的邻域 \(V\)，使得 \(f^{-1}(V) \subset W\)。

     满足上述条件的连续映射叫做**闭映射（closed map）**。

2. 举例说明连续映射未必是闭映射。

3. 举例说明，如果 \(f: X \to Y\) 是闭映射，\(Z\) 是拓扑空间，
   \(f \times \mathrm{Id}_{Z} \colon X \times Z \to Y\times Z\)
   未必是闭映射。

:::

::: exercise [收缩] {@exercise:retraction}
令 \(A\) 为拓扑空间 \(X\) 的子空间。
令 \(i\colon A \to X\) 为包含映射。
一个从 \(X\) 到 \(A\) 的**收缩（retraction）**
是一个连续映射 \(r\colon X \to A\)，它满足
\(r\circ i=\mathrm{Id}_{A}\)。如果存在从 \(X\) 到子空间 \(A\) 的收缩，
我们称 \(A\) 是 \(X\) 的一个**收缩核（retract）**。

1. 收缩是商映射。

2. {@item:retract-hausdorff-closed} 若 \(X\) 为 Hausdorff 空间，\(A\) 是
   \(X\) 的收缩核，那么 \(A\) 是 \(X\) 的闭子空间。

3. 在 @item:retract-hausdorff-closed 中，去掉“Hausdorff”可以吗？

:::

::: exercise [截面] {@exercise:_3_8_3}
令 \(p\colon E \to B\) 为连续映射。
连续映射 \(s\colon B \to E\) 叫做 \(p\) 的**截面（section）**，
如果 \(p\circ s = \mathrm{Id}_B\)。

1. 令 \(s\colon B \to E\) 为 \(p\) 的一个截面。
   如果 \(p\) 是非分歧映射（@exercise:unramified-map），那么 \(s(B)\)
   是 \(E\) 的开集。

2. 令 \(s\colon B \to E\) 为 \(p\) 的一个截面。
   如果 \(p\) 是分离映射（@exercise:sep-map），那么 \(s(B)\) 是 \(E\)
   的闭集。

3. 如果 \(E = \mathbf{I}\)，\(B=\mathbb{S}^{1}\)，且
   \(p\colon E \to B, t\mapsto (\cos(2\pi t),\sin(2\pi t))\)，则 \(p\) 没有截面。

:::

\(\boxed{\dagger}\)
