---
title: 一阶语言
---

首先，我们来描述什么是自然数。

::: definition [自然数]
$0,1,2,3,...,10,11,...$这些符号用来表示我们直觉接受的自然数。

当我们需要一个任意的自然数时，我们会用小写字母$k,l,m,n$之一表达。
在没有特别标注时，它们一定是任意自然数的意思。

如果我们有一种方法，任给自然数$n$均可由这一方法确定唯一的自然数$m$，
则称这个方法是一个自然数到自然数的函数，用$a$表示。这一方法从$n$确定的自然数$m$记为$a(n)$。

我们默认一切初等数论知识，包括但不限于：加法、乘法、数学归纳法、整除、素数、算术基本定理、同余、
中国剩余定理。
:::

::: remark*
对于自然数的标准性、我们如何认知自然数，什么是自然数的相等，以及为何允许谈论任意自然数，
什么是自然数到自然数的函数，请看本章末尾的注记。今后不再特别指出。
:::

我们的一切定义都基于自然数。现在，我们来指定语言中允许的字符表。

::: definition [一阶语言的字符]
一阶语言的字符表被我们列举如下：

1. 变元符号$x_m$，任意变元用$w,x,y,z$表达。

2. 函数符号$f_m$，任意函数符号用$f,g,h$表达。

3. 谓词符号$P_m$，任意谓词符号用$P$表达。

4. 逻辑连接词符号$\neg,\to$，读作否定和蕴含。

5. 量词符号$\forall$，读作对所有（for all）。

6. 括号$(,)$。

这里$m$总是跑遍自然数，换言之任给自然数$m$均有一个自由变元符号$x_m$，
一个$n$元函数符号$f_m$和一个谓词符号$P_m$。

我们还有自然数到自然数的两个函数：函数元数指示器$a_f$，谓词元数指示器$a_P$。它们不是字符表中的字符。
我们称$a_f(m)$是$f_m$的元数，$a_P(m)$是$P_m$的元数。

我们还有两个自然数：函数个数$n_f$与谓词个数$n_P$。
我们总是只考虑下标$m<n_f$的函数符号$f_m$与下标$m<n_P$的谓词符号$P_m$。

我们总是特别地要求$n_P\geq 1$，$a_P(0)=2$且记$P_0$为$\approx$。
如果一个$m<n_f$使得$a_f(m)=0$，则称$f_m$是一个常数符号。

一个四元组$(n_f,n_P,a_f,a_P)$称作一个一阶语言$\mathcal{L}$。以下我们总是默认选定了一个一阶语言。
:::

::: remark*
我们也可以认为上面全部都是奇数：$\forall$是第一个奇数$1$，$(,)$是后面两个奇数$3$和$5$，
$\neg,\to$是再后面的两个奇数$7,9$，$x_m,f_m,P_m$是$6m+11,6m+13$和$6m+15$。
:::

接下来，我们直觉地指出一个概念。

::: definition [字符串]
我们归纳地定义一个字符表下长度为任意自然数$n$的字符串：

1. 长度为$0$的字符串是空串。

2. 长度为$n+1$的字符串是长度为$n$的字符串在后面串接一个字符表中的字符得到的新字符串。

进一步，我们可以定义字符串的串接，串接后的字符串长度变为被串接的两字符串长度之和。

我们认为这一递归定义确实归纳地指出所有的字符串。
:::

::: remark*
我们也可以认为字符串是自然数：长度$0$的字符串是$1$，
长度$n$的作为自然数的字符串$t$串接作为自然数的字符$m$得到的长度$n+1$的字符串对应的自然数是
$t\times p_n^{m+1}$，这里$p_n$是第$n$个质数。
:::

有了字符串的概念，我们就可以定义我们所需的语言中的对象了。

::: definition [项]
我们递归定义以下形式的字符串为项：

1. $x$是项。

2. 若$f=f_m$是函数符号，$n=a_f(m)$是函数$f$的元数，$t_1,...,t_n$是$n$个项，则$f(t_1,...,t_n)$是项。

我们认为这一递归定义确实归纳地指出所有的项。项通常用$s,t$表达。
:::

::: remark*
这一递归定义成立是因为它事实上定义了一些满足要求的自然数，这些自然数对应的字符串就是项。
以下的递归定义和归纳法都因此成立。
:::

::: definition [公式]
我们递归定义以下形式的字符串为公式：

1. 若$P=P_m$是谓词符号，$n=a_P(m)$是谓词$P$的元数，$t_1,...,t_n$是$n$个项，
   则$P(t_1,...,t_n)$是公式。

2. 若$\varphi$是公式，则$\neg\varphi$是公式。

3. 若$\varphi$与$\psi$是公式，则$(\varphi\to\psi)$是公式。

4. 若$\varphi$是公式，$x$是变元，则$\forall x(\varphi)$是公式。

我们认为这一递归定义确实归纳地指出所有的公式。公式通常用$\varphi,\phi,\psi$表达。
我们称形如$P(t_1,...,t_n)$的公式为原子公式。
:::

项和公式是我们要处理的全部语言对象。它们本质上是满足特定规则的字符串。
接下来，我们来给出它们的一些性质。

::: definition [自由出现]
对每个$m$，我们可以对所有项和所有公式讨论$x_m$在其中的自由出现性。
对项$t$而言，$x_m$在$t$中自由出现当且仅当字符$x_m$在字符串$t$中出现。对公式而言，归纳定义：

1. 形如$P(t_1,...,t_n)$的公式，$x_m$在其中自由出现当且仅当它在这个字符串中出现。

2. 形如$\neg\varphi$的公式，$x_m$在其中自由出现当且仅当它在$\varphi$中自由出现。

3. 形如$(\varphi\to\psi)$的公式，
   $x_m$在其中自由出现当且仅当它在$\varphi$中自由出现或它在$\psi$中自由出现。

4. 形如$\forall x(\varphi)$的公式，
   $x_m$在其中自由出现当且仅当它在$\varphi$中自由出现且$x$不是$x_m$。

对项$t$，我们通常将其中自由出现的变元全部列出，记为$t(x_{m_1},...,x_{m_n})$，
这里$m_1,...,m_n$是有限个互不相同的自然数。
对公式$\varphi$，我们同样将其中自由出现的变元全部列出，记为$\varphi(x_{m_1},...,x_{m_n})$。
为了方便，我们又会记$(x_{m_1},...,x_{m_n})$为$(y_1,...,y_n)$以忽略具体的$m_1,...,m_n$的值。
:::

::: remark*
这一递归定义成立的理由仍然需要我们回到它们对应的自然数上去论证。
:::

::: definition [替换]
给定变元$x$与项$t$，我们定义一个操作$\mathrm{sub}^x_t$，它递归地将公式变为另一个公式：

1. 形如$P(t_1,...,t_n)$的公式$\phi$，
   $\mathrm{sub}^x_t(\phi)$是$\phi$这一字符串中所有$x$出现的地方都将$x$替换为$t$得到的新公式。

2. 形如$\neg\varphi$的公式$\phi$，$\mathrm{sub}^x_t(\phi)$是$\neg\mathrm{sub}^x_t(\varphi)$。

3. 形如$(\varphi\to\psi)$的公式$\phi$，
   $\mathrm{sub}^x_t(\phi)$是$(\mathrm{sub}^x_t(\varphi)\to\mathrm{sub}^x_t(\psi))$。

4. 形如$\forall y(\varphi)$的公式$\phi$，若$y=x$则$\mathrm{sub}^x_t(\phi)$仍然是$\phi$，
   若$y\not=x$则$\mathrm{sub}^x_t(\phi)$是$\forall y(\mathrm{sub}^x_t(\varphi))$。

我们还要禁止一些改变语义（虽然我们现在还没有严格定义语义）的替换操作，
因此我们继续递归地对每个公式$\phi$定义$\mathrm{sub}^x_t$对$\phi$是否是无冲突替换。

1. 形如$P(t_1,...,t_n)$的公式$\phi$，$\mathrm{sub}^x_t$对$\phi$总是无冲突替换。

2. 形如$\neg\varphi$的公式$\phi$，
   $\mathrm{sub}^x_t$对$\phi$是无冲突替换当且仅当$\mathrm{sub}^x_t$对$\varphi$是无冲突替换。

3. 形如$(\varphi\to\psi)$的公式$\phi$，
   $\mathrm{sub}^x_t$对$\phi$是无冲突替换当且仅当$\mathrm{sub}^x_t$对$\varphi$和$\psi$
   都是无冲突替换。

4. 形如$\forall y(\varphi)$的公式$\phi$，
   $\mathrm{sub}^x_t$对$\phi$是无冲突替换当且仅当$x$不在$\phi$中自由出现，
   或$\mathrm{sub}^x_t$对$\varphi$是无冲突替换且$y$不在$t$中出现。

:::

::: remark*
我们写$x=y$指的是这两个字符是同一个字符，这与公式$x\approx y$即$P_0(x,y)$并不是一个意思。
:::

以上定义了为了能讨论证明这一概念所需要的所有前置概念。
