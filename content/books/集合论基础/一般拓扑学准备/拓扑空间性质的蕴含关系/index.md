这一节我们主要讨论上节中描述的各项性质中同类性质们在什么情况下能相互推导，以及如何通过加入别的性质来达到下克上的目标。

首先来看强度的严格排序。

::: theorem [分离性]
$T_6\rightarrow T_5\rightarrow T_4\rightarrow T_{3.5}\rightarrow T_3\rightarrow T_{2.5}\rightarrow T_2\rightarrow T_1$
:::

::: proof
我们这里证明每一步都可以推出。然而，证明每一步推出都是严格减弱条件要给出七个例子，这里略去。

$T_6\to T_5$：$T_6$指出存在两个到$[0,1]$的连续函数$f,g$使得$f^{-1}(\{0\})=\mathrm{Cl}(A)$和$g^{-1}(\{0\})=\mathrm{Cl}(B)$。现在考虑连续函数$f-g$，则$(f-g)^{-1}((-\infty,0))$与$(f-g)^{-1}((0,+\infty))$分离$A$与$B$。

$T_5\to T_4$：显然。

$T_4\to T_{3.5}$：这是大名鼎鼎的Urysohn引理，我们放在后面证明之。

$T_{3.5}\to T_3$：用$f^{-1}([0,0.5)$和$f^{-1}((0.5,1])$分离。

$T_3\to T_2$：$T_1$先分离一边，然后其补集作为闭集和点用$T_3$再次分离。

$T_2\to T_1$：显然。
:::

::: theorem [可数性]
$C_2\rightarrow  C_1\wedge Seperable\wedge Lindelof$
:::

::: proof
$C_2\to C_1$是显然的，我们来看余下两个命题。

$C_2\to Seperable$：我们证明只要从每个基开集中取一个点，形成的可列点集就是稠密集。这是因为基的定义保证了每点处每一邻域都包含一个基开集邻域，从而从中选出的点见证这个可列点集在此处的稠密性。

$C_2\to Lindelof$：任给$X$的开覆盖，我们对每个基开集寻找一个$X$中覆盖之的元素（如果没有则不取），从而构成一个可列开集子族，然后证明它亦为覆盖。事实上，任给点$x\in X$，开覆盖中定有一个开集覆盖此点，从而由基的定义有一个基开集覆盖此点，这个基开集被我们选出来的子覆盖中开集自然也覆盖此点。
:::

::: theorem [紧致性]
紧致$\vee$列紧$\rightarrow$可数紧致$\rightarrow$极限点紧致
:::

::: proof
首先，我们给出可数紧致性的一个等价形式，也是闭集套定理的狭义形式。

**引理。** 可数紧致当且仅当非空递降闭集列的交集不空。

**证明。** 类比紧致性与滤子紧致性等价的证明，具体细节留给读者。

现在来看要证明的内容。紧致推出可数紧致是显然的。

序列紧致$\to$可数紧致：只要每个闭集贡献一个点形成点列，然后取出收敛子列，就会收敛到出一个交集中的点。

可数紧致$\to$极限点紧致：对点列$\{x_n\}$构造闭集套$A_n=\mathrm{Cl}(\{x_k|k\geq n\})$。
:::

接下来，我们考虑加强分离性。

一方面，我们给出从$T_3$加强到$T_4$的方法。

::: theorem
$C_2+T_3\rightarrow T_4$
:::

::: proof
我们考虑带有可数集$\mathcal{B}$的$T_3$空间$X$中两个不交的闭集$A$与$B$。任给$x\in A$，考虑$T_3$指出的邻域$S_x\ni x$，它要满足$\mathrm{Cl}S_x\cap B=\varnothing$。我们进而取基里的开集$U_x\in\mathcal{B}$使得$x\in U_x\subseteq S_x$，这样$\{U_x|x\in A\}$构成了$A$的一个可数开覆盖，且其中每个开集的闭包都与$B$不交。我们用$n\in\omega$将这个开覆盖重新命名为$\{U_n\}$。

同理，我们得到$B$的开覆盖$\{V_n\}$，其中每个开集的闭包都与$A$不交。现在$U=\bigcup_{n\in\omega}U_n$与$V=\bigcup_{n\\in\omega}V_n$是包含$A$与$B$的两个开集，但可能相交。因此，我们重新考虑$U_n'=U_n\backslash \bigcup_{i\leq n}\mathrm{Cl}(V_i)$与类似的$V_n'$，然后做$U'=\bigcup_{n\in\omega}U_n'$与$V'=\bigcup_{n\in\omega}V_n'$，我们证明它们是所需的分离$A$和$B$的开集。

一方面，显然每个$U_n'$和$V_n'$都是开集，而$x\in A\rightarrow\exists m(x\in U_m)\wedge\forall n(x\not\in \mathrm{Cl}(V_n))\rightarrow x\in U_m'$，因此$\{U_n'\}$和$\{V_n'\}$构成$A$与$B$的开覆盖。另一方面，若$\exists m\exists n\exists x(x\in U_m'\cap V_n')$，不妨设$m\leq n$，则$x\in V_n'\rightarrow x\not\in\mathrm{Cl}(U_m')\supseteq U_m'$，矛盾。
:::

::: remark*
事实上，这指出Urysohn度量化定理中$T_4$的要求可以减弱为$T_3$。此外，这个证明和Nagata-Smirnov定理的证明中第一个断言的证明非常相似。
:::

它还有一个更强的版本。

::: theorem
$Lindelof+T_3\rightarrow T_4$
:::

::: proof
仅仅在取出$U_n$的方式上有所不同。我们直接注意全体$S_x$附上$X\backslash A$恰好是$X$的开覆盖，然后用Lindelof可取出一可数子覆盖，我们再丢掉$X\backslash A$后称之为$U_n$即可。
:::

另一方面，我们考虑$T_2$如何加强为更强的分离性。

::: theorem
紧致+$T_2\rightarrow T_4$
:::

::: proof
由于紧致推出Lindelof，我们只要证明紧致+$T_2\to T_3$即可。

对于点$x$与不包括它的闭集$A$，我们对每个$y\in A$考虑$T_2$给出的开邻域$S_y$，使得$\mathrm{Cl}(S_y)$也不包括$x$，这样全体$S_y$和$X\backslash A$构成全空间的开覆盖，我们取有限子覆盖后去掉$X\backslash A$得到有限个$S_{y_i}$，现在开集$S=\bigcup_{i}S_{y_i}$满足$\mathrm{Cl}(S)$不包括$x$，这就是所要的分离。
:::

::: remark*
上面这坨定理的证明思路完全一样。
:::

如果条件弱一点，我们也有定理。

::: theorem
局部紧致+$T_2\rightarrow T_{3.5}$
:::

::: proof
在$T_2$空间中，局部紧有一个更强的形式。

**引理。** $T_2+$局部紧$\to$任给点$x$的邻域$U$，存在邻域$V$使得其闭包$\mathrm{Cl}(V)\subseteq U$且紧致。

**证明。** 显然它比局部紧原先的表述强多了。要证明此事，我们对这个空间$X$做单点紧致化$\bar{X}=X\cup\{\infty\}$，然后在其中运用$T_3$给出$x$与$\bar{X}\backslash U$的分离集$V$，最后由$\infty\in\bar{X}\backslash U$得到这个满足$\mathrm{Cl}(V)\subseteq U$的闭（从而紧）子集。

对于点$x$与不包括它的闭集$A$，上面的引理和$X\backslash A$是$x$的开邻域直接给出$T_3$所要的分离集$U\ni x$。现在$\mathrm{Cl}(U)$是一个$T_4$空间，从而是$T_{3.5}$空间，我们任取一个函数$f$将$x$送到$0$且将某个$\mathrm{Cl}(U)$的闭子集送到$\{1\}$。我们将$f$的定义域从$\mathrm{Cl}(U)$延拓到$X$上以证实$T_{3.5}$，自然方法是将所有未定义的值均定义为$1$，连续性不难证明。
:::

事实上，$T_2$与紧致性还能给出别的优良命题。

::: theorem
$T_2$的紧致子空间一定是闭集
:::

::: proof
我们证明紧致的$A\subseteq X$的补集一定是开集。事实上，对每个$x\in X\backslash A$和$y\in A$做分离$U_{x,y}\ni x$和$V_{x,y}ni y$，这样$\{V_{x,y}|y\in A\}$给出$A$的开覆盖，我们取其有限子覆盖$V_{x,y_i}$即可得到$\bigcup_{i}U_{x,y_i}$是$x$的包含于$X\backslash A$的开邻域。
:::

::: theorem
紧空间到$T_2$空间的连续双射一定是同胚
:::

::: proof
连续像保持紧致性，因此这个连续双射也是个闭映射。
:::

接下来，我们考虑加强紧致性。

::: theorem
可数紧致+Lindelof$\rightarrow$紧致
:::

::: proof
先用Lindelof取出可数子覆盖，再用可数紧取出有限子覆盖。
:::

::: theorem
可数紧致+$C_1\rightarrow$列紧致
:::

::: proof
可数紧致给出极限点紧致，于是我们对点列$\{x_n\}$考察其极限点$x$，我们取$x$处的可数邻域基$B_k$使得$B_{k+1}\subseteq B_k$，然后从每个$B_k$里选一个$x_{n_k}$，最后得到的$x_{n_k}$就是收敛到$x$的子列。
:::

::: theorem
极限点紧致+$T_2\rightarrow$可数紧致
:::

::: proof
闭集套每个闭集出一个点，得到的点列的聚点在$T_2$的条件下在交集中。
:::

最后，我们来看度量空间的良好性质，换言之我们把可度量化视作一个特别的性质。

::: theorem
度量空间中紧致、列紧致与极限点紧致等价。
:::

::: proof
无需度量空间的条件已有紧致推出极限点紧致，因此只要在度量空间中用极限点紧致推出列紧，再用列紧推出紧致即可。

第一个推断：考虑极限点紧致的度量空间$X$中的一个点列$A=\{x_n\}$。若$A$是有限集，则显然有常值子列收敛；否则，任取一个$A$的极限点$x$，依次选取$x_{n_k}$使得$x_{n_k}\in B_{\frac{1}{k}}(x)$，则这个子列收敛到$x$。

第二个推断：我们证明Lebesgue数引理。

**引理（Lebesgue数）。** 列紧度量空间$X$的每个开覆盖$\mathcal{A}$都有一个Lebesgue数$\delta$，使得$X$的每个直径小于$\delta$的子集都包含在某个$\mathcal{A}$的元素之中。

**证明。** 反证。如果Lebesgue数不存在，则任给正整数$n$，均存在$X$中直径小于$\frac{1}{n}$的子集$C_n$不包含在任何$\mathcal{A}$的元素之中。从每个$C_n$中选出一个$x_n$，然后由列紧性选取一个收敛子列$x_{n_k}$，且设它收敛到$x$。

假定$x\in A\in\mathcal{A}$，由于$A$是开集，我们取一个开球$B_{\epsilon}(x)\subseteq A$，然后考虑$K$使得$k\geq N\rightarrow n_k>\frac{2}{\epsilon}$，这样就有$C_{n_{K}}\subseteq A$，这引发矛盾。

我们再证明完全有界性。

**定义（完全有界性）。** 度量空间$X$具有完全有界性，若任给$\epsilon>0$均存在由半径为$\epsilon$的开球构成的$X$的有限覆盖。

**引理。** 列紧度量空间是完全有界的。

**证明。** 继续反证。若存在$\epsilon$使得$X$不能被有限个半径$\epsilon$的开球覆盖，则我们可以取一列点，它们两两之间的距离至少为$2\epsilon$，这说明这列点不可能有收敛的子列，矛盾。

现在推出紧致性就很轻松了：选开覆盖的Lebesgue数，然后取完全有界性给出的有限覆盖，它放缩一下就得到原来开覆盖的有限子覆盖。
:::

::: theorem
紧致与可度量化可推出$C_2$。
:::

::: proof
由完全有界性，对每个$n$我们都可以取出有限个半径$\frac{1}{n}$的开球覆盖全空间，我们把它们全部收集起来就得到一个可数的基。
:::

::: theorem
度量空间只要满足可分或Lindelof则一定有$C_2$。
:::

::: proof
Lindelof时与上面完全一样，只不过是可数个可数集做并而非可数个有限集做并。

可分时我们从这个可数稠密集的每个点处拿出全体半径为有理数的开球，可数个可数集，它是所要的可数基。
:::
