---
title: 子空间、积空间与连续像的性质
---

<problems>
- “子空间连通当且仅当其闭包连通”似乎只有“仅当”方向成立（例如有理数集在实数集中的闭包连通，但有理数集不连通）。
- “积空间局部紧当且仅当除了有限个空间之外均局部紧”似乎应为：积空间局部紧当且仅当每个因子局部紧，且除了有限个之外均紧致。
</problems>

本节主要讨论在取子空间、做积空间和做连续函数后取像空间这三种操作下，第二节的各类性质何时不变。

先来讨论分离性。

::: theorem
$T_2$空间的子空间和积空间和箱空间都是$T_2$的。
:::

::: theorem
$T_3$空间的子空间和积空间都是$T_3$的。
:::

::: theorem
$T_{3.5}$空间的子空间和积空间都是$T_{3.5}$的。
:::

::: theorem
$T_{4}$空间的闭子空间与闭连续像是$T_{4}$的。
:::

::: theorem
$T_{5}$空间的等价定义是其子空间都是$T_4$空间。
:::

::: proof
若$X$是$T_5$的，考虑其子空间$A$中的两个不交闭集$C\cap A$与$D\cap A$，
这指出$C\cap D\cap A=\varnothing$。
现在注意$C\backslash D$与$D\backslash C$是闭包与对方不交的$X$中集，$T_5$指出存在$U$和$V$分离它们，
于是$U\cap A$和$V\cap A$在$A$中分离这两个闭集。

反过来，若$X$的子空间都是$T_4$的，且$A$与$B$互相与对方的闭包不交。
考虑开子空间$X\backslash\{\mathrm{Cl}(A)\cap\mathrm{Cl}(B)\}$，在其中$A$的闭包与$B$的闭包不交，
于是由其$T_4$存在开集$U$与$V$在这子空间中分离$A$与$B$，
又由于$\mathrm{Cl}(A)\cap\mathrm{Cl}(B)$是闭集，
我们不妨有$U,V\subseteq X\backslash\{\mathrm{Cl}(A)\cap\mathrm{Cl}(B)\}$，
于是$U$和$V$即使在$X$中也是不交的。
:::

::: theorem {@thm:T6的等价定义}
$T_6$空间的等价定义是$T_4$且闭集都是$G_\delta$集（即一列开集的交），这指出它的子空间也都是$T_6$的。
:::

我们证明以下引理。

::: lemma {@lem:闭G-delta集与零点集}
$T_4$空间$X$中，一个集$C$是闭的$G_\delta$集当且仅当存在$f:X\to[0,1]$满足$f^{-1}(\{0\})=C$。
:::

::: proof
显然任何$f^{-1}(\{0\})$都是$G_\delta$的，我们现在来用$G_\delta$闭集$C$构造函数$f$。

我们假定$C=\bigcap_{n}U_n$，不妨设$U_{n+1}\subseteq U_n$。
注意到$C$与$X\backslash U_n$是不交的两个闭集，
Urysohn引理指出存在$f_n:X\to [0,1]$满足$f_n(C)=0$且$f_n(X\backslash U_n)=1$。
于是，函数$f=\sum_{n}\frac{1}{2^n}f_n$就是我们所要的。
:::

::: proof [@thm:T6的等价定义 的证明]
现在，若$T_4$且闭集都是$G_\delta$，则任何闭集$C$都存在$f$使得$f^{-1}(\{0\})=C$。
若有不交闭集$C$与$D$，则有$f_C$与$f_D$，注意$f=\frac{f_C}{f_C+f_D}$恰好在$C$上为$0$而在$D$上为$1$。

反过来，若$T_6$，则显然$T_4$，且闭集$C$均存在$f$使得$f^{-1}(\{0\})=C$，于是这闭集是$G_\delta$集。

最后，$T_6$则$T_5$，于是子空间均$T_4$，而闭集与$G_\delta$集均可遗传到子空间上，
于是子空间$T_4$且闭集都是$G_\delta$集，换言之子空间$T_6$。
:::

然后是连通性。

::: theorem
子空间连通当且仅当其闭包连通。
:::

::: theorem
连通性与道路连通性在连续像和积空间中保留。
:::

然后是可数性。

::: theorem
Lindelöf取闭子空间、连续像、乘上紧致空间保持性质。
:::

::: theorem
可分在开子空间、可数积和连续像中保持。
:::

::: theorem
$C_1$和$C_2$在子空间、可数积和开连续像中保持。
:::

然后是紧致性。

::: theorem {@thm:紧致的保持}
紧致在连续像、闭子空间和积空间中保留。
:::

::: proof
连续像紧致显然是因为连续像的开覆盖被连续函数拉回为原来那个紧致空间的开覆盖，
闭子空间紧致显然是因为闭子空间的开覆盖可以扩充为全空间的开覆盖。

紧致空间的积空间仍然是紧致空间是大名鼎鼎的Tychonoff定理，我们证明它等价于选择公理。
这里给出的证明是作者见过最简单的，利用了滤子紧致性这一等价形式。

首先用选择公理推Tychonoff定理。
记$X=\prod_{i\in I}X_{i}$，其上的全体滤子在包含关系下形成偏序集，
且允许对一集相互包含的滤子作并得到包含关系下它们的上界，
因此Zorn指出每个滤子都可以扩张为一个极大滤子。
现在任给一个极大滤子$S$，我们证明它的全体元素之闭包相交非空，从而任意滤子的全体元素之闭包相交非空。
具体而言，考虑投影$pr_{i}$将$S$变为$X_{i}$上的滤子$S_{i}$，从而$S_{i}$的全体元素之闭包相交非空，
设为$A_{i}$。
现在运用选择公理，从每个$A_{i}$中选一个点$a_{i}$，然后考虑$X$中的点$(a_{i})_{i\in I}$，
由于$S$是极大的，这个点必须包含在$S$的全体元素的闭包的交之中，从而它非空。

然后用Tychonoff定理推选择公理。
对一族$A_i$，我们赋予它们余有限拓扑，然后再并上一个单点$a_i$，
显然这些$X_i=A_i\coprod\{a_i\}$都还是紧致的，所以积空间$X=\prod_{i}X_i$紧致。
考虑这空间中的闭集族$V_i=pr_i^{-1}(A_i)$，由于有限个$A_i$中各选一个点不需要选择公理，
我们知道这个闭集族形成一个滤子，因此它们全部交起来至少有一个点，
这说明$\prod_{i}A_i=\bigcap_{i}V_i\not=\varnothing$。

当然，在没有选择公理的时候我们可以证明一个弱版本的定理，即有限个紧空间的积是紧致的。
:::

::: lemma [管状引理] {@lem:管状引理}
考虑任意空间$X$与紧致空间$Y$的积空间$X\times Y$中包含薄片$\{x_0\}\times Y$的开集$N$，
它一定包含一个管子$W\times Y$，这里$W\ni x_0$是$X$的一个开集。
:::

::: proof
我们考虑包含在$N$中的全体基$U\times V$给出的薄片的覆盖，由于这个薄片同胚于$Y$，它自然紧致，
于是可以选有限个$U_i\times V_i$覆盖薄片。
令$W=\bigcap_{i}U_i$，不难证明这些$U_i\times V_i$也覆盖$W\times Y$，因此$W\times Y\subseteq N$。
:::

::: proof [@thm:紧致的保持 的证明（续）]
现在要证的结论已经很简单了。
我们任取两紧致空间的积空间$X\times Y$的开覆盖$\mathcal{C}$，
管状引理（@-lem:管状引理）指出对每个$x\in X$都存在开邻域$W_x\subseteq X$使得$W_x\times Y$被有限个
$C_i\in\mathcal{C}$覆盖。
全体$W_x$又是$X$的开覆盖，于是可以选有限个，这样有限个管子的有限个覆盖总共是有限的，
且覆盖整个$X\times Y$。
:::

::: theorem
局部紧在闭子空间和开连续像中保留。
:::

::: theorem
积空间局部紧当且仅当除了有限个空间之外均局部紧。
:::
