# 界面

站点生成器写出的页面在浏览器中的样子与行为：模板、样式与浏览器中的脚本。页面怎样生成见 [开发文档](README.md#构建流程)；搜索界面见 [搜索](search.md)，讲义的目录与侧栏见 [讲义与指南](books.md)，模板文字的排版与字体见 [中文排版](typography.md)。

## 文件

| 部分 | 在哪里 |
| --- | --- |
| 模板 | `scripts/site/templates/`：返回 HTML 的函数。`layout.mjs` 是每个页面的框架（head、导航栏、页脚），`page.mjs` 是条目与讲义的页面（目录、学科导航、术语翻译、页面底部），`home.mjs` 是首页，`special.mjs` 是最近更改、页面历史等页面 |
| 样式 | `site/styles/`：sass，`site.scss` 引入各部分；颜色与字体在 `_variables.scss` |
| 浏览器中的脚本 | `site/scripts/`：直接放在其中的脚本原样发布到 `/js/`，子目录（`diff/`、`editor/`）中的由 esbuild 打包 |
| 界面文字 | `data/messages.yaml`，见下 |
| 图标 | `scripts/shared/icons.mjs`，见下 |

## 界面文字

`data/messages.yaml`，模板、构建与浏览器脚本共用（`scripts/shared/i18n.mjs`）。每项是 `键: 文字`；`{Name}` 是模板与构建填入的参数，`{name}`（小写）由浏览器脚本填入。键或参数缺失时报错。浏览器脚本的文字由模板写在页面中：数据属性（如链接预览的“前往条目”写在脚本的元素上），或 JSON（搜索的 `search-config`）。

## 图标

站点的线条图标（`scripts/shared/icons.mjs`），模板用 `icon(name)` 写入。讲义名前加书的图标（`icon('book')`），与分类名前的文件夹图标相同：讲义页面的面包屑、搜索结果（面包屑与讲义首页的标题）、最近更改页面、差异页面与首页的最近更改中的讲义名（有图标就不再加书名号）；正文中的链接不加。

## 首页的最近更改

Git 历史中最近的 5 次修改（PR 或直接提交，不含首次导入），只算条目与讲义、指南中的页面，不算[小修改](README.md#其他约定)（`scripts/prebuild/recent-changes.mjs`），写入首页的 front matter（`recentChanges`），由首页的模板显示（`scripts/site/templates/home.mjs`）。

- 每次修改一行，分两栏：左边是日期，靠右，与右边之间一道贯通的淡竖线；右边是页面的名称。
- 页面名称链接到页面本身，新页面后标一个上标的加号，名称之间的“·”写在前一个名称后面（换行时在行尾）；按读音排列（新建与改名的页面在前，讲义中的页面以讲义名代表），构建时最多写入 50 个。一行放得下全部名称时只写名称；放不下时显示放得下的几个（`site/scripts/site.js` 从后面整个去掉放不下的），最后一个后面加省略号，一行的末尾是按钮“N 个页面 ⌄”（共改了 N 个页面，与“全部更改”同色）：点开后全部名称在按钮左边换行排开，按钮留在原处（第一行的末尾），写作“收起 ⌃”；页面多于 50 个时，展开后名称后面写“等 N 个页面”。全在一部讲义中的修改只写讲义名，如“数学分析 中的 23 个页面”，不能展开。
- 修改了不止一个页面时，下面另起一行写 PR 的标题（直接提交为提交的标题），说明改了什么；标题只是这些页面的名称（去掉名称后只剩标点、空格与“和、与、及”，如“仿射 Hecke 代数、Hecke 代数”）时不写。页数与标题用小一号的字，标题一行写不下时截断。
- 日期由 `site/scripts/local-time.js` 换成读者的时区，今天、昨天写作“今天”“昨天”；与上一行同一天的日期不显示（列表标有 `data-hide-repeats`，没有脚本时按 UTC 的日期），格子与竖线留着。不写时间。
- 标题下面靠右是到最近更改页面的链接“全部更改”。没有 Git 历史时这一节不显示，链接一行改为链接到最近更改页面。

## 链接预览

指针停在正文的链接上，显示它所指的内容（`site/scripts/link-preview.js`，每页以 module 载入；样式在 `site/styles/_link-preview.scss`；测试 `tests/link-preview.mjs`）。

### 哪些链接

- 正文与学科导航中的引用（`bm-reference`）、文献引用（`bm-citation`）、脚注的标记（`bm-footnote-ref`）与百科链接（`bm-wiki-link`，尚未创建的条目除外）。目录与页脚中的链接、指向本页的百科链接、指向标题的引用不预览。
- 指针停留片刻后显示：百科链接很多，0.4 秒；其他 0.25 秒。用键盘聚焦（`:focus-visible`）时也显示。触摸屏不预览，点按照常跳转。

### 显示什么

- 引用：所指的定理类环境；列表项，按原来的编号；带编号的公式，连同前后的段落，各留约三行半，截断的一侧渐隐。
- 文献引用：参考文献条目；引用版本时显示整个条目。
- 脚注的标记：脚注的文字，不含返回的链接。
- 百科链接：条目的开头，不含条目名。第一个标题之前的段落、列表、公式，约两行文字为止；跳过约定、页面提示与插图（公式中的 TikZ 图照常显示）；条目以定理类环境开头时显示这个环境。去掉人名后的注释（`<person>`）与脚注的标记，其中的链接成为文字。开头截断在约十行；截断了，或者没有在句末结束（最后不是句号、叹号、问号或省略号，后面可以有引号与括号），底部渐隐，表示后面还有。如维基百科的页面预览，整个预览是一个到条目的链接，点哪里都到条目；右下是“前往条目 →”，灰色，指针在预览上（或键盘聚焦）时成为链接的颜色；看得见的最后一行文字伸过约三分之二宽时，它与文字多隔开一些。

### 内容从哪里来

- 目标在本页时从本页复制；在其他页面（讲义的其他章节、文献页、其他条目）时取来那个页面再复制。每页只取一次（最多留 10 页），也为点击预先载入；取不到时下次再试。
- 复制的内容去掉 id，以免与本页的重复；TikZ 图中的 id 连同图中对它们的引用改名。
- 来自其他页面时，相对的链接与图片改为指向原处；那里的 TikZ 图用到而本页没有声明的字体补上声明（每页只声明自己的图用到的字体，`style[data-tikz-fonts]`）。

### 外观与位置

- 预览是 popover（在顶层显示），放在链接所在的 `article` 中，沿用正文的样式；字号 1.4rem，正文中写明字号的参考文献与代码随之。
- 白色面板，宽 44rem（窄屏时为窗口宽减去两边各 1.6rem）；没有边框，只有淡淡的轮廓与柔和的阴影，与首页的搜索框一样，轮廓深一些。
- 在链接下方，下方放不下而上方更宽时在上方，不被导航栏遮住；链接折行时对着指针所在的那一行。边上的尖角指向链接的中点；面板以尖角为中心，不超出窗口，左边距正文的左缘至少 1em（窗口优先）。
- 内容过长时，百科链接的预览截断，其他的在面板中滚动（最高为窗口的一半，至多 44rem）；底部渐隐，渐隐的文字与面板的底边之间留出内边距。

### 交互

指针可以移入预览（离开链接后有 0.25 秒的余地）、选择文字、点击其中的链接；移开、Esc、在别处按下、窗口大小改变或离开页面时关闭。
