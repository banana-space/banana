# 层级分类

在 `data/categories.yaml` 中以分类名称为键，用 `parent` 指定直接父分类：

```yaml
数学: {}
代数学:
  parent: 数学
顶点代数:
  parent: 代数学
```

文章只填写最细分类，例如 `categories: [顶点代数]`；也可以填写多个分类。
预处理会在生成副本中补齐祖先分类并去重。文章页只展示原始分类。
分类总览显示顶层分类及其下指定层数的子分类；分类页显示完整祖先导航、指定层数的子分类，以及直接归属于本分类的条目（按读音排序、每页 50 条）。条目超过 10 条时按首字母分组，宽屏双栏显示；有多页时在条目上方显示字母导航，链接到每个字母开始的页面（窄屏隐藏）。条目总览 `/wiki/` 使用同样的分组。
默认显示一级子分类（总览不计顶层，分类页不计当前分类）；可在 `hugo.toml` 的 `[params]` 中用 `categoryDepth` 改变层数，如 `categoryDepth = 2` 显示两级。设为 `0` 时总览只显示顶层，分类页隐藏子分类。此选项仅控制导航，不影响文章筛选。分类列表旁的数字统计本分类及所有后代分类的条目总数（去重）；只填写子分类的文章不会出现在父分类的条目列表中。没有条目的分类也会生成页面，没有直接归属条目时隐藏“条目”标题。
未在分类树中声明的分类仍可使用，视为独立顶层分类。
分类树和分类页的条目列表按读音排序（见 [语法说明](syntax.md#排序读音)）。分类读音默认由名称自动生成，可用 `sort` 指定：

```yaml
代数拓扑:
  parent: 拓扑学
  sort: dai shu tuo pu
```
分类名称支持行内公式，例如 `$p$ 进几何`；分类页、分类树与祖先导航保留公式显示，不自动大写字母。名称先按内部链接的公式转换规则（见 [syntax.md](syntax.md) 的“名称中的公式”）生成匹配形式，再用于分类匹配和网址（如 `/categories/p-进几何/`）。文章可填写同样的公式名称或对应纯文本名称。分类树中的名称规范化后重复、父分类不存在或循环关系都会导致构建失败；转换后的名称不可包含路径分隔符。

修改分类后请使用 `npm run build` 或 `npm run serve`；直接运行 Hugo 不会更新生成内容。
运行 `npm test` 验证分类汇总、导航、编号与引用和错误配置。
