# 自动排版

中文与西文字母、数字、行内公式之间自动补实际的普通空格；已有普通空白在这些边界统一为一个空格。汉字之间、所有括号和引号内侧，以及汉字与全角括号、`「」『』` 外侧之间的普通空白自动清理。半角括号和引号保留原字符，中文与其外侧之间补空格，例如 `如式(1.1)所示` 变成 `如式 (1.1) 所示`。弯引号 `‘’“”` 使用 Inter，在汉字与上引号 `‘“`、下引号 `’”` 与汉字之间补普通空格，例如 `汉“字”汉` 变成 `汉 “字” 汉`；按字符方向处理，不检查配对。半角逗号、句点、分号、冒号、感叹号及问号后紧接汉字时补空格，例如 `整数,实数` 变成 `整数, 实数`；小数、编号、连字符及公式内容保留。NBSP、细空格、全角空格等所有特殊空格均保留。处理跨越链接和强调等行内标签，边界新增空格放在链接外侧，不改 `href`、`id` 或 TeX。独立公式、代码、预格式文本和参考文献不参与正文清理。括号和引号的清理适用于中文语境，英文及韩文片段保留原有空白。

相邻标点至少有一个是中文标点时，清理两者之间的普通空白（含 Markdown 软换行），例如 `。 （` 变成 `．（`；纯西文标点间的空白及所有特殊空格保留。由 CSS 提供可见间距的分隔符可标记 `data-typography-boundary="true"`，阻止排版规则跨越该元素补空格；术语翻译的分隔点使用此标记。普通空 span 不会阻断中西文间距。

中文语境中的全角标点与汉字、西文字母、数字、行内公式之间都清理普通空白，例如 `。 汉字` 变成 `．汉字`、`xxx （` 变成 `xxx（`、`， xxx` 变成 `，xxx`。此规则可跨越链接和标为外语的西文片段；完整英文或韩文区域及所有特殊空格仍保留。半角逗号、句点、分号、冒号、感叹号和问号清理前面的普通空白，后接汉字时使用一个普通空格，例如 `汉字 , 汉字` 变成 `汉字, 汉字`。

边界规则由同一判断同时负责补空格和清理已有空白，避免两个步骤相互抵消：

| 边界 | 普通空白规则 |
| --- | --- |
| 汉字与汉字 | 清理 |
| 汉字与西文字母、数字、行内公式 | 一个空格 |
| 全角标点与汉字、西文字母、数字、行内公式 | 清理 |
| 标点与标点，至少一侧是中文标点 | 清理 |
| 括号、引号内侧 | 清理 |
| 半角括号外侧与汉字 | 一个空格 |
| 汉字与 `‘“`、`’”` 与汉字 | 一个空格，不检查配对 |
| 半角逗号等句读标点 | 清理前侧，后接汉字时一个空格 |
| NBSP 等所有特殊空格 | 保留 |

全角标点覆盖中文标点及全角形式的 Unicode 标点；共享的弯引号 `‘’“”` 单独按 Inter 引号规则处理。代码、独立公式、参考文献以及显式排版分隔边界不跨越处理。

所有显示文字，包括文章主标题、分类和 wiki 链接文字，都在 postbuild 排版，不把半角括号替换成全角。中文定理标题的外层括号由 i18n 模板直接生成全角括号。prebuild 仅为名称匹配和章节 ID 使用相同的空白规则；条目查询仍接受半角、全角及半角括号前多一个空格的三种写法，显示采用作者输入的括号。章节锚点根据排版后的标题生成，例如 `中文API与$f$` 的 ID 为 `中文-api-与-f`。中西文自动间距关闭；标为 `lang="ko"` 的韩文区域启用原生 `text-autospace: normal`，不人工添加或删除韩文空格。

中文正文默认把 `。` 转换成实际字符 `．`，网页显示与复制一致；ASCII `.`（如 `定理 X.Y`、`3.14`）保持不变。在文章 front matter 中关闭句号转换：

```yaml
typography:
  convertChineseFullStop: false
```

此参数只关闭句号转换，其他排版规则仍执行。完整外文片段用 `<lang>` 标签标注；整篇外文文章可在 front matter 中设置 `lang: ko` 或 `lang: en`。引号默认写作 `“”`，系统保留其他既有引号样式。

排版规则和 HTML 处理器位于 `scripts/shared/typography.mjs` 与 `scripts/postbuild/`，不会复制到公开目录，网页也不会调用这些模块。正式构建和开发预览都通过 parse5 解析 HTML，在 postbuild 完成空白及标点替换；预览浏览器只接收完成的页面和构建刷新通知。直接运行 Hugo 不会执行后处理，请使用 `npm run build` 或 `npm run serve`。

标点字体家族为 `Banana Punctuation`，普通字重使用 `static/fonts/BananaPunctuation-Regular.woff2`，500 和 600 分别使用 `BananaPunctuation-Medium.woff2` 和 `BananaPunctuation-SemiBold.woff2`。字符范围在 `_base.scss` 的 `@font-face` 中声明，仅覆盖中文标点和弯引号 `‘’“”`，不覆盖 ASCII 句点、逗号和数学符号。

字体用 `kern` 收紧相邻标点（如 `），`），正文设 `font-kerning: normal`，因为 Firefox 的 `auto` 对 CJK 文字不做 kerning。`scripts/fonts/banana-punctuation.py` 给字体加上 `halt`（标点的半宽间距）和 `chws`（与 `kern` 共用同一查找表）：中文正文设 `text-spacing-trim: trim-start`，Chromium 据此把行首的开括号压成半宽，并在字体切换处（如加粗边界 `**文）**（`）收紧括号；同一字体内的相邻标点仍由 `kern` 处理，不会重复收紧。Chromium 把 `、。，．` 视作一组，要求它们宽度相同且字形不超过半宽，本字体不满足，所以字体切换处的逗号、句号（如 `**（文）**，`）不收紧。Firefox 不支持 `text-spacing-trim`。代码块恢复 `text-spacing-trim: normal`。

公式在 Hugo 构建阶段输出 KaTeX HTML 与 MathML。postbuild 将每个行内公式视为不可拆分的文字边界，只处理公式外的空白，不遍历或修改公式内部的排版、MathML 和 TeX；独立公式阻断正文排版。
